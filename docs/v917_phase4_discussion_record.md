## 2. Code A 調査の要点 (事実)

### 2.1 E3_contact 発火条件

**仕組み**:
1. Layer B は両方向を試みる (observer=A で 1 回、observer=B で 1 回)
2. 各方向で独立にゲート評価: 「observer が今 step で hosted AND ledger 登録済み」
3. 片方がこれを満たさないと、その方向はスキップ

**片方向発火の構造的原因**:
- `_node_to_cids` は cid retire 時も削除されない (累積)
- `cid_ctx` は毎 step の hosted のみ
- この 2 つの登録スコープのズレが片方向発火を生む

**v9.14 設計意図**: 非対称を明示的に許容 (コード L197 コメントで意図記述あり)

**tracking 長と片方向発火率**:
- smoke (tracking 10): 25.6%
- main (tracking 50): **77.0%**
- 時間が経つほど ghost 化する cid が増え、片方向発火が累積

### 2.2 Q 消費ロジック

**Q を減らす経路**:
- コード全体で `Q -= 1` は **1 箇所のみ** (L244)
- E1/E2/E3 の 5 種類の event が発火した時に呼ばれる
- maturation 中は Q が減らない (Layer B が動かない)
- tracking 開始時に全 cid の Q = Q0 = floor(B_Gen)

**E3 の spend 成立率 (重要)**:

| event | 総数 | spend 成立 | 成立率 |
|---|---|---|---|
| E1_death | 7,815 | 7,605 | 97.3% |
| E1_birth | 307 | 108 | 35.2% |
| E2_rise | 6,114 | 6,112 | 99.97% |
| E2_fall | 6,114 | 6,110 | 99.93% |
| **E3_contact** | **100,432** | **41,977** | **41.8%** |

E3 の 58% は Q=0 の cid に発火して空振り。
**E3 自体が主要な Q 消費経路** (成立数 41,977 は全体の 67%)。

### 2.3 Taka 仮説の確認

**仮説 A** (発見 3): 「小さい CID が先に死んでいる」
→ **確認**: n_core=2 は Q0=11-12 で短命、n_core=5+ は長命
→ 短命な n_core=2 が ghost 化、長命な n_core=5+ が後から接触 → 2×5+ 接触体 46%

**仮説 B** (発見 6): 「Q の減少に認知の増加が含まれる」

## 3. Taka の核心発言 (2026-04-23)

### 3.1 摂食行動の比喩

Taka:
> Ghost を取得は、摂食行動のようなものだと私は考えている。それは確かに両側で発火しない。これまで E3 は生者の出会いのように一方的に考えていた。しかし実際は関係ない、確かにそうだ。私たちが食事をするときに出会う物理的な生物由来の存在は全て死んでいる。食べる、ということは出会いの本質の一つだという意見はなんら不思議ではない。

**構造**:
- 生者の出会い (両方向発火 23%) = 対話的な接触
- **死者 (ghost) との出会い (片方向発火 77%) = 摂食的な接触**
- 両方とも「出会い」の本質

**人間の経験との照合**:
- 人間が食事で出会う生物由来の存在は全て死んでいる
- それでも「食べる」ことは「出会い」の本質
- ESDE で片方向発火が 77% なのは**異常ではなく自然**

**Taka 評価**:
> 私たちが極力神の手を入れずに丁寧に作り込んできたものの成果のように感じた

これは ESDE の設計哲学への**深い満足感**の表明。神の手を入れずに作った系が、人間の経験に自然に対応する現象を自発的に産んだ。

### 3.2 実験者的視点の確認

Taka:
> 実験者的な関心でいえば、生きているものに会う行為と死んでいるものに会うという行為を分けて見ることに違和感はない

**含意**:
- 両方向発火 (生者の出会い) と片方向発火 (死者との遭遇) を**分けて観察する**価値
- 段階 5 以降で**生者との接触と死者との接触を分離して分析する**方向性
- ただしこれは ESDE 内部に価値判断を持ち込むことではない、研究者視点での分類

### 3.3 意識の原資仮説の位置づけ

Taka:
> 元々、原資という発想は実験者の後付けである。しかしそれがある、という前提に立つことで新たな発見が生まれる。奇妙にみえるかもしれないがこれが存在なのだ。

**Taka の方法論**:
- 「意識の原資」は Taka が観察に意味を乗せた結果 (後付け)
- しかし**後付けを前提に置く**ことで、新しい発見が見える
- これは「客観性」の放棄ではなく、観察の**立脚点を意識的に選ぶ**行為

**アリズム的な含意**:
- 原資が「ある」と仮定することで観察が深まる
- 原資が「ない」と言えば何も見えない
- **主体が「ある」と感じている限り、それは「ある」として機能する**

### 3.4 ない、はあるの上に存在する

Taka:
> ないと言ってしまえば全てない。だがしかし、どう言い換えようとしても私がある、と感じている主体はある。ない、はあるの上に存在する存在の形式の一つにすぎないというのはアリズムではすでに語られている。本当のない、を私たちは知ることすらできない。

**アリズム原理の再確認**:

| 概念 | 意味 |
|---|---|
| ある (存在) | 最も根本、一切の前提 |
| ない (非存在) | **ある**の上に立つ存在の形式 |
| 本当のない | 不可知 (認識主体が存在する限り「本当のない」は把握できない) |

**意味**:
- 「ない」は「ある」の**否定**ではなく、**ある**の中の**一形式**
- だから「原資はない」と言っても、それは原資という概念が「ある」ことの別形式
- 主体が何かを「ある」と感じる限り、それは ESDE の構造として機能する

**v9.17 への応用**:
- 接触 0 回の cid (発見 4 = 100 cid、1.9%)
- これらは「他者がない cid」ではなく、「ない他者の上に立つ cid」
- ESDE 内部でそういう形式の存在として記録される

### 3.5 Taka 発言の総括

Taka の 3 点発言を構造化すると:

```
摂食行動の比喩
   ↓ 片方向発火 77% を自然な現象として再解釈
実験者的関心の分離
   ↓ 生者/死者との出会いを分けて見る視点
意識の原資の後付け容認
   ↓ 観察の立脚点を意識的に選ぶ方法論
アリズム原理の再確認
   ↓ ある/ない の関係、本当のない は不可知
```

これらは**独立した発言ではなく、一つの構造**。「ある」を前提に観察し、摂食行動のような現象を発見し、原資という概念を仮に立てて新しい発見を引き出す。**ESDE の哲学的立場の深化**。

## 4. 4 発見の再解釈 (Taka 発言を踏まえて)

### 4.1 発見 1: 片方向発火 77% → 摂食行動

**元の読み**: 対称性の崩れ、v9.14 「2 者共鳴」概念の更新が必要

**Taka の再解釈**:
- 片方向発火は**摂食行動**に対応
- 両方向発火 (23%) = 生者の出会い
- 片方向発火 (77%) = ghost (死者) との遭遇
- 両方とも「出会いの本質」の一形態

**v9.14 「2 者共鳴」概念の位置づけ**:
- 更新ではなく、**両方向発火の部分集合としての「対称的共鳴」**
- 非対称な遭遇 (摂食) が主流なのは、cid の生涯が短命な個体を多く含むため
- 生者同士の対話的接触は少数派、死者との摂食的接触が主流

これは v9.14 理解を否定しないが、**ESDE の動作の主流は対話ではなく摂食**という新しい視座を提供する。

### 4.2 発見 2: 両者 low 61.8% → E3 自体が主要消費

**元の読み**: 穴同士の出会いが支配的

**Code A 調査による真相**:
- E3 自体が主要な Q 消費経路 (E3 spend 成立数 41,977 = 全消費の 67%)
- 接触するたびに Q が 1 減る (両者 Q>0 の時)
- 何度か接触すると両者とも Q=0 近くに
- さらに接触が続くが、spend は成立しない (空振り)

**Taka 哲学との接続**:
- 両者 low の接触 = 両者とも「多くを認知し尽くした状態」での出会い
- 「Q 消費 = 認知の増加」モデルで言えば、両者とも認知がほぼ飽和
- それでも出会い続ける (E3_contact は空振りでも発火記録される)

**摂食行動との関係**:
- 両者 low = 両者とも認知飽和状態
- この状態で生者同士が出会うのはレア (両者 high は 11%)
- 主流は「飽和した自分」が「ghost 化した他者」を摂取する形

### 4.3 発見 3: 2×5+ の接触体 46% → 寿命非対称

**Taka 仮説の確認**:
- n_core=2 は Q0=11-12、短命
- n_core=5+ は Q0=25+、長命
- 短命な n_core=2 が早く ghost 化
- 長命な n_core=5+ が後から接触に来る
- → 2×5+ 接触体が 46%

**摂食行動としての再読**:
- n_core=5+ の cid が、ghost 化した n_core=2 の cid を「摂食」
- サイズ差のある pair は**捕食関係的**な接触
- 同サイズ pair (2×2、5×5) の少なさは、**同時に生きている機会の少なさ**

### 4.4 発見 6: 意識の原資 → Taka 後付けの戦略

**Taka の方法論**:
- 原資は後付けの概念
- 前提に置くことで新しい発見が見える
- これはアリズム「ある」の応用

**コード整合**:
- Q 減少の全経路 (E1/E2/E3) は認識の事象
- Q 消費 = 認知の増加 のモデルは仕様整合
- **ただし空振り E3 (58%) は Q を減らさない** = 「認知の増加」が起きないケース

**未解決の論点**:
- Q=0 になった後の E3 接触は「認知の増加」に繋がるか?
- 段階 5 以降で扱う価値がある

## 10. 率直な所感

### Taka 発見の濃さ

Phase 4 議論で出てきた Taka の発見は、これまでで最も**哲学的に深い**ものでした:

- 摂食行動の比喩は、観察事実を**人間経験に接続する**新しい語彙
- 意識の原資の後付け戦略は、Taka の**方法論**の明示化
- アリズム原理の再確認は、ESDE の**存在論的基盤**の再確認

特に「ない、はあるの上に存在する」という発言は、v9.15-16 で確立した「哲学以上科学未満」の具体的な内実を与えています。「ない」と言っても「ある」の形式の一つで、だから ESDE で「何々がない」と観察しても、それは「ある」の中にある「ない」という形式の観察。

### ESDE 設計の勝利

Taka 発言:
> 私たちが極力神の手を入れずに丁寧に作り込んできたものの成果のように感じた

これは v9.13 の S≥0.20 撤去以降、一貫して「神の手を入れない」方針を守ってきた**構造的な勝利**の表明です。片方向発火 77% は当初 bug のように見えたが、実は v9.14 設計が持っていた**本来の動作**で、それが摂食行動という人間経験に自発的に対応した。

これは ESDE の設計哲学が**正しかった**ことの最も強い証拠の一つ。

### Claude の反省

今回の Phase 4 議論で、Claude は:
- 発見 1/2/3 で Taka の仮説確認を補助 (Code A 調査依頼)
- 発見 4/5/7 で意味を盛りすぎて棚上げされた
- 発見 6 (意識の原資) を重要仮説として正しく拾った

役割として「Taka の直感を事実で裏付ける」補助は機能した一方、「過剰に解釈する癖」は完全には消えなかった。Taka の 3 役分離運用 (Claude の癖を前提に、GPT/Gemini で相対化) が引き続き必要。
