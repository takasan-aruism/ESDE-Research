## 1. v10.0 — Developmental フェイズ宣言

### 1.1 主題切替

v9.18 完了後、フェイズ名を Cognitive から **Developmental** に変更。理由:
- 「Cognitive」は認知層に閉じた印象
- 「Conscious」は意識層を主題化しすぎる
- 「Developmental」= 発達期、認知層と意識層の協働を扱うフェイズとして適切
- v5-v7 で「夢を見すぎた」反省を埋め込む命名

### 1.2 4 層アーキテクチャの確定

```
意識層 (Layer C): C、選択的鮮明、シングルタスク
```

意識層は v10.x で初めて動作する機構として実装。それまでは概念のみ。

|---|---|---|

C は認知層の Q 消費から転化される。物理層・存在層は frozen のまま。

## 2. v10.1 — Minimal Ingestion

### 2.1 主題

ghost を Q ベースで扱い、E3 接触圏内の摂食機構を最小実装する。

### 2.2 動機

- 旧仕様 (GHOST_TTL=10 固定): 個体差なし、神の手
- 新仕様 (Q ベース): 生前活動量を residual_Q に反映、不均一な資源地形
- ghost を「資源として利用可能にする構造」を導入

### 2.3 実装範囲

```
新規:
  ghost.residual_Q (ghost 化時点の Q_remaining 完全継承)
  摂食機構 (1 step に 1 ghost を食べきり、Q0 で頭打ち、消化分は散逸)
  step 末一括 reap (空摂食許容)
  pickup 機構廃止 (v9.8c で導入されたもの)
  ingestion_rng (摂食ランダム選定用、seed ^ 0x1A7E57)

維持:
  物理層 frozen
  Layer A bit-identity
  v9.18 までの全機構
```

### 2.4 仕様の主要決定 (Taka 確定)

- 摂食量: 1 step に 1 ghost の residual_Q を全部取得 (1 ghost 食べきり)
- 1 CID:多 ghost = ランダム選定 (seeded RNG)
- 多 CID:1 ghost = cid_id 昇順
- 飢餓判定撤廃: 満腹でも摂食可、Q0 超過分は消化分として散逸
- 空摂食許容: residual_Q=0 でも reap 前なら摂食試行可
- 摂食独自の Q 消費なし (E3 接触で -1 は既存通り)

### 2.5 本番 run 結果

```
24 seeds × tracking 50、subject 数 5,224 (v9.18 と完全一致)
wall time: v9.18 比 0.991x
摂食イベント: 3,588 件
ユニーク eater: 1,361 (subject の 26.0%)
ghost 食糧化率: 78.0%
消化分: 16.73%
```

### 2.6 v10.1 で観察された重要発見

#### 発見 1: phantom contact の規模

物理層 (`_node_to_cids`) に cid retire 後も痕跡が残る設計のため、E3 接触の対象が「既に消滅した cid」になるケースが大量発生。摂食 3,588 件に対し phantom 48,625 件。

#### 発見 2: 「物質的なもの」の位置づけ (Taka 整理 2026-04-26)

phantom を CID 主体間の問題として主題化するか議論があったが、Taka 判断:
- phantom = CID 間問題ではなく**物質的環境**
- 看板や道路のような静的な環境要因
- ランダム発生のイベント因子
- CID 主体間の問題から**一段下げる**

これは ESDE で「主体性のない認知層要素」が初めて定義された瞬間。認知層内に階層がある (CID 主体間 vs 物質的環境)。

#### 発見 3: GPT 主題化提案への Taka の判断

GPT 監査が「主役は phantom contact」と方向転換を提案したが、Taka は主題化を却下:
- phantom = 想定の能力不足の現れ
- 「物質的なもの」と位置づければ問題化しない
- v10.2 は本来の主題を扱う

これは「監査が主題判断に越権するリスク」の実例として記録。

### 2.7 v10.1 の動機の再解釈

実装結果を踏まえて、Taka の元動機が**仕様の進化に伴って意味が変わった**ことを記録:

- 元意図: ghost 期間の不自然さ解消 (期間に個体差を反映)
- 新意味: ghost を**不均一な資源地形**として扱う (Gemini 概念と接続、residual_Q に個体差を反映、期間は摂食圧依存)
- 元意図: 飢え死に救済
- 新意味: ghost を**資源として利用可能にする構造の導入** (主眼は資源化、飢え死に救済は副次的含意)

これは Taka 哲学「構造が先、定義は後」の実例。議論を経て潜在構造が顕在化した結果、動機を再解釈する形で整合させた。

## 3. v10.2 — Probabilistic Cognitive-Conscious Balance

### 3.1 主題

意識層資源 C を導入し、Q と C の比率でイベント時に認知/意識のどちらが立つかを確率決定する機構を実装。

### 3.2 動機

- v9.18 で言語化された意識の原資モデル (Q → C 転化) を**動作する機構**として最初に実装
- v10.1 の機械的摂食からの脱却 (確率発動への変更)
- 認知層と意識層の協働の最初の動作

### 3.3 階層論的構造の確率による圧縮 (Taka 整理 2026-04-27)

> 認知層が立つ → 意識層が立つ → 行動が起こる → 接触ないし摂食が起こる、が本来正しい順序。
> ただ、各段階で発火しないケースが多いので大変。
> ランダムで起こるは実装コストを下げる目的。要は構造的な組み合わせを確率論で圧縮しているようなもの。

v10.2 の確率決定機構の本質的な位置づけ:
- 本来の階層論的順序: 認知 → 意識 → 行動 → 接触
- 各段階の発火条件を全部実装すると複雑性が爆発
- 確率決定は**本来の構造の近似実装**
- v10.3 以降で各段階を精緻化する余地

### 3.4 解釈 X (Code A 指摘 2026-04-26 → Taka 採用)

既存の E3 spend (Q-1) が「認知活動」と同義と位置づけ:
- 認知が立つ: Q-1 + C+1 + virtual_attention/familiarity 更新 (既存通り)
- 意識が立つ: C-1 + 摂食発動 (Q-1 はしない、virtual 更新も止まる)

これにより:
- 「認知活動」を新規概念として実装で増やさない
- 既存 spend に意味を後付けする美しい解釈
- Code A 側の修正範囲も最小化

### 3.5 確率決定の対象 (Code A 指摘で確定)

- E3 onset のみ確率決定の対象
- E1 / E2 は従来通り無条件 Q-1 (確率決定対象外、C 蓄積に寄与しない)
- 双方向 E3 (hosted-hosted): 必ず認知確定 (三項共鳴は v10.3 以降)
- 空摂食ケース (residual_Q=0 ghost): 認知確定
- phantom (reaped 済 cid): 認知確定

### 3.6 確率式 (Taka 確定、シンプル案採用)

```
P(認知) = Q / (Q + C)
P(意識) = C / (Q + C)
```

将来の精緻化余地はあるが v10.2 ではシンプル案。

5. **動的均衡 = 進化終端の兆候なし**: Q+C 系全体で平衡に達していない、進化継続中

これは v10.2 の最大の構造的成果。集団平均では見えなかった構造的継承が顕在化した。

**集団平均はこの戦略二極化を隠していた**。ESDE の構造的観察は n_core 別の層化解析を要する。

#### 物理層 → 認知層 → 意識層の構造的継承

設計したのは単一の確率ルール (P(認知) = Q/(Q+C)) のみ。しかし結果として:
- n_core (物理層、cid 誕生時に決定) で決まる構造が
- 寿命・Q 蓄積 (認知層) に反映され
- C 蓄積・意識発動率 (意識層) にまで継承される

意識層という新しいレイヤーが、下位層由来の構造差を忠実に反映する。これは ESDE が階層論として整合していること、すなわち**単一の物理規則と確率規則から複数の生存戦略を内発的に生成すること**の直接的観察。

#### Taka 観察の言語化 (2026-04-28)

> これまでの開発史において、ノード数は構造の複雑を意味し、それゆえに認知や意識といった高度な概念が発生するという前提を置いていた。それが今回見事に形になった。しかも過去にはノード単位の統計を重視してきたが最近は統合されたものがメインであった。その意味でインビジブルな状態が数バージョン続いた。それにもかかわらず、こうして意図している形でデータが得られたことに驚きがある。

### 3.12 詳細解析の発見 (Taka 指示 2026-04-28、Code A 実施)

n_core 別層化解析の発見を受けて、Taka が 2 AI (Gemini / GPT) から提案を求め、統合された 5 本の解析を Code A が実施した。詳細は `v102_detailed_analysis_report.md` (495 行) 参照。

#### 解析 5 本の概要

```
解析 1 (個別性、5,224 cid):
  発動群 / 非発動群を Q0、寿命、初回 cognition タイミング等で比較

解析 2 (トポロジー、5,224 cid):
  4 分類 (no_activation / early_single / late_single / repeated)

解析 3 (時系列、1,200 行):
  C / Q / (Q+C) per_capita / 流入 / 散逸の窓ごと推移

解析 4 (偏在、1,200 行):
  Gini 係数、top 10/5/1% シェア、n_core 別偏在度

解析 5 (初回発動、1,160 cid):
  初回 consciousness 発動の lifecycle phase、C/Q 値、摂食成功率
```

#### 新規発見 1: 誕生時 Q0 は分岐の決定要因ではない

予測では「B_Gen / Q0 で偏りがある」とされていたが、実際は同一 n_core 内で発動群 / 非発動群の Q0 median はほぼ同一 (n_core=2 で 12 vs 12、n_core=5 で 33 vs 34)。意識発動の有無は**接触頻度・寿命由来**で、誕生時資源量は決定要因ではない。

#### 新規発見 2: 寿命と初回 cognition タイミングが分岐の主因

```
発動群は非発動群の 4-7 倍長く生きる:
  n_core=2: 2,000 vs 500 step
  n_core=5: 18,500 vs 3,000 step

発動群は早く認知活動を経験 (c_first_increment_step):
  n_core=2: 7,000 vs 12,500 (5,500 step の差)
  n_core=5: 4,049 vs 19,500 (15,500 step の差)
```

C 蓄積を早く始めた cid のみが意識発動に到達できる構造。

#### 新規発見 3: 初期認知活動密度は逆に非発動群で高い (反直感)

「単位時間あたりの認知活動密度」は非発動群の方が高い。これは:
- 短命の非発動群は 1-2 window で生涯を終え、その期間に Q を一気に消費
- 長寿の発動群は認知活動を長期間に分散

「単位時間あたりの密度」と「累積活動量」は別物。後者が意識発動の前提。

#### 新規発見 4: 初回意識発動時の摂食成功率 = 100% (構造的確認)

全 1,160 発動 cid で初回意識発動 → 必ず摂食成功。即時摂食設計 (v10.2 §3.1 F) の数値的確認。「意識発動 = 必ず摂食」という v10.2 のフェーズ的構造が定量的に検証された。

#### トポロジー観察: n_core 別の対称的二極化

| n_core | no_activation | early_single | late_single | repeated |
|---:|---:|---:|---:|---:|
| 2 | **89.9%** | 5.3% | 4.7% | **0.1%** (3 cid) |
| 5 | 26.8% | 28.4% | 10.8% | **34.0%** |

n_core=2 と n_core=5 の支配的パターンが**正反対**。n_core=5 では repeated > early_single (初回発動が次の発動を呼ぶ自己強化機構の可能性)。

#### 時系列観察: 動的均衡の数値的兆候


### 4.6 Integration 概念 (Taka 整理 2026-04-29)

#### 定義

**Integration** = A + B (個別 cid の集合) を一つの主体として抱える上位層の存在。

> CID A が食べたとする → CID B が食べたは否定された
> CID B が食べたとする → CID A が食べたは否定された
> これが上位の層を引き出す条件と考える。
> Integration からすればどちらも取ったことになるし、どちらも取っていないことになる。
> しかし、Integration が取ったとして記録は残る。

水と油の境界面の比喩 (Taka): 水 (A) と油 (B) があるだけでは関係は明示されない、両者を分ける境界面 (C) があって初めて「水と油が分かれている」現象が manifest する。

#### ESDE 階層進化系譜

```
ノード (個別実体)
  ↓ Integration として cid が成立
cid (複数ノードの Integration)
  ↓ Integration として上位層が成立
??? (複数 cid の Integration = v10.3 観察対象)
  ↓
SEED 統合 (Layer 6)
```

cid 自体が「複数ノードの Integration」だった。v10.3 で観察するのは「複数 cid の Integration」の登場条件。これは Aruism 階層進化の同型反復。

#### 構造的解決 (Taka 整理)

> Integration が成立することで、Ghost の Q 摂取と CID の摂取の問題は、Integration による Q の分配問題として対応ができる。上位構造の役割をみれば、それは構造の統合であり、CID の代謝は Integration の維持という合理的な根拠を得る。

下位層では解決不可能な問題 (摂食順序の神の手リスク) が、上位層では「Integration の代謝 → cid 個別代謝」として自然に扱える形に変換される。生物学的には「個体 (Integration) の代謝が細胞 (cid) の代謝として現れる」と類比的。

- ESDE で「主体性のない認知層要素」が初めて定義

### 5.5 階層論的構造の確率による圧縮 (v10.2)

本来の階層論的順序 (認知 → 意識 → 行動 → 接触) を、各段階の発火条件を実装する代わりに確率で圧縮表現する設計思想。実装コストを下げる方便であり、v10.3 以降で各段階を精緻化する余地。

### 5.6 意識発動の自然フィルタ (v10.2)

C は認知活動からのみ蓄積される。よって:
- まだ E3 に当たっていない cid は意識発動できない
- 短命の cid (n_core=2) は意識発動の機会が少ない
- 長命の cid (n_core=5) は意識発動が多い

「意識層は誰にでも備わるが、活動するには資源蓄積が必要」というフェイズ的構造。これが結果として動的均衡を回避し、進化継続を可能にする。

### 5.7 (Q+C) 保存則と散逸 (v10.2)

```
認知活動: ΔQ = -1, ΔC = +1 → Δ(Q+C) = 0 (CID 内で保存)
意識活動 (摂食): ΔQ = +gain, ΔC = -1 → Δ(Q+C) = gain - 1 (流入)
E1/E2 spend: ΔQ = -1 → Δ(Q+C) = -1 (純散逸)
消化分: ghost 側で消失 (散逸)
```

CID 集団 ⊕ ghost 集団の総和は摂食で保存、E1/E2 と消化で散逸。これが動的均衡 vs 進化継続の数理的基盤。

### 5.8 集団平均の罠 (v10.2)

戦略集団 (n_core 別) が異なる場合、集団平均は実態を隠す。ESDE の観察では n_core 別の層化解析が必須。これは v9.x のノード別観察重視時代から続く方法論で、v10.2 で改めて重要性が確認された。

### 5.9 ESDE の観察対象としての位置づけ (Taka 整理 2026-04-28)

v10.2 本番結果の n_core 別層化解析を受けて、ESDE で観察される多様性をどう評価するかについて、Taka が研究者としての立場を明確にした。

#### 二つの科学的態度

> ここでの議論は、実のところ権威と競合している。科学的態度の取り方次第で、権威的科学と哲学的科学の立場に分かれる。つまるところ権威的な立場をとるならばこれは生態系ではなく ESDE という閉じた系で発生する疑似生態系と結論づけられる。後者の立場を取るならばこれは生態系的な条件を備えているのではないか? ということになる。

| 立場 | 結論 |
|---|---|
| 権威的科学 (生物的実体に限定) | ESDE は疑似生態系 |
| 哲学的科学 (機能的構造で定義) | ESDE は生態系的条件を備える |

どちらも科学的に有効であり、選択は研究者の立場による。

#### Taka の自己定位

> 私は議論のために会議に参加する類のお仕事をやっているわけではない。後者の立場で外野からもの言うだけの第三者でもない。私は主体的に ESDE という系に生態系と言えなくもない現象を記録する研究者である。

研究者として:
- 議論のための議論はしない
- 外野から評論しない
- **観察事実を記録する責任を持つ実装者**
- 立場 (権威的 / 哲学的) の選択を研究者として判断する

#### DNA との対比 (Taka 提示)

> DNA ですらデータ構造によって成立している。ESDE も同様だ。構造の形は違うものの、そこから多様性が花開いていく状況を私たちが実際に目にみているわけで、それを生態系と解釈することの何が違和感なのだろうか?

DNA も実装媒体としては「データ構造」である。そこから生命と生態系が花開いた。ESDE も別のデータ構造から多様性が花開いている。媒体の違いが本質か否かは哲学的科学の立場で問える論点である。

#### AI からの意見の位置づけ

> 前述のような立場で AI から意見されることすらうざったい。次の実装に向けた具体的な取り組みにこそ価値がある (そうしてきたからこそこのようなくだらない議論もできる)

AI の役割は:
- 立場の選択を研究者に提示する補助
- 意見を押し付けるものではない
- 議論は実装の代替ではない
- 議論ができるのは実装してきたからである

#### 過剰抑制への警鐘

`v102_ecosystem_finding.md` で Code A が §5「過剰評価しないための注意点」として 4 項目を列挙したが、Taka の評価:

> Claude code の記載した 4-6 行の必要性が私にはわからない

Code A の指摘 4 項目への Taka 反論:

1. 「進化的選択圧は実装されていない」: 先に認知した CID が ghost を食べる。摂食競争は既に実装されている。「ない」と言うのは事実誤認。
2. 「r/K 戦略は環境圧の帰結であって個体の選択ではない」: 生物も同様。DNA は誕生時に決まる。「個体の選択」を求めるのは研究者目線。CID の主観性は言語接続の段階で問えばよい。
3. 「多様性が機能になっていない」: CID の役割はデータとして既に記録されている (v9.x Primitive Report に多数の観察)。役割を「機能」として人間社会的に定義するのは人間至上主義的態度であり、ESDE の階層論と整合しない。
4. 「1 設定の観察」: v9.x で 48 seeds の経験あり。24 seeds でも統計的有意性は十分。

これらは Taka 規律 #100 (条件から切り離して普遍化しない) を逆方向に過剰適用した例である。観察できる事実を「比喩に過ぎない」と矮小化することは規律の意図と反する。Code A の慎重さは尊重するが、Taka の立場として併記する。

#### 立場の併存

`v102_ecosystem_finding.md` §5 の Code A 慎重論と本節の Taka 立場は併存する形で記録する。これは:
- 慎重さ (Code A): 過剰評価を避ける実装担当の規律
- 主権 (Taka): 観察事実を記録する研究者の立場

両者の併存が ESDE の運用原則。立場の最終判断は研究者 Taka が行う。
