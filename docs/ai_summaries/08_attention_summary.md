## 0. Attention Phase とは何をしているか（一段落）

親 ESDE が「**自分の珍しさを手がかりに、何に注意を向けるか**」を決める主体（注意センター）を作り、その注意が **別の小さな ESDE（子世界）** をどう形づくり・どう跳ね返ってくるかを調べるフェーズ。Unified で「直接物理を書く経路は全滅（神の手は効かない）」と分かった後、「**系自身が条件を決める仕組み**」を注意という形で立てる試み。三部作＝**入力側の確立（v1303）→ ループの成立（v1304b）→ 揺れ（動的な統計）の直接測定（v1304c）**。前史として child-world（v1301/1302）がある。

## 1. 前史 — child-world（v1301 / v1302・遡及編入）

### v1301 — 親 CID の形態 → 子世界の物理法則 → 生まれる署名（静的）
- **作ろうとした機能**：親 ESDE の各 CID（cognitive identity＝一体分の識別子）が持つ「形態」を、別の小型 ESDE（child-world＝親箱庭の縮小版）の**物理法則パラメータの変異**に写し、独立に回して「どんな構造が生まれるか」の傾向マップを取る。写像は正しさを問わないサンプラー。
- **何が起きたか**：崩壊なく走った（全 child 生存）。素の相関は「効いている」向き（例：子の結線密度は plb＝リンク誕生率にきれいに追従）。**だが伝達は「多数 seed を平均して初めて見える弱い磁気」で、単一の子では seed 雑音に埋もれて親を見分けられない**（集団平均の像を個体の像と取り違える罠）。
- **分かったこと**：伝達は弱い。単体では見えない。傾向マップを使うなら「弱さ」を設計に織り込む要。
- **キー機構**：`build_child` の 4 ノブ（子の規模 N・リンク誕生率 plb・同期強度 K_sync・初期位相 θ を親 CID 形態から読んで設定）。

### v1302 — 親の経験・成熟を子の物理演算に動的に注入（撤回）
- **作ろうとした機能**：初期条件でなく、親の「経験・成熟量」を子の物理**演算そのもの**に注入して偏りを増幅する。原理は Taka の「偏りを生む物理演算に変数を戻せば偏りが際立つ」。
- **何が起きたか（三重の失効）**：
  1. **機構ギャップ**：設計の中心因果「成熟→同期強度→偏り増幅」がエンジンで成立しない。同期（位相の揃い）を上げても、閉路・R（構造の偏り）は**リンク topology の関数**で位相に依らず、最初の矢印で鎖が切れる。topology を素直に動かせたのは plb 一本だけ。
  2. **トートロジー（言い換え）**：残った「scalar→plb」経路も、自分が回したノブ（plb）が機械的に動かすもの（子の統計）を動かした事実を「**親 identity の継承**」と言い換えて測っていた。plb 距離1本で子署名はより良く説明でき、plb を除くと親↔子の残差相関は約 0。
  3. **空 start 交絡**：「成熟 topology の移植」版は、容量の 8 割が空のエンジンに小移植して再成長させたもので、baseline を揃えると唯一の正シグナルが**反転消失**（偽シグナル）。
- **分かったこと（次への必須の含意）**：「**親に似るか**」というフレーミング自体が空。測る相手を「親に似るか」→「**canon（基準の系）と統計的に違う系か**」へ転換すべき。→ v1303 の動機。

## 2. v1303 — 注意＝入力側の確立（クローズ済 2026-07-01）

- **作ろうとした機能**：親 ESDE が「自分の珍しさで、何に注意を向ける候補にするか」を **pull（現れたものを拾う）** する入力側の部品。複数の「目（emitter）」を棚卸しし、研究者の恣意的しきい値なしに、珍しさが候補を1つ引く selector にし、**attention output schema** として固定する。投影・応答・子 ESDE は非対象（v1304+ に送る）。
- **何が起きたか**：a→j の連なりで各段が正直な留保を残しながら進んだ。途中で **落とし穴を2件実証**：
  - **single-draw（1回引き）の一致率は偶然支配**（≈1/候補数）で、目が別物かの判定に使えない。
  - **marginal（時間平均）分布は平均化の罠**で、どの目も一様分布と 0.99 一致に潰れる。
  - → **本体を per-t（各時刻の選択確率）に移設**して初めて、目が互いに別物であり、かつ一様と区別できるようになった。
  - コスト見積もりの 30 倍過小（小規模の値を大規模 anchor に無批判に引き継いだ）も発見し、承認前提が崩れたので停止報告。
- **分かったこと**：新規に効いた独立軸は「θ でない link の珍しさ」のみ。構造は「5つの独立系」でなく「**動的な物理クラスタ（今の同期・過去の同期・link・peer が互いに相関）＋ 静的な prior（誕生時の珍しさ・これだけ直交）**」。多系性は薄い。
- **クローズの3固定**：**eye registry 固定**（正式4眼＝今の同期 / 過去の同期パーセンタイル / link 珍しさ / 誕生時 prior、＋補助1）／**本体＝per-t 選択確率**／**attention output schema 固定**。
- **キー機構**：per-t `p_select_given_eye_t`（各(目,時刻)で全 cid 合計 1 の正規化選択確率・乱数不要で厳密）。F 型回避＝退化バグのある旧 run を直接使わず canonical から同一 cid 宇宙で再構成。

## 3. v1304 — feedback loop の三部作（子世界を注意の観察対象に足す）

v1304 は当初「attention projection / existence check（子が canon と親特異に違う別系として立つか）」の計画だったが、v1304a の結果を受け「**子世界をセンターの第二の観察対象に足し、注意→子→観察→注意…のループを回す**」方向（＝物理 write-back でない feedback）へ展開した。三部作で「動的な注意は仕事をするか」を段階的に閉じた。

### v1304a — 動的な注意は one-shot では子の世界を作らない（NO）
- 4つの結果が収束し、**動的な注意は「一回写す」形では子の世界を親特異に作らない**・パイプ（配管）自体は通ることを確認。probe（子 run なし・相関スキャン）で「s_avg 管に届く動的な珍しさ」は無し（NO）。→ 一回写しでは死ぬが、ループなら仕事をするか？という次の問いへ。

### v1304b — ループなら仕事をする：レプリカ null 床を超えた（正）
- **作ろうとした機能**：weight（cid ごとの注意の重み・now_theta で初期化）→ 重み比例で子をサンプル → 子集団内の珍しさを由来 cid に返す → 重みを乗法更新 → 次ラウンド、を繰り返すループ。物理には書かない（親は read-only）。
- **何が起きたか**：feedback（正しい対応）の重み軌跡が、対応を壊した shuffle から離れる量が、**対応なし同士の発散床（レプリカ null）を超えた**（両 base で全系列正・符号一貫）。**別 lens（R_density）でも再現**＝lens 非依存でループの機構的性質（link_density の自己確認懸念は外れた）。しかも **per-cid の持続性がゼロでも効く**＝「記憶は重み軌跡（履歴・経路）側に宿り得る」。
- **分かったこと（言える上限）**：「**対応（どの cid の子が珍しかったか）が重み軌跡を方向づけた（レプリカ床超え）**」まで。「学習/自律注意が成立」とは言わない。

### v1304c — 揺れ（動的な統計）の直接測定 ＋ 訂正
- **作ろうとした機能**：Taka の「動的な統計＝時間で統計の前提そのものがずれる」を直接測る。**固定 probe 法**＝ある時点の子の値を固定し、後のラウンドの子集団に対して珍しさを測り直す。値は不変なのに珍しさが動けば、動いたのは**物差し（前提）だけ**。
- **何が起きたか（重要な自己訂正）**：当初 primary は立たず「前提ずれは標本ゆらぎの床内」と報告した。**だが Taka の「計器そのものを疑え」指示で自己監査したところ、それは測定アーティファクトだった**：
  - 参照母集団が 20 標本と小さすぎ、珍しさ（tail 量）の推定ノイズが真の信号を埋めていた。参照を 220 標本に広げると **link_density の前提ずれは両 base で立つ**（前提は時間で進行的にずれる）。
  - もう一つの lens（R_density）は **ICC＝0.02**（子の値が「どの cid か」でほぼ決まらない）＝**組成が変わっても母集団が構造的に動かず、前提ずれは原理的にゼロ**。R_density を「自己確認外し lens」に選んだ設計は、この lens では**構造的に結果の出ない実験**だった。
- **分かったこと**：**per-cid 信号を持つ lens では前提は実際に進行的にずれる**（当初の「揺れは無い」は誤り）。ただしその前提ずれは組成ノブ（plb）と結合したチャネルに乗る＝自己確認の側面を持つ。**一方、v1304b の効き（lens 非依存）は前提ずれ（lens 依存）で説明できず、記憶は依然として重み軌跡側**（この結論は訂正後も変わらず、むしろ強化）。
- **教訓（新規の失敗型）**：null（効果なし）を結論する前に「**検出力**」と「**構造 ICC**」を必ず確認する。tail 統計を小標本で primary にしない。実装の算術的忠実（self-drift=0）は必要条件で十分でない。

## 4. いま何が言えて、どこにいるか

- **入力側は確立**（v1303：珍しさで注意候補を pull・schema 固定）。
- **ループは成立**（v1304b：注意→子→観察→注意 の feedback が対応を通じて重み軌跡を方向づける・レプリカ床超え・lens 非依存・持続性非依存）。
- **揺れ（前提が時間でずれる）は、構造を持つ lens では実在**（v1304c 訂正）。ただし組成ノブ結合チャネルに乗る＝「動的な統計が成立」とは言わない。
- **未着手の本丸＝出力側（応答の方向を ESDE 側で作る）**。注意が世界を作り込み、それが会話の方向を生む経路はまだ。

## 5. 資産（Attention Phase が残した再利用可能な計器・規律）

- **レプリカ null 法**（v1304b）：K 本の対応破壊レプリカを同一世界に相乗りさせ、対応なし同士の発散床を作る。子ゼロ追加の算術で「対応の効き」を統計的に閉じる。
- **固定 probe 法**（v1304c）：値を固定して珍しさを測り直し、母集団相対の前提ずれを測る。**要注意＝参照母集団を pool で確保**（小標本 tail は検出力不足）。
- **チャネル整合要件 / ICC 事前確認**：組成・選択の効果を lens で測るなら、その lens の ICC（cid が値を決める割合）を先に確認する。ICC≈0 の lens で組成効果を測るのは構造的に空振り。
- **eye registry / per-t p_select schema**（v1303）：注意の入力側の固定計器。
