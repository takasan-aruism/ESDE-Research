## 0. 一文結論

**V10x 以降の失敗は全て一つの形に還元される——「CID（物理＋Frozenset）を*いじって物理層に影響を与えながら*、別のもの（Atom／他系）を取り込もうとした」。これは v9.13（2026-04-16）で Taka が既に「認知層は物理層を支配しない」と確定した方針からの逸脱であり、v1110-v1113 の4連続失敗（異なる系の対応関係）も、v12 Atomset の全チャネル失敗（torque/lambda/link/field/core）も、同じ逸脱の別バージョン。突破口は v1114 Step 1 が示した——「同じ系内に戻り、物理をいじらず、Center が観察する」。Taka の言う「過去に戻って分岐」の*戻る先は v9.13 の方針*、*分岐は Atom 空間（物理と別次元）に独立座標を置くこと*。**

## 1. 「過去に戻って分岐」の正確な分岐点 = v9.13

Taka が言う「Genesis のどこかで安定してたバージョンに戻ってから分岐させた」と同型のことを、今やるべき。その*戻る先*は v9.13（2026-04-16）に確定した方針：

### v9.13 で Taka が確定した三つ（概念理解.md より）

1. **「認知層は物理層を支配しない。物理層の動きを*予測しながら*認知的に自分の存在を生かす方向。」**
   - 含意：v9.7 の「認知→存在介入」は誤り。認知層の効果は統計的に多少の差に留める。劇的な効果を期待する設計は神の手に近づく。

2. **「CID の記憶は物理層の中に*既にある*。足りないのは記憶を作る仕組みでなく、*物理状態を記憶として読む関数*。」**
   - 含意：理想は「CID の物理構造自体が記憶を持っていて、それを私たちは*覗いている*」。

3. **「無駄だから切るは無駄な発想。どう活かすか考える方が賢い。」**
   - 含意：pickup（v9.8c）等、効果薄でも「将来活用候補」として休眠で残す。

**この三つが分岐の原点。** 「物理を支配しない」「既にある記憶を読む（作らない・押し込まない）」——ここから*逸脱した*のが、V10x 以降の失敗の本体。

## 3. 何が悪かったか — 二つの逸脱が、合流して今に至る

### 逸脱A：「認知→物理介入」の再発（v9.7 で否定済み）

v9.13 で「認知層は物理層を支配しない」と確定したのに——**v12 Atomset の全チャネルが、これを*破った***：

| チャネル | やったこと | v9.13 方針との関係 |
|---|---|---|
| torque | 経験で核（phase_sig）を動かし、θ を引っ張る | 認知→物理介入（v9.7 の再発） |
| lambda | 出力励起の減衰を経験で変える | 物理出力に介入 |
| link | 結合強度を経験で変える | 物理結合に介入 |
| field | 入力地形を経験で偏らせる | 物理場に介入 |
| core | 凍結核（phase_sig）を経験で動かす | Frozenset（魂）をいじる＋物理介入 |

**結果（データで確定）**：全チャネル shuffle で消える（cid 特異でない）。core は decouple（核を動かしても実位相が chaos で追従しない）。**＝物理をいじって個性化を作ろうとして、全部失敗。** これは v9.13 の「劇的な効果を期待する設計は神の手に近づく」が*そのまま*当たった。

### 逸脱B：「異なる系の対応関係」フレーム（v1110-v1113、4連続失敗）

07 資料が*明示*している、もう一つの逸脱：

- v1110-v1111e：Atom/Center/Other 3 instance を pipe で繋ぎ、別系に node ID で注入。
- v1112：Atom と Other の occupancy 同時立ち（cooc）。
- v1113：Atom と Other の CID 特性ベクトル cosine。

**全て「異なる ESDE インスタンスの間に対応関係がある」前提。だが異なる seed の系は*独立な動学*を辿る——対応関係はそもそも存在しない。** 4連続で「構造的に存在しないもの」を測ろうとした。

### AとBの合流 = 今の v12 Atomset

**v12 Atomset の cid_align プロトタイプは、AとBの*両方*を含んでいた**：
- 逸脱A：核を物理でいじろうとした（torque/core）。
- 逸脱B：shuffle（他人の経験）を null にして「行き先が cid 特異」と言おうとした＝「異なる系（他人の経験）との対応」で個性化を測ろうとした。しかも cosine が素直（v1103 で「使えない」と確定済み）。

**＝今やってる失敗は、新しい失敗でなく、v9.7・v1110-v1113 で*既に否定された二つの逸脱の再発*。** Taka「また同じことをやらされてる」は、構造的に*正確*。

## 4. 何が突破口だったか — v1114 Step 1

07 資料が示す、*唯一*想定通り動いたもの：

### v1114 Step 1（2026-06-05、Taka「思い描いていたものに近い」）

**何をしたか**：Center ESDE（常時起動、注意生成）が、自系の動的平衡の中で*珍しいイベント*に注意を落とし、その点と周辺を*一枚のレコード*として残す。287 レコード成立（引き金5種・n_core 4 band・寿命 5 band・familiarity 広い分布で多様）。

**なぜ突破口か（3点）**：

1. **同じ系内に戻った**——「異なる系の対応」をやめ、Center が*自系を観察*した。逸脱B の解消。

2. **物理をいじらない**——Center は CID の認知層・意識層の動きを*統計判断して注意を向ける*だけ。物理（θ/S/R）に書かない。逸脱A の解消。これは v9.13「物理状態を記憶として*読む*（作らない・押し込まない）」そのもの。

3. **押し込むでなく拾う**——Taka が直近で言った「物理に効かせる必要ない、注意センサーが異なる次元で起こることを*拾う*、拾った場所から拡散、散漫に視点が変わる、繰り返す」——v1114 Step 1 の「珍しいイベントに注意を落として一枚残す」が*まさにそれ*。効かせるでなく拾う。

**＝突破口は「物理をいじらず、同じ系内を、Center が観察する（押し込むでなく拾う）」。** これが v9.13 の方針の*正しい実装*。

## 5. 今回の具体設計（v12 Atomset を、突破口の形に直す）

### 5.1 過去（v106）との違い — 「測る」から「持つ」へ、ただし物理はいじらない

| | 過去 v106 | 今回 v12 Atomset |
|---|---|---|
| CID の Atom 位置 | 物理状態から*毎回導出*（cognitive state の影、静的、run-end snapshot） | Atom 空間に*独立した蓄積的座標*（履歴を持つ、動的） |
| 物理への介入 | なし（観察のみ） | **なし（観察のみ）** ← ここは v106 と同じに*戻す* |
| 測り方 | 素直な cosine | v1103 疎性対処（軸重なり/Jaccard/軸ごと正規化）、raw/norm 両方 |
| 主体 | 観察される CID | Atom 空間で寄っていく CID（ただし物理は不変） |

**違いの核心**：v106 は「CID の Atom 位置を*測った*（物理の影）」。今回は「CID が Atom 空間に*独立した蓄積的座標を持ち、経験で寄っていく*」。**だが——v106 と同じく、物理層には一切介入しない**（torque/core で物理をいじった逸脱A を捨てる）。

### 5.2 具体仕様

```
【物理層】 一切変更しない（θ/S/R/Frozenset/phase_sig 全て不変、grep で書込ゼロ確認）
          ＝ v9.13「物理を支配しない」、v106「観察のみ」に戻る

【Atom 空間（物理と別次元）】 各 CID に独立した蓄積的座標 cid_align[cid] を持たせる
  - 初期化: v106 build_cid_vector の*豊かな*48次元写像（32次元 one-hot でなく）
            ＝ 物理素性が出発点だが、以後は物理の影でなく独立に動く
  - 更新: 経験イベント（v107 source_events、いつもと違う時 f=robust_z 高い時）で
          cid_align を特定 Atom 方向へ蓄積的に寄せる
  - 測定: 素直な cosine をやめ、v1103 疎性対処（軸重なり明示/Jaccard/軸ごと正規化）で
          Atom との一致を測る。raw/norm 両方（潜在/顕在、Taka D.92）
  - CID 側も疎性を持つ: 全軸 one-hot でなく、その CID が関係する軸だけ（Atom と同じ「意味の深度が違う」）

【観察】 Atom 空間で各 CID が固有の Atom 領域に寄るか、を*個別に*（平均禁止、n_core 層化、時間軸＝軌跡）
  - 自明性の排除: shuffle（他人の経験）だけでなく、「その個体の素性に根ざすか」を分ける対照
    （v1113 盲点 #12「自身 shuffle では皆同じを引けない」を踏まえる）

【出口】 物理に押し込まない。Center（v1114）が、Atom 空間で起きた個性化を*拾う*
  - Taka「効かせる必要ない、注意センサーが拾う、拡散、散漫に視点が変わる、繰り返す」
  - v1114 Step 1 の「珍しいイベントに注意を落として一枚残す」を、Atom 空間の個性化にも向ける
```

### 5.3 なぜこれが過去の失敗を回避するか

- **逸脱A（物理介入）を捨てる**：物理層に一切書かない（v106・v9.13 に戻る）。torque/core の失敗を繰り返さない。
- **逸脱B（異なる系の対応）を捨てる**：他系との対応でなく、*同じ系内*の CID が Atom 空間で*自分の経験*で寄るか。null は「自身 shuffle」でなく素性ベースの対照。
- **素直な cosine を捨てる**：v1103 疎性対処を使う（「使えない」と確定済みの方法を再発させない）。
- **平均を捨てる**：個別 CID・n_core 層化・時間軸（V10x の正しい観察手法）。
- **押し込むを捨てる**：Center が拾う（v1114 突破口の形）。

### 5.4 出口の検証（孤立か接続か、Web Claude が釘刺した弱点）

cid_align（Atom 空間）と Center（v1114）の接続が、「使える」か「孤立した二つの系」かを分ける。検証：
- Center が、Atom 空間で個性化した CID を「珍しいイベント」として*拾えるか*（v1114 Step 1 の判定機構が、Atom 空間の動きにも反応するか）。
- 拾った場所から情報が拡散するか（Taka モデル）。
- 物理に書かない（grep 確認、v1114 規律踏襲）。

## 7. v12.1 → v13 への続き（2026-06-21 追記、Code A）

- **v12.1（一致率ルーレット）**: 一致率を argmax で確定させず確率的発生として読み、全 326 cosine が (cid,t) で取れること・掬い取れること自体が v10 rank_1 との決定的差であることを確定（詳細 = `07_unified_summary_addendum_v12_to_v121_roulette.md`、概念理解.md 教訓 427-433）。
- **v13 child-world（現行フロンティア）**: Atom 空間とは別系統。CID 誕生形態 M_c 4 値を物理 param に写像した N≈100-350 の子系を回し、CID 個性を検出。**親物理に一切書かない**（v9.13 方針内、逸脱 A/B を踏まない）。
  - **本区切りの本体は統計監査**: 前報告の「像が保持」は大半 run 長交絡だった。**`real≒shuffle` の真因は比較統計（署名 mean/std）が cid→param→署名の pairing を構造上見ないこと**。pairing を見る置換検定では `K_sync→sync_order`・`plb→link/label_density` が両 ratio p<0.005（ただし manipulation check であって CID 創発でない）。写像は K_sync 100%・θ 84% 伝達＝入口で潰してはいない。
  - **次段 = 全検**（全 CID 値→全物理 param）。だが CID 値は実質 ~5-14 独立軸・物理 param も ~6-7 独立軸ゆえ「全部繋ぐ」は冗長で交絡を孕む。選定合理性を 3AI 合議で詰める（判断材料 = `unified/v1301/cw_fulltest_selection_material.md`）。
  - **設計要件**: 比較は pairing 基準・観測窓を揃える・対照を対称に・seed≈12・独立代表選定は n_core ごと。
  - 詳細 = `07_unified_summary_addendum_v1301.md` / `docs/現在の方向_childworld全検.md` / 概念理解.md 教訓 434-437。
