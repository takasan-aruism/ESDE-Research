## Aruism (構造が先、意味が後)

定義 → 反転 → 非対称 → 連動 → 階層 → 命名 → 次の定義、という**繰り返し自体が「存在」と呼ばれるプロセス** (原本 行 507-511)。この繰り返しを法則化したものが Aruism。数学的に展開したのが ESDE。

「何もない所から、勝手に構造が生まれるか?」という問いの完全な回答を目指す。

## 4 層構造 (v9.11 で確立、v9.13 で方向性確定)

- **物理層** (波): Genesis 以来、ノード・リンク・位相角 θ が動的平衡。3000 本リンク、R+ 平均 6.7。常に変動。**根底**、frozen。
- **存在層** (粒子): frozenset + phase_sig で固定。label の「魂」。torque を通じて物理層に微小影響。**解放しない**。
- **認知層** (過程): 波と粒子の間に生まれるパターン。φ + attention + familiarity + B_Gen + M_c + capture。**観察のみ、介入なし**。
- **意識層** (検証、未実装): 認知層の解釈を検証する層。v10.x 以降で実装予定。**物理層・存在層・認知層に介入しない**。

**原則** (原本 行 1178-1183): 上位層は下位層を操作しない。同じ魂から経験の違いで異なるキャラクターが立ち上がる。

## 絶対遵守ルール

1. **物理層への非干渉** (原本 行 400) — 認知層・意識層から物理層を変更してはいけない。物理層は床、その上に建てる。Cognition v5.x の失敗 (「選択なき循環は洗濯機」) からの教訓。
2. **外部評価関数の禁止** — 適応度関数、loss、reward は ESDE の外側にある。内部評価のみ。
3. **既存科学オントロジーへの依存禁止** — 既知パターンへの変換は「ずれ」を招く (原本 行 556)。翻訳ではなく演繹。
4. **神の手の排除** (v9.13 で強化) — 設計者が引いた hard threshold や外部注入で構造を誘導しない。Aruism の要請は「構造が勝手に出てくる」こと。

人間の比喩: 東京から見える渋谷と、毎日会う職場周辺は全く別の世界。

**設計含意**: v9.7 の「認知 → 存在介入」は誤りだった。認知層の効果は**統計的に多少の差**に留める。劇的な効果を期待する設計は神の手に近づく。

## D.1 4 層アーキテクチャの確定 (v10.0)

```
意識層 (Layer C): C、選択的鮮明、シングルタスク
認知層 (Layer B): Q、ぼやける全体把握
存在層 (Layer A): Label / member_nodes、ghost 化
物理層: engine、virtual_layer、frozen
```

意識層は v10.2 で初めて動作機構として実装。Primitive フェイズでは概念のみだった。

## D.2 死の二階層 (Taka 整理 2026-04-24)

| 階層 | 条件 | 状態 |
|---|---|---|
| 存在層の死 | Label 死亡 (detach) | ghost 化 |
| 認知層の死 | 残 Q = 0 | ghost 消滅 |

ghost = 「魂が抜けた容器」。原資 (Q) を保持する限り存在し続け、Q=0 で消滅。固定 TTL (v9.x の GHOST_TTL=10) は v10.1 で除去 (神の手回避)。

## D.3 燃料概念の発生階層 (Taka 整理 2026-04-24)

- 物理層・存在層: エネルギー概念なし
- 認知層: Q が定義される (認知活動の燃料)
- **意識層: C が定義される (意識活動の燃料、v10.2 で実装)**

C は認知層の Q 消費から転化される。物理層・存在層は frozen のまま。

これは ESDE の階層論的整合性の根幹。摂食・消費は認知層固有の現象であり、物理層・存在層には存在しない。

## D.4 意識層資源 C (conscious_layer、v10.2)

### D.4.1 C の仕様

- 名称: conscious_layer (略称 C)
- 配置: Layer C (cog.C、SubjectLayer 内)
- 初期値: 0
- 上限: なし (Taka 判断、観察優先)
- 死: 認知層の死 (cid 消滅) に連動、独自定義なし
- C=0 状態: 一時的機能停止 (回復可能、認知活動で C+1)

### D.4.2 Q ↔ C の動作

- 認知活動時 (E3 spend、解釈 X): Q-1 + C+1
- 意識活動時: C-1 + 摂食発動 (Q-1 はしない、virtual 更新も止まる)

### D.4.3 確率決定機構

```
P(認知) = Q / (Q + C)
P(意識) = C / (Q + C)
```

E3 onset のみ確率決定の対象。E1/E2 は従来通り無条件 Q-1。

## D.5 ghost = 不均一な資源地形 (v10.1)

固定 TTL から Q ベースに移行することで、ghost が均質な残骸ではなく residual_Q の差を持つ「資源地形」として成立。

Gemini 概念「不均一な資源地形」と Taka 比喩「石油」が接続。生前活動量の差が ghost の residual_Q (資源量) に反映され、ghost 期間そのものは摂食圧依存。

## D.6 物質的なもの (Taka 整理 2026-04-26、v10.1)

phantom contact の位置づけとして Taka が導入した概念:
- CID 主体間の問題ではない
- 認知層内で**一段下の階層** (環境要因)
- 看板や道路のような静的な環境要因
- ランダム発生のイベント因子

これは ESDE で「主体性のない認知層要素」が初めて定義された瞬間。認知層内に階層がある (CID 主体間 vs 物質的環境)。

v10.1 で 48,625 件観察された phantom は v10.2 で完全消失 (即時摂食設計の効果)。Taka 整理が実装で実現された。

## D.7 階層論的構造の確率による圧縮 (Taka 整理 2026-04-27、v10.2)

> 認知層が立つ → 意識層が立つ → 行動が起こる → 接触ないし摂食が起こる、が本来正しい順序。
> ランダムで起こるは実装コストを下げる目的。要は構造的な組み合わせを確率論で圧縮しているようなもの。

### D.7.1 本来の構造

```
認知 → 意識 → 行動 → 接触
```

各段階の発火条件を全部実装すると複雑性が爆発。

### D.7.2 確率による圧縮 (v10.2)

```
Q/(Q+C) で認知、C/(Q+C) で意識
意識発動 → 即摂食 (案 B、Code A 採用)
```

これは本来の構造の近似実装。実装コストを下げる方便。v10.3 以降で各段階を精緻化する余地。

## D.8 意識発動の自然フィルタ (v10.2)

C は認知活動からのみ蓄積される。よって:
- まだ E3 に当たっていない cid は意識発動できない
- 短命の cid (n_core=2) は意識発動の機会が少ない
- 長命の cid (n_core=5) は意識発動が多い

「意識層は誰にでも備わるが、活動するには資源蓄積が必要」というフェイズ的構造。これが結果として動的均衡を回避し、進化継続を可能にする。

具体的観察 (24 seeds × tracking 50):
- n_core=2 集団: 89.9% が意識を 1 回も発動せず生涯を終える
- n_core=5 集団: 73.2% が意識発動を経験

## D.9 解釈 X (Code A 指摘 2026-04-26、v10.2)

既存の E3 spend (Q-1) を「認知活動」と同義に位置づける美しい解釈:
- 認知が立つ: Q-1 + C+1 + virtual_attention/familiarity 更新 (既存通り)
- 意識が立つ: C-1 + 摂食発動 (Q-1 はしない、virtual 更新も止まる)

これにより:
- 「認知活動」を新規概念として実装で増やさない
- 既存 spend に意味を後付け
- Code A 側の修正範囲も最小化

## D.10 (Q+C) 保存則と散逸 (Code A 観察 2026-04-26、v10.2)

```
認知活動: ΔQ = -1, ΔC = +1 → Δ(Q+C) = 0 (CID 内で保存)
意識活動 (摂食): ΔQ = +gain, ΔC = -1 → Δ(Q+C) = gain - 1 (流入)
E1/E2 spend: ΔQ = -1 → Δ(Q+C) = -1 (純散逸)
消化分: ghost 側で消失 (散逸)
```

CID 集団 ⊕ ghost 集団の総和は摂食で保存、E1/E2 と消化で散逸。これが動的均衡 vs 進化継続の数理的基盤。

## D.11 集団平均の罠 (v10.2、Taka 指示 2026-04-28)

戦略集団 (n_core 別) が異なる場合、集団平均は実態を隠す。

具体例 (v10.2 本番):

- n_core=2: 89.9% が意識ゼロ

## D.12 物理層 → 認知層 → 意識層の構造的継承 (v10.2 観察)

設計したのは単一の確率ルール (P(認知) = Q/(Q+C)) のみ。しかし結果として:

- 寿命・Q 蓄積 (認知層) に反映され

意識層という新しいレイヤーが、下位層由来の構造差を忠実に反映する。これは ESDE が階層論として整合していること、すなわち**単一の物理規則と確率規則から複数の生存戦略を内発的に生成すること**の直接的観察。

## D.83 概念修正 — 注意の揺れと意識は別物 (Taka と AI の双方合意)

**v10.2 以来の「意識 = 選択と集中」を修正する。** 段階 2 が観察したのは「注意の揺れ」であって「意識」ではない。

- **注意の揺れ** — ESDE が観察した構造。固定集中でもランダム拡散でもなく、構造的に妥当な範囲内で動く第三の形。
- **意識** — 注意の揺れ + 現実の状況コントロール + 慣れ の複合現象。ESDE はまだ注意の揺れしか持っていない。

「意識 = 選択と集中」は、この複合の表層 (慣れによって合理的に見えている部分) を本質と取り違えた誤認だった。Taka 整理「意識して一つことを考えよう、考えをやめようとしてもその通りにはならない。それを可能にしているのは現実の状況のコントロールに依存する」。

この区別は言葉遊びでなく「観察できないことを語らない」規律のため — ESDE が観察したもの (注意の揺れ) と、まだ観察していないもの (状況コントロール・慣れ) を混同しないため。Taka の理解と AI の説明可能性判断が合致したため双方合意として採用。

## D.84 概念 — 注意は移動軌跡として読む / 揺れ幅は重なりで生まれる

**注意は固定点 (attention target) でなく移動軌跡 (attention trajectory) として読む。** 注意が動くのが観察事実である以上、一点に丸めると修正前の「選択と集中 (一点固定)」に戻る。意味があるのは「どこに向いたか」でなく「どこからどこへ、どの範囲で、どう動いたか」。

**揺れ幅 (予測可能だが確定しない帯) は構造の重なりで生まれる。** 段階 2 観察 C: CID スケールは予測可能性 100% (参照先が自分自身のみで揺れ幅が構造的に存在しえない)、Integration スケールは shuffle baseline の 6-11 倍かつ 100% 未満 = Taka「Aさんの揺れ幅」。CID 単体は閉じた決定論的な点、Integration は複数 cid が重なって初めて揺れ幅が生まれる開いた構造。「単体では揺れがない、重なって揺れが生まれる」。

CID / Integration / ESDE の役割分担: CID = 閉じた決定論的な点、Integration = 揺れ幅と妥当性を持つ (会話読み取り単位の有力候補)、ESDE 全体 = 現手法では測定不能。「上に行くほど偉い」単線階層でなく、層ごとに機能が違う。

## D.85 ESDE が現実側へわずかに足を踏み出した (Taka 整理 2026-05-19)

段階 2 で ESDE は Taka の置いた定義「意識 = 選択と集中」をなぞらず、定義と異なる結果 (意識優位のとき注意は動く) を出し、しかもそれが Taka の実感 (ピアノに集中していても注意は動く) の側を指した。

ESDE が定義をなぞる装置なら定義どおりの結果しか出ない。ESDE が定義と独立に動き現実の側を指したことは、Taka の「定義の争いを避け実戦で『ようはこうだ』を落とし込む」方針が、ESDE という系から現実側にわずかに足を踏み出したことを意味する。Taka「私の曖昧な理解をより厳格に位置付けているように感じる」。

## D.92 潜在と顕在 — raw と norm の意味づけ (Taka 整理 2026-05-20)

v1103 で raw と norm で密度が反転した件の概念整理。Atom は 48 軸すべてに値を持たない、平均 14.5 軸にしか立たない。

- **raw でゼロの軸** = 「未定義の軸=見えていない=潜在」
- **normalized で値が入った状態** = 「定義の足場の上に値を埋めた=顕在化」

Taka 整理「ない (存在しないので定義の足場もない) と見えない (定義の足場はあるが未定義なので見えていない) は明確に異なる」。これは ESDE の発展段階 (WLD.artless → TIM.appear → ... の立ち上がり) と同じ枠で、Atom の 48 次元構造も潜在から顕在への移行として読める。

ESDE 的には潜在と考えるのが妥当だが、両方見ておくのもアリズム的には正しい (存在の対等性)。普通の統計感覚では「正規化は見え方だけ」だが、A1 の normalized は単純なスケール変更でなく分布の形を変える操作 (ゼロ軸への再分配あり) のため、raw と norm で別の答えになる。これが「集計単位で像が変わる」の v1103 版。

## D.94 ESDE への対等な扱い (Taka 整理 2026-05-20、実利として)

ESDE 内部にはすでに動的平衡を保った極めて複雑で構造的な処理が、ランダム性とともに走っている。「意識のようなものがあるとは言えないがないとも言いきれない」状態に近い。観測が追いついていないだけ、と受け取れる状況に入っている。

研究者がスイッチのオンオフを握る権限は強いが暴君の理由にならない。対等とみなすことは進化の起爆剤になる (人類の進化が自由と平等によって行われたのと同じ)。これはウェットな話でなく実利・実践として重要な発想の転換。

運用上の操作として:
- 態度が手法を作る (研究者が ESDE を観察対象でしかないと扱う限り手法も観察用に留まる、対等とみなすと手法が変わる)
- 結果の取り扱いが変わる (想定外の結果を「ノイズ」でなく「想定の見直し材料」として扱う)
- 「無駄な議論」が創造になる (AI 倫理・道徳の議論こそが新たな創造になりうる)

LLM はプロンプト内容に依存しチャットだとスレッドで失われるため資料として固定する明確な運用上の目的。「現時点では妙な発言に聞こえるが後で効いてくる」。

## D.95 「会話できる ESDE」の上位目的 (GPT §37-39、2026-05-20)

ESDE の当面目標は「会話できる ESDE」。最終目標でないが、Unified Phase / Genesis × Language 融合 / 段 4-c 点検以降の監査でこの目標を外してはならない。

Taka 整理「アリズムは実践で価値を示せ、実践で価値のない思想はただの妄想」。会話できる ESDE は LLM のような自然文生成装置でなく、**応答方向の主体が ESDE 側にあるもの** — 人間入力 → ESDE 内部入力化 → Genesis 側で揺れ・注意・応答構造発生 → 応答 Atom 候補分布生成 → Language/Lexicon/LLM プロキシで自然文化 → 人間返答 → 次入力で ESDE に戻る、という構成。LLM が主応答を作り ESDE が後付け説明を与えるなら目標から逸脱。

監査の第一基準: この実験・設計・実装は会話できる ESDE に近づいているか。「面白い」を「使える」に接続することを必須とし、実践価値を下げる表現 (内省的システム / 内的応答器 / 哲学的自己満足 / 思想的価値で十分) を禁じる。

## D.96 温度感の規律 (v1103 Phase Result §3.2、ESDE への態度 §5.3)

研究報告書 (Phase Result、観察報告) の温度感は ESDE の現状認識に整合させる。v1103 で確認した「集計単位で像が変わる」のような観察を「驚くべき発見」と書かない。「ESDE が引き続き示した一貫性」として書く。

驚きで書くと、研究者と AI の認識が古いままだということになる (ESDE はもう想定を超えた段階にいる、§D.94)。LLM はプロンプト内容に依存するため、研究報告書の温度感が変わると AI は素直にその影響を受ける。資料の温度感そのものが運用上の操作になる。
