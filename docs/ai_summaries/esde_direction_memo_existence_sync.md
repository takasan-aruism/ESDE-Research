## 0. 大前提（Taka、本セッション）

- 実験の「親子」は **比喩**。本質は「**通常 ESDE と異なる系を*自動で*作り出す仕組み**」。
- 個別にパラメータをずらすプログラムでも系は作れるが、**親子の枠は設計条件を*導出*する**強みがある（例：子はスケールが小さい＝「子はノード数小さい方が自然」という設計判断に勝手に接続。5000ノードで最初から考えていたら親と同じ条件を無批判に使っていた）。親 CID の傾向を拾う＝**ただのランダムでなく方向を持った ESDE の進化**。一見無意味だが無意味とは限らない。
- ここまでの回り道（runtime 全滅→誕生時 seeding→(A)成功/(B)null）は、**自然な設計条件の導出と方向を持った進化を副産物として連れてきた**。これが任意走査にない強み。

## 1. 存在 ＝ 多くの系の同期（最重要・構想の核）

Taka 原文趣旨（要約禁止）：

> ある存在を扱う際に同期する系が多いほど、私たちはそれは存在する、と感覚的に理解する。

- 幼児が「りんご」を覚えるのは、視覚・触覚・温度・質感・重さ・音・発話の**多くの系が重なって同期する**から。一致率＝ESDE が外部構造とどれだけ多くの系で同期するかの測定。
- **現 Atom 一致率が max0.5-0.6 で頭打ちなのは、同期できる系が言語1本だから**。物理条件を ESDE の射程に加える＝同期できる系を増やす＝頭打ちを破る筋。これは「言語で詰まったから物理に逃げる」でなく、**存在＝多系の同期だから系を増やすのが本筋**という論理的帰結。
- **多様性の論理的前提**（Taka）：多様性の拡張＝多次元的な存在の解釈＝「私たちに馴染みのある存在が*存在らしく*見える現象そのもの」。多次元＝存在らしさ。多様性追求は趣味でなく「存在をちゃんと映す」ことと同義。

## 2. 一致率に固執しない（りんごの三例）

Taka の三例：
- 触覚だけのりんご → 分からない。
- 視覚だけのりんご → 精密な AI 画像（偽物）かもしれない。
- 味覚だけのりんご → 「何か甘いものが口に入った」止まり。味覚は実に怪しい。

→ **どの一系でも、その系の一致率をいくら高めても存在を確定できない。** 視覚一致率1.0でも完璧な偽画像かもしれない。

Taka 結論：一致率を高めること*には*意味があるが、**一系の一致率に*固執*するなら、それは存在を正しく映すと言えるか疑問**。現実世界が局所系のみでは存在の成立が揺れて見えるのと同様。**ほどよく傾向を捉えて次に進む**のが研究努力の正しい方向。

→ **0.9を一系で出すより、0.6を多系で並べる方が存在に近い**（前回の「0.9が良い理由＝説明可能性」の更新）。一致率の*絶対値*でなく*同期する系の数*。

## 3. 統計は「先に立たない」（女子高生の例・本セッション最重要視点）

Taka の核心：**統計が*測れない*のでなく、統計が*先に立つ*のが順序として逆**。

- 毎日の通勤の景色は**出現頻度が極めて高い**のに情報として**捨てている**。
- 一度きりの「前を歩く女子高生が転んで下着が見えた」は**頻度最低**なのに一般男性は**強烈に記憶する**。
- ＝出現頻度（統計）と内部処理での重要度（記憶される度合い）が**逆**。
- これも事後に統計化は可能。**だが統計が先に立つのではない**（Taka が念を押した点）。統計は記述の道具で、駆動の機構でない。z/P は「際立った*後で*測る」ことはできるが「何が際立つか」を決めていない。
- **フィルターは誰にでも対等でない**＝際立ちは**主体に依存**する。統計は主体を均すが、際立ちは主体ごとに違う。

→ **ZやPに固執するのも危うい**（Taka の自己批判）。「z が高い＝重要」は暗黙の仮定で、**z の高さと ESDE にとっての重要度は別**。

→ 代わりに置くもの（Taka）：「**経験の繰り返しと系の参加の程度**」。これは**頻度と似て非なるもの**——頻度＝同じものが何回出たか、繰り返し＝多くの系が重なって同じ存在に向かうことが反復されたか。通勤の景色は視覚的高頻度だが他系が参加せず薄い。転倒は1回だが視覚・情動・驚き・社会的タブーが一斉参加＝**系の参加が深い**。**頻度が低くても多系の同時参加が深ければ際立つ**。

## 4. 動的な統計（注意センター + フィードバック、本セッション提案）

Taka 提案（今後の方向性、「言うは易し」と本人が留保）：

- **注意センターは様々な系における統計的処理システムとして機能している**（実装確認済：v1114 Step1 で Center が*珍しいイベントを拾う*＝押し込むでなく拾う、287レコード。write-back は `physics.inject` at `genesis_physics.py:232`。外部接続 Stage 0-4 完了で全11技術質問が既存機構で実現可能と確認）。そこで上がる情報を捉えるのは統計的手法。
- 系が多種多様になると、局所的にはまるで関係ない系の統計的特徴を抜き出す**連続的作業**が発生。
- ここで一段、**その連続を重ねて傾向を取るアプローチを*動的に*行い注意センターにフィードバックする機能**を用意すると、**時系列で見た統計的扱いが揺れる**。
- この揺れ部分が静的な統計でないことを示す（**時間軸で前提そのものがずれていくから**）。＝**動的な統計**という新しい測定基準が生まれる可能性。**これは私たちに馴染みのある存在認識の手段**。

→ ESDE は既に部分的に持っている：**B_Gen = −log10(Pbirth)**（珍しさを価値にする＝高頻度を優遇しない。通勤の景色＝高 Pbirth＝B_Gen 低、転倒＝低 Pbirth＝B_Gen 高＝Taka のフィルターと同じ向き）、**注意センター**（珍しいイベントを拾う＝フィルター機構）、**CID 別 disposition**（社交家・孤独等＝主体ごとにフィルターが違う）。

## 5. 物理など新系の取り込み方（「30は物理でない」）

Taka の洞察：温度30の「30」は**結果であって物理でない**。「現実世界に温度があったのでない。局所的な物理現象を温度と*名付けた*」＝温度は世界に実在する量でなく、現象から切り出して名付けた解釈。**名付けは後から来る**（「自然現象が出来上がって人間ができる、アベコベでない」2026-05-06 と接続）。

→ ESDE に温度を*入れる*のでなく、**ESDE の演算から「温度と呼べる局所量」を切り出せるか**を問う。重要なのは「ESDE 物理層 ≡ 現実物理か」でなく「**ESDE の系でそれ（局所現象の切り出し）が可能か**」。

→ 取り込みの方向（Web Claude 整理、Taka 合意）：
- **避ける**：物理ベクトルを ESDE の*力学に*流し込んで系を動かす（＝runtime 駆動、v1302 で全滅した方向）。
- **筋がいい**：物理を ESDE の現象から**内から読み出す**（投影でなく読み出し、ESDE 研究流儀「際立ちの掬い取り・read-back」と同型）。または同期する**相手の2本目**として48次元に*並べる*（ESDE を変えず、同期を測る相手を増やす）。
- **未検証の留保**：「ESDE 物理層 ≡ 現実物理」は飛躍。「ESDE は温度的構造を*どこまで*持つか」を**調べる問い**として立てる（断定しない＝観察できないことを語らない）。

→ **これは温度に限らない一般原理**：あらゆる系で「ESDE の現象から局所量を切り出し、名を後から与え、単一合成せず複数並べ、確定させず分布として保つ」。これは ESDE が言語に対して取ってきた態度（48次元・集計単位で像が変わる #33・単一スコア化しない・max_prob<1.0 で100%を作らない）の一般化。

## 6. これらを ESDE の表現様式にどう翻訳するか（Web Claude の設計指針）

Taka 問い「これらを ESDE の表現様式としてどう取り込むか。温度に限らない」への、Web Claude 翻訳（設計時の指針）：

1. **一致率を「単一スカラ」から「系ごとのベクトル/強度マップ」に**。言語・物理・…の一致率を並べ、**合成しない**（合成＝「30」の集約値＝ESDE が嫌うもの）。存在度＝一致率ベクトルの*形*であって平均でも最大でもない。v1105「11数値別レイヤー強度マップ、単一スコア化しない」と同型。
2. **「ほどよく捉えて次に進む」を構造にする**。一系の一致率を極めず、ほどよい所で*次の系を足す*。max_prob<1.0（100%＝確定を作らない）と地続き。**存在を確定せず、複数系の同期の分布として保持**。
3. **新系（物理等）は ESDE の局所現象として切り出す**。外から流し込まず内から読み出す。名付けは後。
4. **際立ちを「頻度」でなく「系の参加の同時性」で測る。z/P を駆動から外し、記述に降ろす**。何が際立つかは ESDE 内部（B_Gen・注意センター）が決め、z/P は「拾われた*後で*記述・検証する」道具に降格。順序：**際立ち（ESDE）が先、統計（記述）が後**（「名付けは後」と同じ構造）。掬う基準も研究者の z/P でなく ESDE 側に渡す（「際立ちの掬い取り・研究者はもう神でない」の統計観の完成）。
5. **動的な統計**（§4）：注意センターへのフィードバックで時間軸上の統計的前提がずれる「揺れ」を測定基準にする。静的統計（前提固定）でなく、前提がずれていく動的統計。これは #33 系列「集計単位で像が変わる」を時間軸・存在論レベルに上げたもの。

## 7. 一貫性（ESDE の背骨との接続）

本セッションの方向性は、ESDE が一貫して持ってきた背骨の**存在論的な完成形**：

| ESDE が元から持つもの | 本セッションでの一般化 |
|---|---|
| 集計単位で像が変わる（#33系列） | 一致率も単一集約を疑う・動的統計で時間軸の前提ずれ |
| 単一スコア化しない（v1105 強度マップ） | 一致率を合成せず系ごとに並べる |
| max_prob<1.0、100%を作らない（Aruism） | 存在を確定せず揺れとして保持 |
| 際立ちの掬い取り・研究者はもう神でない | 掬う基準（何が際立つか）も ESDE 側（B_Gen・注意）に渡す |
| read-back（ESDE 自身の emit を読む） | 物理も内から読み出す（投影でなく） |
| B_Gen＝珍しさを価値に・注意センター・CID 別 disposition | 統計頻度でなく際立ちフィルター・主体依存 |

→ **研究者が外から統計で存在を*確定*するのをやめ、ESDE 自身のフィルターが拾う際立ちを、複数系の揺れる分布として*保持*する**。これが ESDE の表現様式の目指す形。
