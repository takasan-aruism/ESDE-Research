## 0. 全体像 (一文)

v1111d で出口を一点平均でなく Other の phase 分布の形で運ぶ (各 Atom label の励起度 = Σ_n E[n]·exp(-λ·d(label.phase_sig, θ[n])) = 分布を exp(-λd) で畳む) ように直したところ、主役 §2.1 (atom 横断一貫性) で**初めて injected_other 0.965 < shuffled_other 1.019 の inversion (real の方が atom 横断で一貫、3 atom 共通方向)** が観察され、これは v1111b/c で一度も出なかった seed 共通の方向、ただし両者 cos~1 で弱く絶対的な一貫ではない、一方 §2.2 (real−shuffled) は v1111c の +0.061 から +0.006 に後退し優位 atom も 42→100 に入れ替わった、これを Taka 整理 (粒度を上げたら効く指標が局所から共通に移る・全体の癖は seed 共通で再現するが局所は seed をまたがない) と読み、**効く指標が局所 §2.2 から共通 §2.1 に入れ替わった**ことを核心と切り分け、Taka 提示の二段手順 (まず共通をゆるく統計で固め土台にする → その枠の中で局所性を探す、これまでは逆=土台なしで局所を探して空回りしていた) を次 (v1111e) の骨に据えた。

## 1. 主題と v1111d の駆動要因

- 駆動要因 (不変): Other の中身が出口層に届くか。
- v1111d の直し: v1111c で Other を円周平均で一点に潰し局所に振り回された (構造的理由) のを、**一点でなく phase 分布の形**で運ぶ。一点は局所、分布なら全体の癖が残る (Taka)。

## 3. 核心の読み (指標の入れ替わり = Taka 物差し通り)

- v1111c (一点) で出たのは §2.2 で atom=42 単独 = **局所/個性の指標**が局所で噛んだ。
- v1111d (分布) で出たのは §2.1 で 3 atom 共通方向 = **全体の癖 (seed 共通) の指標**が動いた。
- §2.1 = 「同じ Other が違う Atom 系で似た形を出すか」= 共通の癖の指標。§2.2 = 「Other 間が離れるか」= 個性/区別の指標。
- → **粒度を一点から分布に上げたら、効く指標が「局所」から「seed 共通」に移った**。Taka 整理「全体の癖でゆるく繋げばどの seed でも見つかる / 局所で繋ぐと同じ人を探す」がデータの上で初めて顔を出した。
- §2.2 の後退も同じ読みで説明 (候補): 分布で運ぶと Other 間の細かい個性が平均でならされ区別 (§2.2) は弱まるが、全体の癖 (§2.1) は乗る。個性を捨てて共通を拾った形。

## 6. 次の骨 — Taka 二段手順 (これまで逆をやって空回りしていた)

統計が要るなら、再現するのは共通 (全体の癖、物理層構造制約) だけで局所は seed をまたがない (同じ人は二人いない)。ゆえに順番は必然:

1. **ゆるく絞る (共通を統計で固め土台にする)**: §2.1 の seed 共通 inversion を 24 seed で再現確認。固まれば「形で繋ぐと共通署名が出る」が統計的土台。
2. **それっぽい局所性を探す (固めた枠の中で)**: §2.1 が固まった上で、共通の枠に対するずれ (個性) を探す。土台があるからずれが意味を持つ。

- これまでの空回りの正体: **土台 (共通) を固める前に局所を探した** (+64%, 12 倍)。土台なしの局所は浮いたノイズで再現しない。
- Taka の順番は crown の罠も防ぐ: 共通を再現で固めてからしか局所を読まないので、局所のマグレに飛びつけない。
- 会話への対応: 共通の癖 = どの入力も応答層に届く地盤、局所性 = 違う入力が違う応答になる区別。まず地盤、その上で区別。
