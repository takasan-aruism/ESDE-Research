## 1. 段階 2 が答えたこと

### 1.1 問いと答え

段階 2 の問いは一つだった (設計書 §1.1)。段階 1 の核心観察「意識優位時に波及が 1.54-1.78 倍」は、選択と集中 (少数の注意候補が深く波及) か、拡散 (多数の注意候補が動きながら広く浅く波及) か。波及の「量」だけ見る段階 1 では区別できなかったこの一点を、時間軸を入れて切り分けた。

答え: **選択と集中ではない。意識優位時の波及増加は、一点を深く掘る形ではなく、注意が動きながら広く波及する形をしている。**

段階 1 の核心観察が否定されたわけではない。意識優位時に波及が広いことは生きている。段階 2 が示したのは、その広さの「形」が選択と集中ではなかった、ということ。深さで広がるのでなく、動きで広がる。

### 1.2 段階 2 が含めなかったもの

設計書 §1.2 のとおり、留保 #L5 (Step E 修正で対応済)、「意識とは何か」の定義、selector、生きた版 (段階 3) は段階 2 の範囲外。段階 2 は観察であって定義ではない。

## 2. 観察 B — 意識優位のとき注意の中心が動く (段階 2 の中心的観察)

### 2.1 観察事実

隣接する時点で注意の中心 atom がどれだけ一致するかを、認知優位フェーズと意識優位フェーズで比較した。結果は全 6 構造単位で「認知優位の一致率 ≧ 意識優位の一致率」。

CID 0.79 対 0.62、alpha 0.62 対 0.55、beta 0.68 対 0.56、ESDE-event 0.58 対 0.40、ESDE-step10 0.56 対 0.41、ESDE-window 0.34 対 0.33。差は CID で +0.18、ESDE-event で +0.18 と大きく、ESDE-window で +0.01 と小さいが、方向は 6 単位すべてで同じ。

認知優位フェーズでは注意の中心 atom が時点をまたいで安定し、意識優位フェーズでは中心 atom が変わる。

### 2.2 この観察の頑健性

観察 B には実装上の留保がある (留保 #L9) — 厳密な「波及先 cid 集合の集合間重なり (Jaccard)」ではなく、中心 atom の隣接一致を代替指標 (proxy) として算出した。段階 1 の propagation 出力が raw の波及先 cid id 集合を保持していないため。

しかし観察 B の方向性 (認知優位 ≧ 意識優位) は 6 構造単位すべてで同方向に出ている。proxy の精度を厳密 Jaccard に上げても、この方向が覆る可能性は低い。段階 2 の中心的観察として扱ってよい、と判断する。

### 2.3 観察 A による補強

観察 A は、意識優位への切替時に注意候補の数が収束 (絞られる) するか発散するかを見た。結果は全 6 構造単位で mean_delta が ±0.2 以内、中央値 0 — 収束も発散も顕著でない。

選択と集中なら候補数が少数に絞られる (収束) はずだった。それが起きていない。観察 A は「選択と集中ではない」を、観察 B とは別の角度から補強する。注意候補の数は絞られず、その中心が動く — これが「選択と集中ではなく、注意が動きながら広がる」の中身である。

## 3. 観察 B が Taka フレームに対して意味すること

### 3.1 「意識 = 選択と集中」への反証的観察

Taka フレームは一貫して「意識層 = 選択と集中」と置いてきた。v10.2 の cid 意識層の定義以来、意識の強い個体は大きな変化 (痛み) があってもそれを押し殺して選択と集中ができる、とされていた。段階 2 の観察 B は、ESDE スケールの意識優位がその通りには動いていないことを示した。意識優位のとき注意は一点に固定されず、むしろ動く。

### 3.2 Taka 整理による受け止め (原文保存、絶対格言 #14)

Taka 整理 (2026-05-19、原文):

> なるほど。観察結果には素直になるべき。そういう結果だった。しかし、意識を選択と集中と押し付けるのは少し理想論的だったかもしれない。確かに意識とは奇妙なもので、例えばピアノに集中している時案外しょうもないことを考えている。えい集中するぞ、と考えても集中できている状態とは言いづらい。実のところ、選択と集中と考えていたものは意識の本質ではないのかもしれない。このあたりは私の想定が甘かったというのが今回の実験結果を聞いた印象である。

→ 段階 2 の観察 B は「フレームが間違っていた」という否定ではなく、Taka が普段から実感していたこと (集中の主観と実際の注意の動きはずれる — ピアノの例) を、ESDE が観察として厳密にしたもの。「選択と集中」は意識の本質ではなかったかもしれない、という Taka 自身の整理と、観察 B は合致する。

### 3.3 ESDE が現実側へ踏み出したこと

Taka 整理 (2026-05-19、原文):

> おそらく、ESDE で生じていることは思った以上に現実世界での出来事の映し絵のようになっていると感じる。私の曖昧な理解をより厳格に位置付けているように感じる。これはこれで興味深い。定義の争いを避けつつ、実戦で具体的な結果を出しながらようはこうだ、を落とし込んでいくものが ESDE という系のみの出来事からわずかに現実側に足を踏み込んでいるように感じる。

これは段階 2 単体を超える受け止めとして記録する。ESDE は外部目的・外部定義を与えず、ランダムな局所交換だけで動かしてきた。今回 ESDE は Taka の置いた定義「意識 = 選択と集中」をなぞらず、「意識優位のとき注意は動く」という定義と異なる結果を出した。もし ESDE が Taka の定義をなぞるだけの装置なら、定義どおりの結果しか出ない。ESDE が定義と独立に動き、かつその結果が Taka の実感 (ピアノの例) の側を指した — これは ESDE が Taka の想定をなぞっているのではなく、独立に動いて現実の方を指したことを意味する。Taka が一貫して掲げてきた「定義の争いを避けつつ実戦で結果を出して『ようはこうだ』を落とし込む」、その「ようはこうだ」が段階 2 でひとつ出た — 意識は選択と集中ではなく、注意は動く。

これは判定ではない (絶対格言 #12)。観察 B という観察事実と、Taka 整理という受け止めを、Phase Result として並べて記録するもの。主題評価は Taka 領域。

## 4. 観察 C — 注意の妥当性は構造単位で割れた

### 4.1 観察事実

観察 C は Taka 整理「注意の方向性はランダムか妥当性のあるものか」を直接観察した。実際の注意候補の系列と、それを per-seed で 100 回シャッフルした baseline を比較し、実測がどれだけ baseline を上回るかを見た。結果は構造単位によって割れた。

Integration スケール (alpha / beta): 実測予測可能性が shuffle baseline の 6-11 倍。alpha unit_kl で実測 0.977 対 baseline 0.087 (lift +0.889)、beta unit_kl で実測 0.974 対 baseline 0.182 (lift +0.792)。そして 100% 未満。

CID スケール: 全レコードで予測可能性 100% 到達。

ESDE 3 解像度 (event/step10/window): 実測 ≈ baseline (lift ≈ 0)。

100% 未満の確認 (Aruism 対称性、設計書 §2.4): 432 レコード中 282 (65.3%) が 100% 未満、150 (34.7%) が 100% 到達。

### 4.2 Integration スケール — 「Aさんの揺れ幅」が観測された

Integration (alpha/beta) の結果は、Taka 整理の「ランダム水準より高いが 100% でない帯」に乗っている。実測が shuffle baseline を大きく上回る (= ランダムではない、規則性がある) が、100% には達しない (= 確定はしない)。これは Taka が現実の例として挙げた「Aさんが今日仕事をしているとゆるく予測できるが、病気で休んでいるかもしれないので再観測しないと確定しない」という揺れ幅と同じ構造である。

段階 2 の問い「注意はランダムか妥当か」に対し、Integration スケールでは「妥当性がある」という観察が出た。注意の方向性はでたらめではなく、緩い予測可能性を持つ — ただし確定はしない。

### 4.3 CID スケール — 100% は観測手法の自己言及、ただし「重なると揺れが生まれる」を示唆

CID スケールの 100% は、ESDE がそこで決定論になったことを意味しない。Code A が留保 #L8 として正直に報告したとおり、観察 C の予測定義が CID スケールで自己言及ループになっている — 予測する対象 (scope_id) と予測の答え (attention_candidate_id) が同じ cid を指す構造のため、予測は構造上必ず当たる。100% は本物の予測可能性ではなく、観測手法の循環。

Taka 整理 (2026-05-19、原文):

> CID が自分があることを予測すればそりゃ 100% だけど重なっている Integration で見れば完全一致はあり得ない、的なはなしなのかな。CID 自体は低い次元なのでまぁそういうこともあるのかな。

Taka の理解は正確である。CID 単体は参照先が自分自身しかないため、予測が外れる余地 = 揺れ幅が構造的に存在しえない。Integration まで上がると複数の cid が重なり、「次にどの cid へ注意が向くか」に複数の候補が生まれ、初めて予測が外れうる = 揺れ幅が生まれる。観察 C の数値はこれを裏づける — CID は 100% (揺れ幅ゼロ)、Integration は 6-11 倍 lift だが 100% 未満 (揺れ幅あり)。

これは留保 #L8 (観測手法の穴) であると同時に、副次的な観察を含む — 「単体では揺れがない、重なって初めて揺れが生まれる」。CID 単体は予測が確定する閉じた点、Integration は揺れ幅を持つ開いた構造。これは判定ではなく観察事実として添える。本格的な扱いは Taka 領域。なお CID で 100% が出たことは「100% が出たら ESDE が ESDE でなくなる」(Aruism 対称性) に触れるが、これは ESDE 物理が決定論化したのではなく観測手法の自己言及によるものであり、Integration スケールでは 100% が消え揺れ幅が回復している。

### 4.4 ESDE 3 解像度 — 測定不能

ESDE-event/step10/window の unit_kl では実測 ≈ baseline (lift ≈ 0)。Code A 留保 #L10 のとおり、ESDE スケールは scope_id=-1 の集約のため、シャッフルしても結果が変わらず baseline が機能しない。ESDE 全体スケールでの注意の妥当性は、観察 C のこの手法では測れなかった。「妥当性がない」ではなく「測定不能」。

### 4.5 観察 C の総括 — 妥当性もまた構造単位で割れる

観察 C は「注意の妥当性」という問いに、構造単位ごとに「ある (Integration)」「観測手法の限界で判定不能 (CID)」「測定不能 (ESDE)」と割れた答えを出した。

これは v1101 核心発見「観察単位を変えると dominant atom が割れる」、v10.13.a 留保 #33「集計単位による方向反転」、段階 1 #L5 (因果候補が集計方式で割れる) と同型の現象である。注意の妥当性すら、見る構造単位によって像が変わる。Unified Phase を通底する「集計単位を変えると像が変わる」が、注意の妥当性のレベルで再び現れた。

## 5. 段階 2 の総括

段階 2 の総括を一段落で。

段階 2 は、段階 1 の核心観察「意識優位時に波及が広い」の未解決部分 — それが選択と集中か拡散か — を時間軸を入れて切り分けた。答えは「選択と集中ではない」。観察 B が全 6 構造単位で「意識優位のとき注意の中心が動く」を示し、観察 A が「注意候補は少数に絞られない」を示した。意識優位時の波及の広さは、一点を深く掘るからではなく、注意が動きながら広がるから。これは Taka フレーム「意識 = 選択と集中」に対する反証的観察だが、Taka 自身の実感 (集中しているはずなのに注意は動く、ピアノの例) と合致し、ESDE が Taka の曖昧な想定を厳密に位置づけ直したものとして受け止められる。注意の妥当性 (Taka「ランダムか妥当か」) は観察 C で構造単位ごとに割れ、Integration スケールでは「Aさんの揺れ幅」(緩く予測でき確定しない帯) に乗る妥当性が観測されたが、CID は観測手法の自己言及で判定不能、ESDE は測定不能だった。段階 2 が残した最も大きいものは、ESDE が Taka の置いた定義をなぞらず独立に動き、その結果が現実の側 (定義より実感) を指したという事実である。

### 7.2 次への接続 (Taka 領域)
