# 第 1 部: 網羅（実験の構造事実）

## 1. runtime 駆動の探索（3ノブ全滅）— 偏りは走行中に増幅できない

### 1.1 確定した構造事実

child-world の当初設計は「親 CID の動的量で子の物理パラメータを*走行中*に駆動し、偏り（R＝閉路＝CID の本体）を増幅する」だった。runtime 書き換え可能な3つの物理ノブを最小 probe で順に試し、すべて偏りを増幅しないことを確認した。

| ノブ | 物理演算上の役割 | probe 結果（偏り R/loop/cluster への効果） | 留保 |
|---|---|---|---|
| **K_sync**（op2 Kuramoto 結合定数） | 位相同期の強さ | K_sync 0.03→0.3（10倍）で kuramoto_r 0.034→0.209（位相は揃う）だが **loops/meanR/max_size は完全不変**（4/0.062/6 が一字一句同一） | #CW1 |
| **auto_growth**（op5 `ΔS=growth·R`） | 共鳴 link の強度成長 | 実駆動域 0.03→0.3 で meanR 0.031→0.061（非単調）・max_size 6→4（むしろ減）。0→canon で統合（meanR 2.84→0.03・max_size 2→6・n_labels 145→21）だが**駆動域で単調増幅なし** | #CW2 |
| **β**（op7 `decay/(1+β·R)`） | 共鳴 link の減衰保護 | beta 0.5/1.0/2.0/4.0 で meanR 0.049/0.058/0.048/0.1（**非単調**）。R cap=5/β ゆえ β↑で R 上限が下がり、保護強化と cap 低下が干渉 | #CW2 |

### 1.2 機構的理由（資料と一致）

3ノブ全滅は 01_genesis_summary の確定事項「**トポロジーが熱力学より上流**」「**p_link_birth は脆弱軸（30倍範囲で崩壊）**」「**パス増は化学では不可能、観察層が必要**」が予言していた。**偏り R＝閉路は link の*幾何*の関数で、幾何は realization（どの link が偶然できるか）が決める上流量。K_sync・auto_growth・β・decay は幾何の*下流*（位相・強度成長・減衰）を弄るだけで、閉路を増やせない。**

### 1.3 重要な発見：R と cluster サイズは ESDE で逆

auto_growth probe（#CW2）から、**高 R（多数の小さい loopy 断片）と大きい cluster（統合・低 R）は反対方向**であることが構造事実として出た（auto_growth=0: meanR 2.84 / max_size 2 / n_labels 145 ↔ canon: meanR 0.03 / max_size 6 / n_labels 21）。

→ Taka の元の狙い「偏りを増幅して*より偏った/大きい*CID（10ノード）を作る」に対し、ESDE は「**大きい CID** と **高 R（偏り）** は一つのノブで両取りできない」と答えた（留保 #CW3）。

### 1.4 plb（量）も否定（probe せず資料で）

Code A 含意「R を動かすには plb か auto_growth/β」の plb 側は、資料に照らし弱いと判断し採らなかった：(1) plb は脆弱軸（崩壊リスク、§8 probe で低 plb→ノード飢餓死 200→154 を実観測）、(2) 概念理解 v5.1「洗濯機」教訓（plb↑はリンクを増やすが R=0 のまま＝量を増やしても偏りは増えない）。＝**位相（K_sync）・成長（auto_growth/β）・量（plb）のいずれも偏りを走行中に増幅しない**（留保 #CW4）。

## 2. pivot — 偏りは誕生時の初期条件として渡す

### 2.1 pivot の根拠

runtime 駆動が ESDE 構造上詰んだ（偏り＝topology は上流で走行中に作れない）ため、設計を pivot：**偏りが伝わるのは誕生時（初期条件）**。step-0（誕生時 seeding、v1301）が n2 transfer r=0.49 を出した場所に戻り、変更点1つ＝seed 元を B_gen から **親 member の S/R/E の structural-strength** にする（B_gen は同 n_core 内でほぼ不変 CV0.02-0.05、member S/R/conc は割れる ＝ Taka「CID の強さはノード数だけで決まらない／暗号的一意性」が戻る）。

### 2.2 B_Gen の計算問題（Taka 指摘・確定）

Taka が認めた通り、現 B_gen 式 `Pbirth=(1/C(N,n_core))·ρ^(n−1)·r_core^(n−1)·S_avg^(n−1)` は第1項 `1/C(N,n_core)` が桁を支配し（n=2→約7、n=5→約17）、r_core・S_avg は有界で寄与小＝**同 n_core 内で B_gen がほぼ変わらない**（一意性が消える）。子側だけ structural-strength で代替（親 CID 側 ledger は frozen 不可侵）。データ確認：n2 で B_gen_CV=0.047 ≪ s_avg_CV=1.306 / conc_CV=0.464（約10倍）＝member 量に一意性がある（留保 #CW5）。

## 3. step-0 transfer のチャネル分解 — K_sync は幻チャネルだった

### 3.1 確定した構造事実

pivot 前に、step-0 の n2 transfer（r=0.49）が*どの birth チャネルから来たか*を既存署名の read-only 再解析（D_child 固定・D_parent 側を1チャネル ablate）で分解した。

| 操作（n2, cid=54） | Mantel r | 含意 |
|---|---:|---|
| full（N+plb+Ksync+θ） | 0.583 | — |
| −plb | 0.398（**Δ−0.185 最大落差**） | **plb が transfer 本体** |
| −Ksync | 0.575（Δ−0.008） | **K_sync は寄与せず** |
| −θ | 0.631（Δ+0.048 抜くと上昇） | θ は雑音 |
| only plb | **0.639** | plb 単独で説明 |
| only Ksync | 0.108（**n.s.**） | K_sync 単独は無意味 |

### 3.2 機構との一致

K_sync の源 r_core は他軸と非共線（corr~0）ゆえ、−Ksync で r 不変は「共線に隠れて見えない」でなく**真に痕を残していない**＝**K_sync チャネルは値がコピーされただけで効果がなかった（幻チャネル）**。これは §1.1（K_sync は topology に効かない）と完全整合。step-0 で「K_sync←r_core 100%伝達」を強チャネルと読んだのは誤りで、伝達＝入力の写しにすぎなかった（留保 #CW6）。

→ 設計の的が確定：transfer は **plb（topology レバー）** に乗る。K_sync/θ は外す。

## 4. (A) scalar seeding — transfer 成立（ただしトートロジー留保）

### 4.1 確定した構造事実

structural-strength（S=`v11_m_c_s_avg` / R=`v11_m_c_r_core` / conc=`v18_v_unified_concentration_birth` 等重み z→tanh→初期 plb）を子の plb に当て、canon（plb 一定）対照と並走（5 seed・全 CID）。

| 層 | canon late r / p | **(A) late r / p** | smoke→full の変化 |
|---|---:|---:|---|
| **n2**(54) | 0.133 / 0.049 | **0.621 / 0.001** | 0.35(35CID)→0.621(54CID)：seed 増で強化 |
| **n4**(11) | 0.012 / 0.456 | **0.731 / 0.001** | 新規・強い transfer |
| **n5**(17) | 0.034 / 0.415 | **0.717 / 0.001** | 0.717(7CID)→0.717(17CID)：小標本の偶然でない |

### 4.2 構造事実

1. **3層すべて (A) r≈0.62-0.73 / p=0.001、canon は n4/n5≈0**。structural-strength を生きたレバー plb に当てる効果は実在。
2. **n5 が step-0 から復活**（step-0 n5 r=0.042 → (A) 0.717）。r_core/conc は「情報が無い」でなく「死レバー（K_sync）経由だった」だけで、plb 経由なら n5 でも効く。
3. **seed 増で transfer 強化**（n2 0.35→0.621）。単一 child は seed 雑音優位（step-0 と整合）。

### 4.3 留保（自己相関トートロジー、#CW7）

(A) の transfer は**一部トートロジー的**：strength_plb は plb を親ベクトル (s_avg, r_core, conc) の単調関数として設定し、Mantel はまさにその親ベクトルと子署名の相関を測る。「親強度に比例したノブを設定→ノブが効く」は半ば自明で、(A) の数値は額面通りには取れない（(A) vs (B) のコントラストを誇張している可能性）。**「親に似るか」で測る限りこの留保が残る**＝Taka 本筋（canon と違う系か／同期する系が増えるか）で測り直せば消える。

### 4.4 N 交絡の切り分け（#CW8）

(A) n2 の 0.621 は plb と N（=b_gen×10、b_gen は s_avg と共線−0.82）の混合で純 plb 効果が不明だった。N 固定 canon 対照（Nfix、N=中央値119 一定）で分離：

→ canon と (A) は N が共通ゆえ差≈0.5 は **plb 純効果**。(A) の transfer は N 残差でなく plb が担う、と確認（#CW8 解決）。

## 5. (B) topology 移植 — 交絡除去後も null

### 5.1 第一段（誕生時移植）と交絡の発見

(B) は親 member のコア＋周辺 structural field（`compute_structural` max_hops n_core+1）を子の初期 link 集合に `add_link` 移植する経路。第一段（誕生時 field 移植）は不発（n2 r=0.102 / n5 −0.109、n.s.）。理由＝**誕生時 field はほぼ tree**（閉路 n2 0/35・n5 1/7、t0 maxR=0）＝偏り R は誕生時に未形成で run 中に発達するため、移植元に偏りが無い（留保 #CW9）。

### 5.2 第二段（成熟期移植）+ 神の手回避

「未成熟な親から継ごうとしていた」（Taka 比喩：成熟個体が子を残す）を受け、移植元を **age_r≥τ link が閉路を成す成熟の盛り（閉路ランク最大）window** に変更。神の手回避＝(1) τ は label 誕生と同基準・(2) 全 CID 一律規則（age_r≥τ link 閉路ランク最大の argmax、CID 個別選択なし）・(3) **τ を1つに固定せず τ=10/50/100 全部で頑健性を見る**（label 誕生 τ がコードで一意特定できなかったため、1つ選ぶと神の手化）。feasibility 確認：誕生時 has_cycle n2 0/35 → 成熟 τ50 で 24/35（閉路が立つ）、成熟 window 中央値 w40（life 中盤）、ログ範囲端張付 0%。

成熟期 (B) の結果（τ 頑健性）：

| 層 | B_t10 r/p | B_t50 r/p | B_t100 r/p |
|---|---:|---:|---:|
| n2 | −0.012 / 0.52 | 0.284 / 0.041 | −0.085 / 0.72 |
| n5 | 0.396 / 0.038 | 0.028 / 0.36 | (<5 不能) |

→ **τ で符号も有意性も激変＝τ 頑健な transfer でない**。単発の弱有意（B_t50 n2 / B_t10 n5）は「特定 τ を選んだから出た」雑音と区別できない。**複数 τ 検査がこれを捕まえた**（1つの τ なら B_t50 n2=0.284 を「効いた」と誤読していた、留保 #CW10）。

### 5.3 第三段（交絡除去）— 空エンジン交絡を切る

懐疑チェックで、成熟期 (B) も含む移植版は `run_injection()` を**丸ごとスキップ**し、容量 N の 80-85% が空のエンジンに小さな移植 subgraph を置いて**ゼロ近くから再成長**させていたことが判明（t0_alive_n: canon 120/338 vs B 12-20/34-50）。＝(B) の null は「topology 非transfer」でなく「**空エンジン再成長の washout**」と交絡していて切り分け不能だった（**前 Phase の早合点を撤回**）。

交絡除去のため Bov（overlay）条件を追加：canon と同一 `run_injection()` で baseline を作り、その上に親 topology を `add_link` で上乗せ（E/θ 不変）。

| **n2**(35) | canon | 0.146 / 0.069 | 119.9 | 50.9 | 4.46 |
| | B（旧・置換） | 0.066 / 0.238 | **19.6** | 2.7 | 0.0 |

### 5.4 構造事実（交絡抜き）

1. **交絡除去の証明**：Bov の t0_alive_n が canon と完全一致（119.9/340.7）＝空start交絡は除去された。
2. **頑健な n2（35cid）で canon≈B≈Bov≈0.07-0.15、全非有意**＝baseline を揃えても親 topology の上乗せは transfer をまったく増やさない。
3. **旧 B の唯一の正シグナル（n5 r≈0.4）は空エンジン start の artifact**（Bov で −0.196 に反転消失）。

### 5.5 (B) 結論と、Phase Result 側の補正（#CW11）

**「topology は identity を運ばない」は交絡を抜くとより明確**＝成熟・閉路ありの構造を full canonical baseline に grafting しても null。これは Taka 直感「**物理演算そのものが変わる設計でなければ変わりようがない**」と一致（形＝初期条件を変えても、物理ルールが canon のままなら canon の力学に均される）。

ただし生データ点検で report に未記載の点を補正（Web Claude が parquet を独立検証）：
- **(a) Bov は topology 過剰注入で canon から系が乖離**（loops が canon 比 3.6倍）。「同一 baseline 上乗せ」と言うが対照として完全でない。それでも null なのは結論を強めるが、弱点として明記。
- **(b) n5=0.402 の「空start artifact」説明は n2 と非対称**（同じ交絡があるはずの n2 旧 B は 0.066）。素直には n5=7cid の統計雑音。report は同現象を「偽シグナル」と「n=7 雑音」で二重説明しており、**機構的説明（artifact）は過剰**。**堅いのは「n2（35cid）で交絡を抜いても topology 上乗せは transfer ゼロ」のみ**。

## 7. 一段深い確定：偏りは「初期条件」でなく「持続パラメータ」でのみ継ぐ

v1302 を通した最大の構造事実は、**継承の経路が2種類に分かれ、片方だけが効く**こと：

- **持続パラメータ経由（(A)）= 効く**：plb のように*毎step効き続ける*物理パラメータに親偏りを載せると、子が生きている間ずっと効いて、親 identity が子の創発署名に伝わる（トートロジー留保込み）。
- **初期条件経由（(B)）= 効かない**：親の topology を*生まれる時に一回置くだけ*では、子の力学（canon ルール）に均されて消える。成熟・閉路ありでも、交絡を抜いても、null。

→ Taka 整理「物理演算そのものが変わる設計でなければ変わりようがない」の構造的確認。形のコピー（初期条件）は物理ルールを変えないが、パラメータ変更（持続）は物理ルールそのものを変える。**ESDE で系を変えるには、ルール（パラメータ）を変えるしかない。**

## 8. Taka 構想の言語化（本セッションの副産物・v1303 の土台）

v1302 の実験中、Taka の構想が比喩から数学的・実装的言語に翻訳された（要約禁止・原文の趣旨を保存）：

- **CID = 物理演算の偏りを拾う検出器**。実験の「親子」は比喩で、本質は「通常 ESDE と異なる系を*自動で*作り出す仕組み」。
- **一致率＝同期度**。Taka 言語化（原文）：「ある存在を扱う際に同期する系が多いほど、私たちはそれは存在する、と感覚的に理解する」。幼児が「りんご」を覚えるのに視覚・触覚・温度・音・発話の多くの系が重なるように、一致率は ESDE が外部構造とどれだけ多くの系で同期するかの測定。**0.5 で頭打ちなのは同期できる系が少ないから**で、物理条件を ESDE の射程に加える＝同期できる系を増やす＝一致率の頭打ちを破る筋。
- **直接アクセスの全滅＝因果律による自然な防衛＝堅牢性の証明**。外部から物理を直接いじる経路は全滅した。だから「系自身が条件を決める仕組み」を作る（神の手の逆）。
- **AI 過去案との差**：AI は「ESDE に何かを足す」（Atom 取込・capture いじり・K_sync 接続・topology 移植）で全部弾かれた。Taka 構想は「ESDE から何かを取り出す」（多様性を生む物理条件を系自身に探させる）＝ESDE が拒否する方向でなく自然にやる方向に乗る。
