## 3. 物差しに当てた読み (Taka 整理が当たった)

Taka が v1111c 結果の前に置いた物差し:
> 繋ぐのは「物理層の構造制約が生む seed 共通の癖」のレベルで、ゆるく。局所の個性は seed をまたがない (同じ人は二人いない) から、そこで繋ごうとしたら出ない。

- **方向が出た (12 倍拡大) のは収穫**。出口を一致率にした効果は確かにある (番号コピーが部分原因だった候補が支持)。
- **だが atom=42 単独**。atom=100/200 で逆 = 3 seed 共通でない = **まだ局所 (特定 seed) の話**。Taka の「局所の個性で繋ごうとすると同じ人を探すことになって見つからない」がそのまま当たった。
- **12 倍を「効いた」と記録しない** (Taka 確認済)。+64% の再来 (局所を一般化する早合点) を避ける。方向は出た、共通ではまだ、が正確な記録。

## 4. 構造的理由 (Taka 整理 = Code A 判断③⑤)

- 出口で Other の活性を **top-K node の phase を円周平均で一点に集約**している。
- = Other のテーマを**一点に潰している**。全体の癖も局所の個性も区別なく 1 点に平均 = 情報を捨てている (Code A 判断③)。
- 一点平均はその時の局所に引きずられる → atom 横断で一貫しない (cos~1)、atom=42 でだけ偶々噛む。
- Taka 整理「全体の癖でゆるく繋げ」を実装に直すと: **一点平均でなく phase 分布の形で運ぶ** (Code A 判断⑤)。一点は局所に振り回されるが、分布の形なら「全体の癖」が残る。

## 6. これがどう Unified / 会話に繋がるか (継続)

- v1110-v1111c で踏み固めたこと: 連携は「位置 (node ID)」でなく「意味 (phase=seed 共通のテーマ座標)」で繋ぐしかない (seed 違いで配線はバラバラ)。出口を一致率にしたのはその第一歩。
- 残る分岐点: 繋ぐ粒度。**一点 (テーマ平均) は局所に振り回される。全体の癖 (phase 分布の形) なら seed 共通で繋がるかもしれない**。
- Taka 整理: Atom はどの seed でも「それらしい形」に収まる (物理層が seed ごとにそれほど違わない構造制約)。だから全体の癖のレベルでゆるく繋げば、どの seed でも見つかるはず。局所で繋ごうとすると同じ人を探すことになる。
- → v1111d で「全体の癖 (分布の形) で繋ぐ」を試すことが、Unified/会話が「全体の癖のレベルで通るか」の検証になる。
