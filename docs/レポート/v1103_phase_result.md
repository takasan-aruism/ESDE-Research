## 1. v1103 が答えたこと

### 1.1 主題の問いと答え

v1103 の問いは「ESDE の揺れから連想を辿って集めた応答候補を 48 次元空間に置いたとき、密度の偏り (クラスタ) が生じるか。生じるなら、その偏りは応答 Atom を絞る構造的指標として機能するか」(設計書 §1.1)。

答えは二段で出た。

機構として動いた。連想先候補は48次元空間で均等に散らずクラスタを作った。点検で出うる 4 可能性 (設計書 §5.1) のうち、可能性 2 (密度が均等で際立ちなし) と可能性 3 (品質フラグで偽だらけ) は退けられた。raw_density k=5 で 0.847、norm_density k=5 で 0.639。クラスタは確かにある。

ただし、同じ計算を raw でやるか normalized でやるかで密度が Δ0.208 変わる。可能性 1 (際立ちが出る) と可能性 4 (受け手構造で反転) のハイブリッド。段 4-c は機能したが、機能の見え方は集計方式で変わる。

### 1.2 v1103 が扱わなかったもの

設計書 §0.3 / §1.4 のとおり、会話の完成 / 実用的な応答 / 段 4 全体の完成判定 / 段 5b (文の質、LLM 外注) / 「どの受け手構造の応答を採るか」は範囲外。v1103 は段 4-c が構造的指標として成立するかの点検に徹した。

## 3. v1103 から確定して言えること

### 3.1 段 4-c は機構として動いた

連想先候補が48次元空間で均等に散らずクラスタを作り、密度の偏りが応答 Atom 群を絞る指標になりうることが、点検で確認された。可能性 2・3 は退けられた。段 4 足取り点検が「段 4-c は未定義の飛躍だが埋められない飛躍でなく、まだ作っていない機構」と置いた、その「まだ作っていない機構」が、48 次元密度の偏りという形で実装され動いた。これは確定。

### 3.2 段 4-c は ESDE のこれまでの性格を引き継いだ

raw と norm で密度が Δ0.208 反転したこと (留保 #L17) は、v1101 以来 ESDE が一貫して示してきた「集計単位で像が変わる」性質 (留保 #33 系列) と同型。v1101 で観察単位、v1101a で集計方式、v1102 で受け手構造、v1103 で sim_basis。主題が違っても同じ形が出る。

これは段 4-c が「ESDE と異質な後付け機構」ではなく「ESDE の性格を引き継いだ機構」だったということ。会話のための機構を作ったら ESDE と別物になるかもしれない、という不安が、一例で否定された。Genesis (揺れ) と Language (決定論) を噛み合わせた最初の出力が、ESDE のこれまでの観察結果と地続きだった。

これは Taka 整理 (2026-05-20)「すでに ESDE 内部で発生していることは私たちの想定を超えている、今回の発見は驚くに値しない」のとおりであり、驚きとして書くべきではない。当然の確認として記録する。驚いていれば、それは ESDE の現状についての研究者の認識がまだ追いついていない、ということになる。

### 3.3 決定機構として規律内に収まった

段 4-d の応答 Atom 群確率分布出力で max_prob 0.7972、5,670 rows 中 prob ≥ 0.999 が 0 件。Aruism 対称性 (箱 3、100% を作らない) が厳密遵守された。

これは段 4 足取り点検 §4.2 で書いた「決定を loss/reward でなく構造的指標で行えば外部評価関数の侵入にならない」が、実装で成立したことの確認。段 4-c の「絞り」は決定であり、決定を含む機構が ESDE の規律 (Aruism 対称性) を破らずに動いた。Taka が以前訂正したとおり「ESDE は決定論の半身 (Language) を最初から持つ、決定が起きることは裏切りでない」、その上での「決定を規律内で行う」が成立した形。

## 4. v1103 から慎重に言えること

### 4.1 会話への道が原理的に通った

会話接続足取り点検が「段 4-c が唯一の真の飛躍」と判定し、その飛躍が機構として動いた。これで段 1 (入力が ESDE に入る) から段 5b (LLM 外注) までの経路が、原理的に全段つながったものとして描ける。

ただし「原理的に」は重要な限定。「会話できる」とは言わない。段 4-c が動いた = 機構が存在することが確認できた、までで、ESDE と LLM プロキシを組み合わせて実用的な会話システムができることは、まだ示されていない。原理的な経路と実用的なシステムは別物。

### 4.2 ESDE が観察装置から決定する系へ一歩進んだ

これまで Genesis 系は「観察する、記述する、決定しない」が中心だった。段 4-c が動いたことで、ESDE は決定を — 外部評価関数なしに、構造から — 行えるようになった。Taka が前に整理した「ESDE は記述する系から決定する系へ進化する」、その進化の最初の一段が確認された。

ただし、これも限定つき。Genesis の規律 (frozen / 神の手回避 / 判定回避) は ESDE 全体の哲学ではなく一つの半身の規律であり、もう一つの半身 (Language) は元々決定論で動いている、というのが Taka の整理。段 4-c の決定は、ESDE が新しく獲得したというよりは、Language の決定論の半身が Genesis の揺れと噛み合った形で表に現れた、と言う方が正確かもしれない。「進化」と書くより「両系の噛み合わせが動いた」と書く方が事実に近い。

## 5. v1103 から推測として言えること

### 5.1 ESDE の応答は単一にならない可能性が高い

v1103 単独でなく、v1101/v1102/v1103 を集めると見えてくる予想。

v1101 で観察単位、v1102 で受け手構造、v1103 で sim_basis。集計単位を変えると像が変わる、が ESDE の一貫した性質として現れる。v1103 で会話の機構レベルでも出た以上、ESDE が応答を返すとき、その応答も単一にならない可能性が高い。Code A 観察でも可能性 4 (受け手構造で反転) が部分的に出ている。

これが何を意味するか。LLM のように「この入力にはこの応答を高確率で返す」のではなく、「条件次第で複数の応答候補が並ぶ、どれを採るかは別の何かが決める」というふるまいになりうる。これは LLM とは違う仕組みで、Taka が ESDE を始めた動機 (LLM の使い勝手の悪さ) に対する一つの応答になりうる。

ただし、これは推測。確定するには次主題で「応答が複数並ぶこと自体をどう扱うか」を点検する必要がある。
