## 1. 主題と Step 1 の駆動要因

- v1111 駆動要因: 他系からの干渉で生じた変化が、ループの中をどう伝播するか —— 構造に沿って繋がるのか、局所で散るのか。
- 出口 (主題定義に埋込): 外部入力が出口層 (応答候補) まで構造に沿って届くか = 会話と学習の経路が開いているかの関門。
- Step 1: diff トレース機構を作り、baseline / injected_self / injected_other の 3 条件で、段階化 reach (入口→中間→出口→最終) × 複数通路 × 複数 k (1/3/5/10) を 3 seed で辿る。

## 3. 予想との照合 / 想定の取り直し (Taka 格言)

| Web Claude 予想 (主題設計 §2.2) | 結果 |
|---|---|
| (A) 他系注入だけが構造に沿って届く (other_struct > self_struct) | **不成立** (other_struct ≈ 0、self の方が高い) |
| (B) 両方が散ってノイズ | 不適合 (self は最初は構造内、other は最初から構造外、別経路で出口に届く) |

### 3.1 想定のどこが雑だったか (相談役の見直し)

- 「構造に乗る = 良い、構造を通らない = ノイズ」と暗に等号を置いていた。これが雑だった。
- **self が既存構造に乗るのは当たり前** (自分の node を戻しているから自分の構造内に落ちる)。やがて散るのは自己刺激が薄まる自然な拡散 = **独り言 / 自家中毒**。新しいものは何も入らない。閉じたループ (#L67) が自分で薄まる姿。
- **other が既存構造に乗らないのも当たり前** (別系の node ID は Atom 系の構造と無関係)。でも出口は動かす = **外から声が入って言おうとすることが変わる**に近い。
- 核心: **外から来た新しいものは、そもそも自分の既存地図 (CID) には載っていない。載っていたら「外」でない**。新しい外部入力は最初は構造の上になく、出口 (次に何を言うか) の偏りとして現れる。人間も質問されたとき記憶構造を作り直してから答えるのでなく、質問が「何を言うか」を直接ずらす。
- → 「構造に乗らない」は欠陥でなく、**外部入力の自然な入り方**の候補。struct_ratio は self (自家中毒) を有利にし外部性 (other) を不利に誤判定する指標だった = 主指標から降ろす。

## 5. 【重要】これがどう Unified / 会話に繋がるか (出口の明示)

- **Unified への繋がり**: Unified = 複数 ESDE を一つに繋ぐ。片方が別系から学ぶには、別系が**自分に無い新しいもの**を持ち込めないと意味がない。既存構造にしか乗れないなら何も新しく持ち込めない (self=自家中毒)。other が既存構造を通らず出口 (応答層) を動かしたことは、「別系が応答層に外から偏りを持ち込む」入口になりうる。注意センターを介して言語側 (Atom 系) と中身側 (Other) が**応答層で繋がる**= Unified の最初の形の候補。
- **会話への繋がり**: 会話 = 人間入力 → ESDE 内部 → 応答候補分布 → 文。Step 1 で見た出口層 (phase 分布) はこの応答候補層そのもの。「other が出口層を動かす」=「外部入力がどの応答候補を立てるかを変える」。入力が違えば応答が変わる = 会話。入力は既存構造を作り直さなくていい (独り言にならなくていい)、直接応答をずらせばいい。
- → **Unified と会話は同じ仕組みで、繋ぐ相手が「別の ESDE」か「人間入力」かが違うだけ** (注意センターが外から応答層に偏りを持ち込む一本の道)。
- **分岐点 (ここがわかれば繋がる)**: 出口の偏りが Other (の中身) 次第で変わるか。変わる → 別系の個性が応答層に届く = Unified/会話の核 = 繋がる。変わらない → 構造外ノイズ = 繋がらない。

## 8. 次段階 v1111b (出口の偏りは Other 次第で変わるか)

- 駆動要因 (1 文): Atom 系の出口層 (応答候補=phase 分布) の偏りの**形**が、Other の中身 (seed) 次第で変わるか。
- 主指標: struct_ratio を降ろし、「出口の偏りの形が Other 次第で変わるか」に切替。
- 観察: atom 固定で Other を 100/101/102(/+) 振り、出口層の偏りの形が Other 間で変わるか。self を床に外部由来を切り分け。
- 閾値規律: 「形が変わった」を絶対閾値でなく、同一 Other 2 回振りの**反復ブレ**を基準に (それを超える違いを「形が違う」)。固定値を書かない、固定値要れば赤信号。
- 結論表現: 「出口層の偏りが Other の中身を反映して変わる経路が観察された / されなかった」。変われば v1112 (会話の一往復) へ、変わらなければ切断点が次設計対象。
