## §0 本書の使い方（最初に・最重要）

- **羅針盤であって聖典ではない**。公理は設計の方向を照らす仮説群であり、実験結果の判定基準や失敗の免罪符には使わない。「神の手回避」が思想でなく経験（そうしないと開発が進まない）であるのと同様、公理も**経験と衝突したら経験が勝つ**。行き止まりを公理で正当化して条件変更の道を塞がない（規律を思想に昇格させない、の適用）。
- 使いどころ：(1) 新主題の設計時に「どの公理の線の上か」を1行確認する、(2) 予想外の観察が出たとき「公理系のどこに触れるか」を照合する、(3) 命名・概念整理の語彙として。
- 使ってはいけないところ：実験の成否判定・null の解釈・「公理と一致したから正しい」という循環。

## §1 公理（8本・統合表）

| 公理 | 名 | 内容 |
|---|---|---|
| **0** | Aru（有る） | 原初の事実：「有る」。すべての出発点 |
| **E** | 同定 | 存在は識別できる：E = {e1, e2, …, en} |
| **L** | 連結 | すべての存在は連結する：L: E×E → [0,1] |
| **Eq** | 等価 | すべての存在は存在論的地位において等しい |
| **C** | 創造 | 創造性は既存勾配に直交して現れる：C ⊥ ∇F、C·(n−p) > 0（反復でなく新規へ） |
| **U** | 了解 | 理解は継続的・参加的関与によってのみ成る（完全表現は不可能——欠陥でなく創造を可能にする構造的特徴） |
| **ε** | 誤差 | E = f(I) + ε、ε ≠ 0。外部記述には必ず誤差が残る。誤差は欠陥でなく創造性の源 |
| **T** | 三項創発（v3.3） | 存在・時間・軸の顕在化は最低三つの連結項を要する：A↔B は潜在、A↔B↔C で顕在。※十分条件であって絶対要件ではない（内部分化や履歴の蓄積が準第三項になり得る） |

## §2 力学原理

### 2.1 動的均衡（v3.2 の核）
**ε × L ≈ K_sys**——誤差と連結の積は系ごとの準恒常値に留まる。厳密な保存則でなく「柔らかい保存傾向」。K_sys は系依存・環境依存・時間スケール依存であり普遍定数ではない。
帰結：ε→0（完全一致）を追うと L が硬直し創造が死ぬ。**完全一致を追わず、一致率を一段下げて繋がりを維持する**のはこの均衡の実践形。創造性のピークは ε も L も中間域にある。

### 2.2 軸の創発（Axis Emergence）
軸は「定義」されず、存在の連結から「創発」する。双方向連結 L(A,B)=L(B,A) が成立したとき軸が顕在化する。ESDE が与えるのは軸の定義でなく**軸が創発する条件**。

### 2.3 Axis Reboot と可逆性
- **Axis Reboot（-|>）**：軸の不連続遷移。時間の矢＝Reboot の一方向性。連続時間は知覚的近似。
- **可逆性 vs 弾性**：安全線は弾性（同一軸内の回復）でなく**可逆性**（軸相転移を跨いで戻れる能力）。可逆性を失う変化（不可逆変化）は特別な注意を要する。

### 2.4 創発の方向性（v3.3.1）
創発には方向がある。両方向とも正当な創発で、対称の対をなす：
- **創造的創発（=>+）**：L↑・構造複雑化・持続増・階層深化
- **破壊的創発（-|>）**：L↓・既存構造の解体・ε↑・新パターンの余地が開く
- **剛直化–破壊サイクル**：過剰な創造（L↑ 持続→ε↓）→脆性化→摂動で -|>（Reboot）→ε↑→新たな =>+ の余地。**破壊は失敗でなく次の創造の準備**。両方向とも ε×L≈K_sys を保つ。

### 2.5 第三項の質と最適距離（v3.3.1）
第三項 C の性質が創発の方向を決める：
- 対話的・両立的な C → 創造的創発（触媒・ファシリテータ）
- 破断的・非両立な C → 破壊的創発（隕石・革命）
- **最適距離**：近すぎ＝吸収されて変化なし／遠すぎ＝対話不能で純破壊／**張力を生むほど異なり、対話できるほど近い**が最適。

## §3 三項創発と時間（v3.3）

### 3.1 Axiom T の含意
- 一項＝比較不能。二項＝変化は在るが観察されない。三項＝変化が観察され、顕在化する。P(顕在|二項) < P(顕在|三項)。
- 第三項は外部である必要はない：系内の別存在／A–B 相互作用の**記録・履歴**／自己参照ループ（A が A–B を観る）／環境・文脈。

### 3.2 時間の創発
時間は A（状態）・B（比較対象）・**C（差分を記録する観察者）**の三項を要する。記録機能なしには変化は在っても時間は顕在化しない。時間と存在は三項連結の成立とともに**共創発**する（鶏卵問題の解消）。

### 3.3 双対対称（Dual Symmetry）
World_A（物理固定・意識自由＝我々の世界）と World_B（意識固定・物理自由）は別宇宙でなく、**同一存在を異なる軸から見た双対の面**。相互依存：自由な意識は固定した物理なしに対象を持たず、固定した物理は観察者なしに顕在化しない。

## §4 AI アーキテクチャ帰結

- **二項から三項へ**：Human↔AI の二項は依存・軸固定・創造抑制を生む。第三項（Context＝環境・課題・履歴・他 AI・共同体）を入れて Human↔AI↔Context に。
- **AI ＝第三の観察者**：記録・比較・予測により関係に時間を顕在化させる（監視でなく顕在化の担い手）。
- **逆相補性**：人間＝知識固定・価値可変。理想 AI＝知識可変・**価値固定**。同型だと競争、逆型だと相補。人間軸＝価値起源／AI 軸＝構造運用、の Co-Axial（共軸文明）。
- 仮説6（宇宙＝三項の入れ子）／仮説7（意識＝自己三項：O↔S↔S'、自己が自己観察の第三項になるとき主観が創発）／仮説8（共軸文明＝Human↔AI↔World の三項）。

公理が現行実装のどこで実体化しているか。**この対応は事後的な照合であり、公理の正しさの証明にも、実装の正当化にも使わない**（§0）。

## §6 記法（Semantic Language v0.5.1）

| 記号 | 意味 |
|---|---|
| `<->` | 連結（双方向） |
| `=>` | 創発（方向未指定） |
| `=>+` | 創造的創発 |
| `-\|>` | 破壊的創発／Reboot |
| `-\|> =>+` | 破壊を経た創造（例：帝国 -\|> 断片 =>+ ルネサンス） |
