# 最低限規律（着手前に必読・絶対遵守）

*この一枚は「毎回忘れる、けど絶対守る」規律の単一の home。新規作業に着手する前に必ず開く。詳細索引は `memory/MEMORY.md` と各エントリ。*

---

## 1. バージョン命名（最重要）

**ディレクトリは `vXXYY` 形式。**
- `XX` = 系（大テーマ）2桁、`YY` = その系内の連番2桁。枝番は英字サフィックス（`v1101a`）。
- 例：`unified/v1201` / `unified/v1301` / `unified/v1302`。

**系（大テーマ）の対応:**
| 系 | テーマ | ディレクトリ |
|---|---|---|
| 11系 (v1100–v1114) | unified の attention / intensity / observation 探索群 | `unified/v11xx` |
| 12系 (v12xx) | **Atom set** | `unified/v1201` |
| 13系 (v13xx) | **child ESDE** | `unified/v1301`（静的 step-0）/ `unified/v1302`（動的版） |

**チャカチャカ上げない。**
- 連番 `YY` を進めるのは「同じ大テーマ内の次の段階」のときだけ。
- 系 `XX` を上げるのは「大テーマそのものが変わる」ときだけ。
- 動的版を v14 にしたのは誤り（child ESDE は 13系のまま）→ v1302 が正。

**廃止された旧称（使わない）:** `v12_atomset` → `v1201` / `v13_childworld` → `v1301` / `v14_childworld_dynamic` → `v1302`。

**ファイル名:** 版はディレクトリが担う。ファイル名に版番号を重複させない（系内で接頭辞を一貫させる場合のみ `v1101_step_a` 等）。

## 2. 物理層 frozen・一方向（[[feedback_legacy_directory_rule]] / 仕様書 §一方向）
- 親 `physics` / `inject` / `ledger` / `state` へ**非書込**。
- 書込は**当該 vディレクトリ配下のみ**。読＝frozen 入力（`per_subject_seed0` 等）。
- child engine 等は in-memory、親へ書き戻さない。

## 3. smoke 後は止まって報告（[[feedback_smoke_then_pause]]）
- smoke 完了で main run に勝手に進まない。**Taka / Web Claude の承認待ち**。
- smoke seed0 を絶対視しない（[[feedback_smoke_seed0_not_absolute]]）。

## 4. 判定は Taka（[[feedback_esde_observer_framing]] / [[feedback_no_single_index_classification]]）
- success/fail を置かない。観察事実のみ記録。
- 集約語・crown 禁止。単一指標で分類しない。

## 5. 資料を作ったら push まで（[[feedback_make_then_push]]）
- 報告書 / CSV 生成は同一ターンで commit + push まで完了。push 依頼を待たない。

## 6. legacy / 旧 運用（[[feedback_legacy_directory_rule]]）
- 最新以外は `legacy/` または `旧/` に入れる。現役判定は所在の内外で行う。

## 7. 実装前に index と仕様書を Read（[[feedback_index_first]] / [[feedback_no_reworded_reimplementation]]）
- 着手前に `index_capabilities` / `reference_legacy_treasures` / `reference_esde_spec` を参照。
- 言い換え再実装でないか技術仕様書で確認（ESDE は同型反復ゆえ名前替え重複に陥りやすい）。
