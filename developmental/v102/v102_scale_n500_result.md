**観察 2-A**: N が小さい方が **cid 総数が多い** (6,362 vs 5,224、+22%)。物理層の link 密度が高くなり、persistence 条件 (age_r ≥ τ) を満たす component が多く形成される。

**観察 2-B**: **大型 n_core (6-11) が 71 cid 出現**。N=5000 では n=6,7,8 が 1 cid ずつのみだったが、N=500 では n=6 で 27 cid、最大 n_core=11 まで存在。**小さい N は大きな coalition を形成しやすい**。

**観察 2-D**: B_Gen median は N=500 で 37.05、N=5000 で 32.88。**B_Gen は N が小さいほど高い**。これは Pbirth = (1/C(N,n)) 分母が小さくなる (C(500,2)=124,750 vs C(5000,2)=12,497,500) 効果が、ρ^(n-1) や S_avg^(n-1) の効果と打ち消し合った結果として B_Gen が緩やかに変動する。

## 3. 観察 (観察事実から読める傾向)

### 3.1 N=500 では系が「希薄に活発」

- 物理層は N=5000 と同等 (link 密度 ~高) で event は多発する
- しかし C 蓄積に必要な cognition 当選が起きづらい (大量の skip)
- 結果: 物理層は活発だが、認知/意識層の活動は希薄

### 3.2 ghost residual_Q の枯渇

N=500 では ghost が放出する residual_Q がすべて消費される。これは:
- 物理層の link 死亡 / R 変化が同等に起きるが
- 意識発動による摂食が少ない → ghost の residual_Q は摂食ではなく E1/E2 spend で枯渇する経路がメイン
- v10.1 の「全食料 ingestion」想定とは別経路で食料が消える

### 3.3 大型 coalition の出現

n_core = 11 まで形成される。N=5000 では n=6,7,8 が 1 cid ずつだったのに対し、N=500 では多様な大型 coalition が出る。**小さい N は構造的多様性 (n_core サイズの幅) を高める**。

---

## 4. 仮説 (慎重)

- 仮説 1: N が小さいほど「**物理層の活発さ vs 認知層の希薄さ**」のギャップが広がる。これは「ノード密度が高い小さい系では event は多発するが、cid あたりの cognition 当選機会は少ない」という構造の帰結
- 仮説 2: 「Q0 が N にほぼ独立」という事実は、Pbirth の N 依存項 (1/C(N,n)) と他の項 (ρ, r_core, S_avg) が部分的に相殺している可能性。設計時の予想外の安定性
- 仮説 3: N=500 の skip_C_zero 81% は、ESDE が「N が変わっても Q0 が同じ → C 蓄積機会が同じ」だが「物理層 event が増える → balance decisions の機会が増える」という非対称が支配的になる兆候

これらは v10.3 三項共鳴に向けて、N 依存性が **物理層 vs 認知層のバランス** を変える効果を持つことを示唆。
