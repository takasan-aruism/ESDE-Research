# v10.2 スケールテスト 統合比較レポート

*作成*: 2026-04-29、Code A
*対象*: 5 スケール (N=500/1000/2500/5000/10000) × 24 seeds × tracking 50 windows
*親資料*: 各 N の個別レポート (`v102_scale_n{N}_result.md`)、v10.2 main run (`v102_main_run_result.md`)
*出力 CSV*: `scale_comparison.csv` / `scale_comparison_n_core.csv` / `scale_comparison_conservation.csv`
*位置づけ*: v10.2 の延長として軽量実験。新バージョン化なし。**5 桁の N 範囲で v10.2 設計の robustness と認知層活性化の N 依存を初めて系統的に観察**。

## 0. 一行サマリ

ノード数 N を 500-10,000 まで 5 スケール変えても **v10.2 設計 (確率決定 + 意識層 C + 即時摂食) は構造的に頑健**で、認知/意識活動は **N に対し monotonic に加速、N=10,000 でも飽和兆候なし**。同時に **大型 coalition (n_core ≥ 6) が N とともに消失** (N=500: 71 cid → N=10,000: 0 cid) という反直感的な現象、**ghost_residual_Q が N=1,000-2,500 の境界で 0 → 残存に転換**、**Q0 と E1/E2 spend が N に対しほぼ不変**、などの観察事実が定量化された。

## 3. 重要発見 5 つ

### 3.1 発見 1: Q0 の N 不変性 (5 桁の N 範囲で確認)

n_core 別の Q0 median:

| n_core | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| 2 | 12 | 12 | 12 | 12 | **11** |
| 3 | 20 | 20 | 19 | 18 | 18 |
| 4 | 28 | 28 | 27 | 26 | 25 |
| 5 | 37 | 36 | 34 | 33 | **32** |

**観察事実**: N が 20 倍変わっても Q0 median は ±5 の範囲。Pbirth = (1/C(N,n)) × ρ^(n-1) × r_core^(n-1) × S_avg^(n-1) の N 依存項が他要因と相殺している。

**仮説**: これは v9.11 で導入された B_Gen 設計の **構造的安定性**を示す。「cid の認知原資が物理層スケールに依存しない」という設計目的が予想以上に強く保たれている。

### 3.2 発見 2: E1/E2 spend の N 不変性

E1/E2 spend 数 (24 seeds 合計):

| N | n_E1_E2_spend |
|---:|---:|
| 500 | 21,671 |
| 1000 | 20,926 |
| 2500 | 20,843 |
| 5000 | 20,107 |
| 10000 | 20,548 |

**観察事実**: 5 スケール通じて 20-22k で揃う (幅 7% 以内)。N が 20 倍変わっても物理層由来の Q 消費はほぼ一定。

**仮説**: E1 (link 死/生) と E2 (R 状態変化) の発火頻度は cid 集団の構造変化に駆動される。cid 数が N=2500 以上で飽和することと整合する。

### 3.3 発見 3: cognition / consciousness 加速の monotonic 性 (N=10,000 で飽和なし)

| N | cognition_rate | consciousness_rate | n_core=5 意識発動経験率 |
|---:|---:|---:|---:|
| 500 | 18.7% | 0.09% | 14.0% |
| 1000 | 26.7% | 0.45% | 42.5% |
| 2500 | 40.5% | 1.68% | 66.6% |
| 5000 | 56.8% | 3.50% | 73.2% |
| **10000** | **76.7%** | **5.67%** | **79.0%** |

**観察事実**: 全指標で monotonic 加速。N=5000 から N=10000 で skip_C_zero_rate は **17.7% に半減以下**になり、cognition_rate は +20 ポイント上昇。

**仮説**: ESDE の認知層活性化は **N に飽和点を持たない可能性**。これは v10.2 main run (N=5000) を「典型例」と見なしていた判断を覆す: **N=5000 は中央であって上限ではない**。

### 3.4 発見 4: 大型 coalition (n_core ≥ 6) の N 依存消失 (反直感)

| n_core | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| 6 | 27 | 7 | 7 | 1 | **0** |
| 7 | 25 | 5 | 1 | 1 | **0** |
| 8 | 14 | 2 | 2 | 1 | **0** |
| 9 | 4 | 1 | 0 | 0 | 0 |
| 11 | 1 | 0 | 0 | 0 | 0 |
| **合計 ≥ 6** | **71** | **15** | **10** | **3** | **0** |

**観察事実**: N が大きくなると n_core ≥ 6 の大型 coalition が monotonic に消失し、**N=10000 では完全消失**。

**仮説 (反直感だが構造的に説明可能)**: persistence-based birth は age_r ≥ τ の link で connected component を構成し、既存 label と 50% 以上重複する component を排除する。N が大きいと:
- link 候補数は C(N,2) で爆発 (N=500: 124,750 / N=10,000: 49,995,000、400 倍)
- しかし persistence 条件 (R>0 が τ=50 step 連続) を満たす link は構造的に難しくなる
- 結果として component サイズの分布は **小型 (n=2-5) に集中** し、大型 (n ≥ 6) が選択的に消える

これは v9.13 で「persistence 条件は神の手ではなく構造選別」とされた設計の **N=10,000 での表現** と解釈できる。

### 3.5 発見 5: 食料経済の N 依存 (3 段階)

ghost_residual_Q の run 末値:

| N | ghost_residual_Q | 解釈 |
|---:|---:|---|
| 500 | **0** | 完全枯渇 |
| 1000 | **0** | 完全枯渇 |
| 2500 | 80 | 残存開始 |
| 5000 | 410 | 残存中 |
| 10000 | **1,146** | 大量残存 |

**観察事実**: N=1,000 と N=2,500 の間に **「枯渇 → 残存」の質的境界**。N=10,000 では食料供給 > 摂食需要 で大量残存。

**仮説**: 
- N が小さい (≤ 1,000): 意識発動が少なく、ghost.residual_Q は E1/E2 spend (= 系全体の散逸) で消える
- N が大きい (≥ 2,500): 意識発動経由の摂食が増えるが、ghost が多く生まれて (cid 数が多い) 食料供給過多に
- これは **「資源消費の経路が N で変化する」** 現象。v10.3 三項共鳴の前提条件として重要

## 7. 仮説の整理

### 7.1 構造的仮説

1. **B_Gen 設計の N 不変性**: Pbirth の数式が cid の認知原資を物理層スケールから切り離す
2. **persistence 条件の N 選別性**: link 候補が N とともに増えるが、persistence (R>0 連続 τ step) を満たす確率は N でやや下がり、結果として **小型 component が支配的**になる
3. **物理層と認知層の独立性**: E1/E2 spend が N で一定、認知/意識活動は N に依存。これは **物理層が認知層からの介入を受けない** 規律の数値的確認

### 7.2 機能的仮説

4. **認知層活性化の N 飽和なし** (少なくとも 10,000 まで): N をさらに大きくすると何が起きるか別途検証必要
5. **食料経済の 3 段階**: 枯渇 (N≤1,000) → 残存 (N=2,500-5,000) → 過剰 (N=10,000)
6. **大型 coalition の構造的消失**: 「N が大きいと多様性が増える」素朴期待と逆。ESDE では選別効果が支配

## 9. 規律と限界 (Taka 規律 #100 + §4.9)

### 9.1 観察事実の正当な記録

本レポートは「ESDE は活発な系」「N が大きいほど意識が立ち上がる」のような普遍化はしていない。**「v10.2 で 24 seeds × tracking 50 × N=500/1000/2500/5000/10000 を実行したところ、以下の指標が以下の値を示した」** という条件付き記述に徹している。

### 9.2 普遍化の抑制

以下の表現は使用していない:
- 「ESDE はスケール不変な系である」(N=500-10,000 での観察にすぎない)
- 「これは生命的活性化を示す」(比喩、規律違反)
- 「N が大きいと知性が立ち上がる」(因果断定)

代わりに:
- 「N=10,000 まで観察した範囲では飽和兆候なし」
- 「これは v10.2 設計の構造的特徴を反映している可能性」
- 「観察事実 / 仮説」の三層分離

### 9.3 限界

- 1 設定 (24 seeds × tracking 50) のみ。robustness 横断検証なし
- N > 10,000 (Taka 過去の N=20,000 経験) での挙動は未確認
- 物理パラメータ (p_link_birth、auto_growth、K_sync 等) は固定。N との交互作用は未検証
- 詳細解析 (lifecycle pattern、トポロジー、偏在性) は本レポートでは未実施 (各 N の `analysis/` ディレクトリで個別実施可能)
- v9.18 指標 (cognitive_gain、unity_metrics、theta_distance) との相関は未集計

## 11. 結論

v10.2 を 5 桁の N 範囲 (500-10,000) で実行した結果、以下が観察事実として記録された:

### 11.1 設計の robustness

- **空摂食 / phantom 0 件が全 N で維持** (即時摂食設計が破綻しない)
- **Q0 が N にほぼ不変** (B_Gen の構造的安定性)
- **E1/E2 spend が ~21k で N 独立** (物理層と認知層の規律的分離)

### 11.2 認知層活性化の N 依存

- cognition_rate / consciousness_rate / 意識発動経験率が **N に対し monotonic 加速、N=10,000 でも飽和兆候なし**
- skip_C_zero_rate が逆に monotonic 減少 (81.3% → 17.7%)

### 11.3 反直感的な観察

- **大型 coalition (n_core ≥ 6) が N=10,000 で完全消失** (N=500 で 71 cid → 0 cid)
- これは persistence 条件の構造選別効果が N で強化される現れ

### 11.4 食料経済の質的境界

- ghost_residual_Q が **N=1,000-2,500 の境界で 0 → 残存に転換**
- N=10,000 では 1,146 まで残存 (食料過剰)

### 11.5 v10.3 への接続

- **主役候補 (n_core=5 意識発動経験者) が N=10,000 で最大 (543 cid)**
- 系の状態は「**N=5,000 を超えてもさらに活性化**」
- **v10.2 main run (N=5,000) は中央であって上限ではなかった**

これらは ESDE が 5 桁の N 範囲で **構造的に頑健**でありながら **認知/意識活動の量的特性が N に強く依存**するという二重の性質を示す。

---

## 12. 最終一文

本スケールテストは v10.2 (Probabilistic Cognitive-Conscious Balance) の延長として、ノード数 N を 500 から 10,000 まで 5 段階で変化させ 24 seeds × tracking 50 windows を実行することで、空摂食/phantom の構造的消失・Q0 と E1/E2 spend の N 不変性・認知/意識活動の monotonic な N 依存・大型 coalition の N=10,000 完全消失・食料経済の枯渇/残存境界、という観察事実を 5 桁の N 範囲で初めて系統的に記録し、v10.3 三項共鳴の主役候補が N=10,000 で最も豊富であること (n_core=5 意識発動経験者 543 cid) と v10.2 main (N=5,000) が ESDE の挙動空間の中央であって上限ではないことを明らかにしつつ、Taka 規律 #100 (普遍化禁止) と Taka 立場 §4.9 (観察事実の正当な記録) を併存運用して観察事実 / 観察 / 仮説の三層分離を保ち、結論を「N=10,000 まで観察した範囲では」という条件付きで限定する形で記述した。
