### 3.2 観察 (重要発見)

#### 発見 1: skip (C=0) が 39.71% — 想定外の頻度

E3 onset の 4 割で「相手 ghost に residual_Q > 0 で意識候補成立、しかし observer の C=0 で意識発動できず、Q もない (= 認知候補もない)」状態が起きていた。

意識候補成立の総数: `n_consciousness_won + n_skip_c_zero_only = 3,517 + 39,880 = 43,397` 件。

うち実際に意識発動したのは **8.1%** のみ。残り **91.9%** は「機会はあったが原資 (C) なしで取り損なった」。

これは smoke (windows=2) では観察できなかった現象。本番規模で initial Q=0 の cid (誕生時 Q=0 ghost との接触者) や Q 枯渇後の cid が意識候補成立時に C も 0 で skip になるパターンが顕在化。

#### 発見 2: 意識率 3.50% は smoke (0.4%) より高い

windows=2 の smoke では意識当選が 1/232 件 (0.43%) のみだったが、本番 50 windows では 3.50%。C 蓄積が進むほど意識が立つ確率が上がる構造が確認された。

#### 発見 3: 認知優位の傾向

認知率 56.79% > 意識率 3.50%。Q ≫ C の状態が大半なので、確率決定で認知に倒れる傾向が顕著。これは設計通り (Q/(Q+C) で Q が大きいほど認知優位)。

### 6.2 数理的観察

主題 §3.1 G の数理:
```
認知活動: ΔQ = -1, ΔC = +1 → Δ(Q+C) = 0 (CID 内で保存)
意識活動: ΔQ = +received, ΔC = -1 → Δ(Q+C) = received - 1 (流入)
E1/E2 spend: ΔQ = -1 → Δ(Q+C) = -1 (純散逸)
消化: ghost 側で消失 (CID 集団の Q+C には影響しないが全系 Q+C には影響)
```

期待される CID 集団 Q+C 増分 (run 全体):
```
+ received (流入) - n_e1_e2_spend (散逸) - n_consciousness_won (意識消費 -1)
= 18,468 - 20,107 - 3,517
= -5,156
```

run 末の CID 集団 Q+C = 25,868 → 初期 Q+C 総和 (run 開始時の hosted の Q0 合計) ≈ 25,868 + 5,156 = 31,024 のオーダー (ただし実際は途中で hosted の出入りがあるため厳密値ではない)。

#### 発見 7: 動的均衡の兆候は無し (進化継続)

- ghost residual_Q 総和 410 (run 末で残っている食料) と CID 集団 Q+C 25,868 は乖離
- 意識発動率が伸び悩み (39.71% が C=0 で skip) → エネルギー流入が限定的
- → 全系で「平衡」に達していない、進化終端のリスクは現時点では見えない

Taka 警告 (2026-04-26)「動的均衡 = 進化終端のリスク」への暫定回答: **v10.2 段階では均衡に達していない**。継続観察対象。

5. **動的均衡 = 進化終端の兆候はなし** — Q+C 系全体で平衡に達しておらず、進化継続中

- **意識発動 cid の B_Gen / Q0 特性**: どんな cid が意識発動できるか (個体差)
- **(Q+C) 保存則の窓ごと推移**: c_trajectory_seed{N}.csv を活用した時系列観察 (本レポートでは未深堀)

## 11.6 詳細解析の概要 (`v102_detailed_analysis_report.md` 概要)

依頼書 (`v10_2_analysis_request_to_code_a.md`) で指定された 5 本の詳細解析を実施し、`diag_v102_main/analysis/` に CSV 10 本、`v102_detailed_analysis_report.md` にレポートとして記録した。観察事実の要約のみ:

- **解析 1 (個別性、5,224 cid)**: 意識発動の有無は誕生時 Q0 では予測できない (発動群 / 非発動群で同一 n_core 内では Q0 median が一致)。**寿命** (発動群は非発動群の 4-7 倍) と **初回 cognition (= C+1) のタイミング** (発動群は早期、非発動群は後期) が分岐の主因。初期接触相手の n_core 平均は群間で差なし。

- **解析 2 (トポロジー、5,224 cid)**: lifecycle pattern を 4 分類 (no_activation / early_single / late_single / repeated)。**n_core=2 は 89.9% が no_activation**、n_core=5 は **34.0% が repeated**。n_core 軸が大枠を決め、内部で履歴依存の細部が分かれる。n_core=2 の repeated は 0.1% (3 cid のみ)、短寿命と低接触頻度が反復発動を構造的に阻害。

- **解析 3 (時系列、1,200 行)**: C_total は 17.5 → 1,047.5 (60 倍、ただし減速兆候)、Q_total は 387.7 → 30.3 (92% 減)、**(Q+C) per_capita は 22.5 → 33.4 で安定** (動的均衡の数値的兆候)。流入 (gain) は 30.2 → 9.6 で鈍化、E1/E2 散逸は ~16/window で安定。**hosted 集団は run 末で 60% が n_core=5** (時間とともに K 戦略寄りに再編)。完全平衡には未到達、しかし C 蓄積期から飽和期への移行の兆し。

- **解析 4 (偏在、1,200 行)**: 全体 Gini は 0.29-0.33 で安定 (中程度)、top 10% シェア 21-25%、top 1% シェア 7-12%。**n_core 内 Gini は ≤ 0.25** で偏在の主因は n_core 群「間」の階層差。run 末の C 総和の **73% が n_core=5 集団** に偏在。「ハブ型」ではなく「階層型」偏在。
