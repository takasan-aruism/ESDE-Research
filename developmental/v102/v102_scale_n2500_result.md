## 3. 観察 (傾向)

### 3.1 N=2500 は「ほぼ N=5000 級」の系

意識発動経験率 / 摂食 / consciousness_rate は N=5000 の 70-90% レベルに達している。**N=2500 で系が「成熟」に近づく**。

### 3.2 ghost_residual_Q の境界が確定

5 スケールの観察:
- N=500: 0 (枯渇)
- N=1000: 0 (枯渇)
- N=2500: 80 (残存開始)
- N=5000: 410 (残存)
- N=10000: 待機

**枯渇 → 残存の転換は N=1000-2500 の間**。

### 3.3 物理層 (E1/E2 spend) の N 独立性

E1/E2 spend が 5 スケールで 20-22k に揃うのは **物理層動態が N に対し統計的に同等** であることを示す。系全体の Q 消費 (= cognition の代替経路) のベースが安定。

## 4. 仮説

- 仮説 1: ESDE には **「認知層活性化の N 飽和点」が N=2500 付近に存在**。それ以上 (N=5000、N=10000?) では限界収益逓減
