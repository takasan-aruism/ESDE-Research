## 3. 観察 (傾向)

### 3.1 N 依存性は monotonic

主要指標 (cognition_rate、consciousness_rate、eater_rate、意識発動経験率) はすべて **N が大きくなると monotonic に上昇**。逆に skip_C_zero_rate は N が大きいほど減少。

### 3.2 「物理層は N=500 と等価、認知層は中間」という挙動

E1/E2 spend は N に独立 (~21k で揃う)。total_decisions は N=500 (501k) → N=1000 (269k) → N=5000 (100k) で逆に減少 (cid 数当たりのバランス機会が減る方向)。

### 3.3 「ghost residual_Q 枯渇 vs 残存」の境界

N=500/1000 では枯渇 (=0)、N=5000 で 410 残存。**境界は N=1000-5000 のどこか**。N=2500 の結果次第で位置を絞れる。

---

## 4. 仮説

- 仮説 1: ESDE には **N に対する「認知層活性化の閾値」が存在** する。N が小さいと cognition 当選機会が物理層 event 数に追いつかず C 蓄積が遅延、結果として意識発動が起きづらい
- 仮説 2: N=1000 の「中間性」は、N=500 と N=5000 の差が線形ではなく構造的境界を含む可能性を示唆。境界の位置 (どの N で qualitative shift があるか) は N=2500 + N=10000 の結果から定量化可能
