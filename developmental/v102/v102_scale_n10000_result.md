## 3. 観察 (傾向)

### 3.1 「N=5000 は飽和ではなかった」

主要指標が N=5000 から N=10000 でさらに活性化:
- cognition_rate +20 ポイント
- consciousness_rate +62%
- skip_C_zero_rate を半分以下に
- 意識発動経験率 (n_core=5) +5.8 ポイント

これは v10.2 main run (N=5000) の評価を改める材料: **N=5000 は ESDE の挙動空間の中央であって、上限ではない**。

### 3.2 大型 coalition の完全消失 (反直感)

N=500 で 71 cid あった n_core ≥ 6 の coalition が、N=10000 では **完全消失 (0 cid)**。
- N が大きいほどノード候補が多い → 大型 coalition が形成しやすそう、と素朴には思える
- しかし結果は逆: N が大きいほど大型 coalition が出ない
- 仮説 (慎重): persistence 条件 (age_r ≥ τ かつ 既存 label と 50% 以下重複) は ノード集合の「狭さ」と「co-firing 確率」の積に依存。N が大きいと多数派 component が分散して合成しにくい

### 3.3 食料経済の「枯渇 → 残存」3 段階

ghost_residual_Q の N 依存:
- N=500/1000: **完全枯渇** (0)
- N=2500: 残存開始 (80)
- N=5000: 残存中 (410)
- N=10000: 大量残存 (1,146)

意識発動経由の摂食が増加するが、それでも食料供給 > 需要 で残存が積み上がる。**N=10000 では系が「過剰食料」状態**。

## 4. 仮説 (慎重)

- 仮説 1: ESDE の認知層活性化は **N に対して飽和点を持たない** (少なくとも 10,000 まで)。N が更に大きい (例: N=20,000) と何が起きるか別途実験が必要
- 仮説 2: 大型 coalition の N=10000 消失は、persistence-based birth の **構造選択効果** が N と共に強化される可能性。link 候補数の指数的増加に対し persistence 条件が選別的になる
- 仮説 3: ghost_residual_Q の累積は「**食料供給 (= ghost が多く生まれる) > 摂食需要 (= 意識発動経由の流入)**」のギャップを示す。N=10000 では ghost 数が多すぎて全部食べきれない
- 仮説 4: C_max が N=2500 で最大、N=10000 でやや減 という非単調性は「**個別 cid の累積 C 上限**」と「**集団全体の摂食機会**」の異なる scaling に由来する可能性

## 5. v10.3 三項共鳴への素材としての評価

- **N=10000 が「最も活発な系」** = v10.3 主役候補は N=10000 で最も豊富
  - n_core=5 で 79% が意識発動経験あり (= 543 / 687 cid)
  - 反復発動者 (n_core=5 × n_consciousness ≥ 5) はさらに多数と推定
- **大型 coalition がないことは利点 or 欠点?**
  - 利点: n_core 5 までの「均質」な構造で観察容易
  - 欠点: 「中規模 vs 大規模 coalition」の比較が N=500-2500 でしかできない
- **wall time 9.6h/seed** は v10.3 本番として現実的範囲。N=5000 (3h) より重いが許容内
