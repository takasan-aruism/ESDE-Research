## 2. 観察 (n_core 別データ)

### 2.1 n_core 分布 (24 seeds 合計、5,224 cid)

| n_core | cid 数 | 構成比 |
|---|---|---|
| **2** | **3,968** | **76.0%** |
| 3 | 288 | 5.5% |
| 4 | 327 | 6.3% |
| **5** | **638** | **12.2%** |
| 6/7/8 | 各 1 | 0.0% |

n_core=2 が圧倒的多数派、n_core=5 が二位。

### 2.2 n_core 別の主要指標

| n_core | n | lt mean (step) | Q0 mean | n_cog (認知) | n_con (意識) | n_skip | C_at_run_end (hosted のみ p50) |
|---|---|---|---|---|---|---|---|
| **2** | 3,968 | **1,716** | 11.5 | **5.18** | **0.13** | 0.99 | 8 |
| 3 | 288 | 4,858 | 18.4 | 12.38 | 0.85 | 6.67 | 17 |
| 4 | 327 | 10,356 | 25.8 | 25.46 | 2.02 | 26.30 | 25 |
| **5** | 638 | **13,598** | 33.5 | **38.24** | **3.25** | 39.64 | **35** |

**観察**:
- n_core=2 → n_core=5 で寿命 8 倍、Q0 3 倍、認知活動 7 倍、意識活動 25 倍、C 蓄積 4 倍
- skip 件数は **40 倍** 増加 (= 長く生きるほど「視たが C 不足」が累積)

### 2.3 意識発動経験率 (n_core 別)

| n_core | n | 意識発動経験者 (n_con > 0) | 比率 |
|---|---|---|---|
| **2** | 3,968 | 401 | **10.1%** |
| 3 | 288 | 94 | 32.6% |
| 4 | 327 | 195 | 59.6% |
| **5** | 638 | 467 | **73.2%** |

**核心発見**: n_core=2 の **89.9% が意識を 1 回も発動せず**生涯を終える。一方 n_core=5 は 73% が意識発動を経験。

### 2.4 link 1 本あたりの E1/E2 発火率 (構造の頑健性)

| n_core | C(n,2) link数 | E1 / 1k step / link | E2 / 1k step / link |
|---|---|---|---|
| 2 | 1 | **0.742** | **1.270** |
| 3 | 3 | 0.324 | 0.334 |
| 4 | 6 | 0.150 | 0.188 |
| 5 | 10 | **0.079** | **0.133** |

**観察**: link 1 本あたりの E1/E2 発火率が n_core=2 → n_core=5 で **約 10 倍減少**。大きい構造ほど個別 link が安定。

### 2.5 寿命統制した E3 onset rate (cid 間接触の頻度)

寿命 [5,000, 10,000) step に統制した cid のみで比較:

| n_core | n | E3 onset / 1k step |
|---|---|---|
| 2 | 98 | **1.91** |
| 3 | 40 | 2.82 |
| 4 | 47 | 3.56 |
| 5 | 110 | **3.75** |

**観察**: 寿命を揃えると n_core=5 は n_core=2 の **約 2 倍** E3 を発火する。「全 cid 平均では n_core 不変」は集団構成のアーティファクト。

## 3. 生態系との具体的対応

| 生態系の概念 | ESDE v10.2 で観察された対応物 |
|---|---|
| r 戦略 (多産短命、簡素) vs K 戦略 (少産長命、複雑) | n_core=2 (76% / lt 1,716) vs n_core=5 (12% / lt 13,598) |
| 個体数 ≠ バイオマス分布の歪み | 個体数は n_core=2 が支配、活動量・C 蓄積は n_core=5 が支配 |
| 集団規模と個別死亡率の逆相関 | link 1 本あたり E1/E2 発火率が n_core で 10 倍差 |
| 資源枯渇 → 行動制約 | Q 枯渇 28.4% → 認知候補から除外 → skip 増加 |
| 個体間の資源流動 | ghost.residual_Q → 摂食経由で hosted に流入 (18,468 / 24 seeds) |
| ニッチ分化 | 「視るが C にできない」(skip 多発) と「視て C にできる」が共存 |

## 4. 構造的に emerge していること (設計に書いていない)

設計したのは以下のみ:

```
- 物理層: alive_l (= ノード間 link)
- detect_e1_events / detect_e2_events: member_nodes 内部の link 死生・R 変化を検出
- detect_e3_new_pairs: 異なる cid の member_nodes が link を共有した onset を検出
- decide_balance(Q, C): P(認知) = Q / (Q + C)
- attempt_ingestion: ghost.residual_Q → CID Q への流入
```

これだけで以下が emerge した:

1. **r 戦略 vs K 戦略の二極化** — 単一の `_process_event` ルールから個体差が出ている。集団を分けて実装していない。

2. **構造の頑健性が cid サイズに逆相関** — n_core 大ほど link 1 本あたりの死亡率が下がる。意図せず `compute_member_alive_links` のメンバー集合論理の帰結。

3. **集団統計の構造的バイアス** — mean と median が別の物語を語る。これは「2 種の戦略が共存」の証拠。

4. **意識層が物理層由来の戦略差を継承** — n_core=2 で意識発動率 10%、n_core=5 で 73%。意識という新しいレイヤーが下位層の構造を忠実に反映。

## 5. 過剰評価しないための注意点 (Taka 規律)

教訓 #100 (条件から切り離して普遍化しない) に基づき、以下を区別:

| レベル | 内容 |
|---|---|
| **観察事実** | r/K 様の二極化が n_core 別に成立、集団統計をバイアスする |
| **解釈 (比喩)** | これは「生態系様」と表現できる |
| **過剰評価 (避ける)** | 「これは生態系である」と断定する |

具体的な抑制点:

1. **進化的選択圧は実装されていない** — 淘汰・適応度は cid 間に存在するが、「生存競争」と呼べる動的構造ではまだない
2. **r/K 戦略は環境圧の帰結であって個体の選択ではない** — n_core は誕生時に決まり、cid 自身は選んでいない
3. **多様性が「機能」になっていない** — 戦略の差が cid 同士の役割分担 (r 個体が K 個体を支える等) にはなっていない
4. **1 設定の観察** — 24 seeds × 物理パラメータ固定。条件を変えた robustness は未検証

## 6. ESDE 全体での位置づけ

過去の発見との連続性:

| バージョン | 関連発見 |
|---|---|
| v9.14 | E3 ablation で 70-90% が cid 間共鳴と判明 → E3 = 上位層の足場と再定義 |
| v9.16 | E3 は cid が Q 枯渇に近づいてから発生 (age_factor median 0.00)、n_core 別に age_factor が異なる |

| **v10.2 (本観察)** | **戦略二極化が「意識発動率」にも継承されることが定量化** |

v9.18 までは **「認知層内での個体差」** の観察。v10.2 は意識層 C を実装したことで、**「物理層 → 認知層 → 意識層が一貫した秩序で繋がっている」** ことが見えた。意識層という新しいレイヤーが、下位層由来の構造差を忠実に反映するのは、層が分断していない証拠。

### 論点 3: 「すごい発見」の評価軸

ESDE Constitution §9 (成果定義): 「単一の成果ではなく、安定した実験ループの存在」

- 本観察は「**新しい安定実験ループの完成**」を示唆: 物理層 → 認知層 → 意識層の継承を n_core 軸で観察できる
- ただし**新しい物理現象を発見したわけではない** (n_core 効果は v9.18 で既に観察済)
- 意識層への継承が新しいだけ

Code A 解釈: 「すごい」のレベルは「既存の系譜が意識層まで一貫していることを示した」あたり。「生態系を発見した」ではない。

### 論点 4: v10.3 以降への接続

主題ドキュメント §3.2 で v10.3 以降の論点として保持中:
- 三項共鳴 (双方向発火)
- 意識行動の他形態 (focus / 選択 / 行動)
- Salience 駆動

これらが r 戦略 / K 戦略の cid に **異なる影響を与えるか** (= 二極化が深化 vs 同化) は、v10.3 で観察できる新しい軸になる。

Code A 推奨: v10.3 主題ドキュメント (Claude が作成) で、本観察を引用しつつ「意識行動の拡張が n_core 別にどう作用するか」を観察目標として明示する。

### 論点 5: Robustness 検証の必要性

n_core 二極化の robustness を確かめるなら:

- A. 同物理条件で別 24 seeds の追加 run (3 時間 / 1 set)
- B. 物理層パラメータを変えた run (主題 §8.5 で v10.x 以降と棚上げ済)
- C. 24 seeds 本番 run の per_subject を統計的に解析 (追加 run なし)

Code A 仮推奨: C のみ。本観察自体は 24 seeds × 5,224 cid の集計で十分な有意性。追加 run のコストは v10.3 の本番 run と統合するほうが効率的。
