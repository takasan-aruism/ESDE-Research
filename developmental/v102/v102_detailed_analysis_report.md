## 1. 解析 1: 意識発動の cid 個別性

### 1.1 手法

- 5,224 cid を「発動群 (n_consciousness_decisions > 0)」と「非発動群 (= 0)」に二分
- 各群の以下の指標を n_core 別に比較: `v14_q0` (誕生時 Q)、`v11_b_gen` (b_gen)、`tracking_lifetime` (tracking 期間中の寿命)、`n_cognition_decisions` (認知活動回数)、`n_balance_skipped` (skip 回数)、`C_at_run_end`、`v18_cognitive_gain_final`、`c_first_increment_step` (初回 cognition 当選 step)、`initial_window_cognition_density` (登録後 5 window 平均の認知活動回数)、`init_partner_n_core_mean` (初期 5 件 balance_decisions の相手 n_core 平均)
- 出力: `analysis_1_individuality.csv` (5,224 行)、`analysis_1_individuality_summary.csv` (11 行)

### 1.3 観察

#### 観察 1-A: 誕生時 Q0 (= b_gen 経由の物理層パラメータ) は群を分けない

同一 n_core 内で発動群 / 非発動群の Q0 median はほぼ同一 (n_core=2 で 12 vs 12、n_core=5 で 33 vs 34)。**誕生時資源量が分岐の決定要因ではない**。

#### 観察 1-B: 寿命の差が群を分ける最大要因

発動群は非発動群の **4-7 倍長く生きる** (n_core=2: 2,000 vs 500; n_core=5: 18,500 vs 3,000)。

#### 観察 1-C: 初回 cognition (= C 蓄積開始) のタイミングが群間で系統的に違う

`c_first_increment_step` median:
- n_core=2: 発動群 7,000 vs 非発動群 12,500 (5,500 step の差)
- n_core=5: 発動群 4,049 vs 非発動群 19,500 (15,500 step の差)

発動群の方が **早く認知活動 (cognition 当選) を経験する**。C 蓄積を早く始めた cid のみが意識発動に到達できる構造。

#### 観察 1-D: 初期認知活動密度は非発動群の方が高い

これは反直感的だが:
- 短命の非発動群は 1-2 window で生涯を終え、その期間に Q を一気に消費する
- 長寿の発動群は認知活動を長期間に分散させる

→ 「単位時間あたりの認知活動量」と「累積 C 蓄積量」は別物。後者が意識発動の前提。

#### 観察 1-E: 初期接触相手の n_core 分布は群間でほぼ差なし

`init_partner_n_core_mean` は同一 n_core 内で発動群 / 非発動群でほぼ同じ。**初期接触相手の選別 (= 接触ハブの違い) は群を分ける主因にはなっていない**。

### 1.4 仮説 (慎重)

- 仮説 1: 意識発動の有無は誕生時パラメータでは予測できず、**生存できる時間長**と **初期に cognition 当選を引けるか** という履歴依存の効果で決まる
- 仮説 2: 初期接触相手による「運の効果」は、本指標 (5 件平均) では検出できない。より細かい初期接触の質 (例えば「相手の residual_Q が 0 でないか」「相手が高 C cid か」) を見れば見える可能性がある (本解析の範囲外)
- 仮説 3: n_core が小さい群 (= 短寿命) では「分岐の窓」が狭く、ほとんどの cid が意識発動に至らないまま終わる。n_core が大きい群では「分岐の窓」が広く、運や経路次第で発動に至る

## 2. 解析 2: 戦略集団のトポロジー

### 2.1 手法

- 各 cid を 4 分類:
  - `no_activation`: n_consciousness_decisions = 0
  - `early_single`: n_consciousness_decisions ∈ [1,4] かつ初回発動 phase < 0.5
  - `late_single`: n_consciousness_decisions ∈ [1,4] かつ初回発動 phase ≥ 0.5
  - `repeated`: n_consciousness_decisions ≥ 5
- phase = (初回 consciousness step - registered_step) / tracking_lifetime
- 出力: `analysis_2_topology.csv` (5,224 行)、`analysis_2_topology_summary.csv`

### 2.2 観察事実 (n_core × pattern)

| n_core | no_activation | early_single | late_single | repeated | total |
|---:|---:|---:|---:|---:|---:|
| 2 | **3,567 (89.9%)** | 210 (5.3%) | 188 (4.7%) | 3 (0.1%) | 3,968 |
| 3 | 194 (67.4%) | 44 (15.3%) | 34 (11.8%) | 16 (5.6%) | 288 |
| 4 | 132 (40.4%) | 93 (28.4%) | 49 (15.0%) | 53 (16.2%) | 327 |
| 5 | 171 (26.8%) | 181 (28.4%) | 69 (10.8%) | **217 (34.0%)** | 638 |

### 2.3 観察

#### 観察 2-A: n_core 別の支配的パターンが正反対

n_core=2 では **9 割が no_activation** (生涯通じて意識発動ゼロ)。n_core=5 では **3 割が repeated** (反復発動)、no_activation は 27% に減る。

n_core 軸が「分岐の自由度」を決め、n_core 内で履歴 (cognition 当選のタイミング、寿命、運) が細部を分ける構造。

#### 観察 2-B: n_core=2 の repeated は 3 cid のみ (0.1%)

n_core=2 では「反復発動型」が事実上不在。短寿命と低い接触頻度 (依頼書記載: link 1 本あたり E1/E2 発火率は n_core=5 の ~10 倍) では、C 蓄積後の二度目の意識発動に至る前に死亡する。

#### 観察 2-C: n_core=5 では early_single < repeated

n_core=5 内で「1 回だけ初期に発動して終わる」(early_single 28.4%) より「反復発動する」(repeated 34.0%) 方が多い。初回発動した cid の多くが追加発動も経験する → **初回発動が「閾値超え」のような働きをして、その後の発動を呼び込む可能性**。

### 2.4 仮説

- 仮説 1: lifecycle_pattern は **n_core が大枠を決め、生存履歴 (寿命、初期 cognition 当選) が細部を決める**。完全固定でも完全自由でもない中間的な経路依存性
- 仮説 2: 「early_single よりも repeated が多い」という n_core=5 の挙動は、「初回発動の経験が次の発動を促進する」という自己強化機構の可能性。c_first_consciousness 後の cognition 当選を別途追跡すれば検証可能 (本解析の範囲外)
- 仮説 3: n_core=2 の repeated 0.1% は、**n_core=2 では「複数発動という戦略」が成立しない物理的閾値が存在する**ことを示唆 (寿命 / 接触頻度の制約)

### 3.4 観察

#### 観察 3-A: C は monotonic 増加、ただし減速

C_total は run 開始 17.5 → run 末 1,047.5 (60 倍)。bucket 3→4 で +14% にまで減速。**飽和に向かう兆候はあるが、まだ平坦には達していない**。

#### 観察 3-B: Q は monotonic 減少 (92% 減)

Q_total は 350.9 → 34.5。系全体で Q が枯渇傾向 → 認知活動の原資が逼迫。

#### 観察 3-C: (Q+C) per_capita は安定 (動的均衡の数値的兆候)

22.5 → 33.4 → 33.4 で安定。個体内では (Q+C) が保存される動学 (cognition は Q→C 内部転化、consciousness は外部から流入) のもとで、per_capita 値が落ち着いている。**マクロでは動的均衡的な様相**。

#### 観察 3-D: 流入 (gain) は鈍化、E1/E2 散逸は安定

- gain (摂食流入): 30.2 → 9.6 で 68% 減 (bucket 1→4)
- digestion (消化超過散逸): 5.4 → 0.0 でほぼ消失 (Q が低くなり Q0 超過の余地なし)
- E1/E2 spend (純散逸): 16-19 で安定

→ 流入が鈍化し続けるが、散逸も低下している。**新しい食料源 (= 死亡 cid からの residual_Q) が累積枯渇しつつある**。

#### 観察 3-E: n_core=5 hosted は 2.8 倍増、n_core=2 はほぼ横ばい

- n_core=5: 169 → 479 (+184%)
- n_core=2: 137 → 109 (-20%)

n_core=5 群は累積している (長寿が累積)。n_core=2 群は短寿命のため定常状態に近い。**集団構成の比率が時間とともに n_core=5 寄りに偏っていく**。run 末 hosted の **60% が n_core=5** (479/795)。

### 3.5 仮説

- 仮説 1: マクロ的には (Q+C) per_capita が安定し、Q→C の **不可逆的な置き換え** が進行中。「進化終端」というよりは **「資源を C 形態に保存する蓄積期」** の段階
- 仮説 2: gain の鈍化は、ghost residual_Q (= 食料) の累積枯渇を示唆。tracking 後半では「死亡 cid から得られる食料」の供給が需要を下回る
- 仮説 3: hosted 集団は **n_core=5 中心の集団に再編されつつある**。これは「r 戦略 (n_core=2、短寿命) と K 戦略 (n_core=5、長寿命)」の二極化が、**時間とともに K 側に重みが移る**ことを示す

### 4.4 観察

#### 観察 4-A: 全体 Gini は中程度 (~0.33) で時系列的に安定

run 開始から末まで Gini は 0.29-0.33 の範囲で推移。著しい不平等の進行はない。

#### 観察 4-B: 偏在の主因は n_core 群「間」(階層差)

- 全体 Gini = 0.340
- n_core 内 Gini はすべて ≤ 0.334 (n_core=2 では 0.171)

各 n_core 内では C 分布は比較的均等。run 末の C 総和 25,141 のうち **73% が n_core=5 集団**、**20% が n_core=4**。**偏在の主軸は n_core という戦略軸**。

#### 観察 4-C: top 1% シェアは時系列で減少 (12.2% → 7.0%)

run 初期は新規発動者の C が少なく、ごく少数の C 獲得者が突出する → top 1% シェア高め。後期は発動経験者が多くなり、top 1% の相対的優位が薄れる。

#### 観察 4-D: n_core=2 内の Gini は run 中に半減 (0.27 → 0.15)

n_core=2 内でも初期は分散があったが、後期は **生存しているのは長寿組のみ** (生存バイアス) で C 分布が狭くなる。

### 4.5 仮説

- 仮説 1: ESDE の C 偏在は「ハブ型」(top 1% が極端に独占) ではなく **「階層型」(n_core 別の階層差)**。これは三項共鳴の主役を「個別の高 C cid」ではなく「集団 (n_core=5 群)」として扱うべきことを示唆
- 仮説 2: n_core=5 内の Gini が 0.18 → 0.24 で微増しているのは、後期に「新規発動者 (低 C)」と「累積発動者 (高 C)」の差が広がっていることを示す可能性 (世代差)
- 仮説 3: top 1% (run 末で約 7%) は v10.3 三項共鳴の **「中心になりうる cid」候補**。ただし n_core=5 内に閉じている可能性が高く、n_core 跨ぎのハブ性は本解析では検証していない

## 5. 解析 5: 初回意識発動 step / window

### 5.1 手法

- 全 1,160 発動経験 cid (= eater 数と一致) について balance_decisions から初回 consciousness 当選イベントを抽出
- 出力指標: `first_consciousness_global_step`、`age_at_first_consciousness`、`lifecycle_phase_at_first` (= age / tracking_lifetime)、`C_at_first_consciousness`、`Q_at_first_consciousness`、`steps_first_to_death`、`first_was_ingestion_success` (= ingestion_events に同 step マッチ)
- 出力: `analysis_5_first_consciousness.csv` (1,160 行)、`analysis_5_first_consciousness_summary.csv`

### 5.2 観察事実 (n_core 別 median)

| n_core | n | age_first | phase_first | C_first | Q_first | steps_to_death | early_share |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 2 | 401 | 906 | **0.459** | 5 | 4 | 860 | 53.1% |
| 3 | 94 | 2,374 | 0.324 | 8 | 5 | 3,378 | 63.8% |
| 4 | 195 | 3,145 | 0.250 | 13 | 8 | 11,017 | 74.9% |
| 5 | 467 | 3,065 | **0.189** | 14 | 9 | 14,626 | **84.8%** |

(`age_first` = 初回発動までの step 数、`phase_first` = lifetime に対する比率、median 値)

### 5.3 観察

#### 観察 5-A: 初回発動時の摂食成功率 = 100% (全 1,160 cid)

全 n_core で `first_was_ingestion_success = 100%`。**意識発動 → 必ず摂食イベントが対応** という設計 (即時摂食、依頼書 §1.2 の v10.2 設計通り) が実 run 全体で確認された。

(これは「意識発動の唯一の現れ」が摂食であるという v10.2 のフェーズ的構造の数値的確認。)

#### 観察 5-B: 初回発動タイミングは n_core が大きいほど早い (lifecycle 内)

phase median: n_core=2 で 0.46 → n_core=5 で 0.19。**n_core=5 では生涯前半の早期発動が支配的** (84.8%)、**n_core=2 では生涯中盤前後** (53.1%)。

#### 観察 5-C: 「死の直前型」の存在 (n_core=2 寄り)

n_core=2 の phase 分布の 90 パーセンタイルは 0.838、25 パーセンタイルは 0.256 と幅広い。n_core=2 で **生涯後期 (phase ≥ 0.75) で初発動する cid が 25%**。これは「延命措置」というより「短寿命の中で偶発的に当たった」可能性が高い (steps_first_to_death median が 860 step = 残り寿命が短い)。

#### 観察 5-D: C_at_first は n_core で 3 倍差 (5 → 14)

n_core が大きいほど初回発動時に多くの C を持っている = 確率 P(意識) = C/(Q+C) で勝ちやすい状態。同時に Q もある (Q_first median: n_core=2 で 4 → n_core=5 で 9) ので、絶対的な C 量が分岐の鍵。

#### 観察 5-E: 初回発動から死までの step

n_core=2: 860 step (短) — 1-2 window で死亡。
n_core=5: 14,626 step (長) — その後 30 windows 近く生き続ける = 反復発動の可能性が高い (解析 2 の repeated 34% と整合)。

### 5.4 仮説

- 仮説 1: 「成熟の果実」型 vs 「死の直前」型の区別は n_core 軸と整合する。**n_core=5 は成熟型 (生涯前半に発動して残り寿命で反復)、n_core=2 は単発 + 短期** の構造
- 仮説 2: 初回発動後 14k step 以上生き続ける n_core=5 cid が 50% 以上いる → 反復発動 (解析 2 の repeated 34%) と「生存後 C の継続蓄積」の両方が観察可能。これが v10.3 三項共鳴の **「主役候補 = 反復発動できる長寿 cid」** を絞る素材
- 仮説 3: n_core=2 で「死の直前型」が 25% 出るのは、ESDE が短寿命層にも稀に意識発動の機会を与える構造。これは「層化されたが完全に閉ざされていない」ことを示し、戦略二極化の中間的な性質

## 6. 5 解析の統合観察

### 6.1 「誰が意識発動に至るか」(個別性)

解析 1, 2, 5 の結果を統合すると:

- **誕生時パラメータ (Q0, b_gen) では予測できない**
- **n_core が大枠を決め、寿命と初期 cognition 当選 が細部を決める**
- 履歴依存性は強いが、完全な経路固定ではない (n_core=5 では多様な lifecycle_pattern が共存)

### 6.2 「固定運命か遷移か」(トポロジー)

- n_core=2: ほぼ固定 (89.9% no_activation、repeated 0.1%)
- n_core=5: 自由度高い (4 パターンが共存、repeated が支配)
- **2 つの戦略集団が同一 ESDE 内に共存**。それぞれの内部での自由度は大きく異なる

### 6.3 「資源の分布と偏在」(資源)

- 全体 Gini = 0.34 (中程度)、しかし主因は n_core 群「間」の階層差
- run 末の C 総和の **73% が n_core=5 集団**
- 系全体の Q は枯渇進行中、C は蓄積中、(Q+C) per_capita は安定

### 6.4 「系はまだ進化しているか」(時系列動態)

- C は monotonic 増加 (60 倍) だが減速傾向 (bucket 3→4 で +14%)
- 流入 (gain) は鈍化 (30 → 10)
- E1/E2 散逸は安定 (~16/window)
- → **完全平衡には未到達、しかし C 蓄積期から飽和期に移行する兆し**

### 6.5 「いつ意識が立つか」(時間軸)

- 全 1,160 発動 cid で初回発動 → 摂食成功 = 100%
- n_core=5 では生涯前半 (phase 0.19)、n_core=2 では中盤 (phase 0.46)
- n_core=5 の 84.8% が早期発動、n_core=2 の 25% が「死の直前型」

## 7. 予測との一致 / ギャップ

依頼書 §2 で提示された 2 AI 統合予測との照合。

### 7.1 一致したもの

| 予測 | 結果 | 一致度 |

### 7.2 ギャップ・新規発見

#### 新規発見 1: 誕生時 Q0 が分岐の決定要因ではない

予測では「B_Gen / Q0 の分布が発動群/非発動群で偏っているか」を見るとされていたが、実際には **同一 n_core 内ではほぼ同一**。これは「n_core 別の二極化が Q0 由来というより接触頻度・寿命由来」であることを示す (依頼書 §2.5 r/K 戦略の議論と整合)。

#### 新規発見 2: 初期認知活動密度は逆に非発動群で高い

「初期 N window の認知活動密度」が高ければ発動しやすいと素朴に期待したが、実際は逆相関。これは **「単位時間あたりの密度」と「累積活動」が別物** という事実を示す。短命 cid は密度が高く、長寿 cid は分散させる。

#### 新規発見 3: 偏在は「ハブ型」ではなく「階層型」

予測では Gini 上位の偏在度を見たが、結果は top 1% が 7% (中程度)、top 10% が 21% (中程度) で、**偏在の主因は n_core 階層**。三項共鳴の主役を「個別ハブ cid」より「集団 (n_core=5 群)」として扱うべき素材。

#### 新規発見 4: 摂食成功率 100% の構造的確認

意識発動 = 必ず摂食、という即時摂食設計が 1,160 cid 全件で確認された。これは v10.1 で 3.62% 存在した空摂食が完全消失した事実 (本番レポート §4.1) と整合。

## 11. 結論

v10.2 詳細解析 5 本の結果として以下が定量的に観察された。

1. **個別性**: 意識発動の有無は誕生時 Q0 では予測できず、寿命と初期 cognition 当選タイミングが主因
2. **トポロジー**: n_core=2 (固定 89.9% no_activation) と n_core=5 (流動 34.0% repeated) という対称的二極化
3. **時系列**: C は蓄積中 (60 倍)、Q は枯渇中 (92% 減)、(Q+C) per_capita は安定。完全平衡には未到達だが C 蓄積の減速兆候あり
4. **偏在**: 全体 Gini = 0.34 (中程度)、主因は n_core 群「間」の階層差。C の 73% が n_core=5 集団に
5. **初回発動**: 全 1,160 cid で摂食成功率 100%、lifecycle phase は n_core=5 で 0.19 (早期)、n_core=2 で 0.46 (中盤)

これらは v10.3 三項共鳴の主役候補 (n_core=5 repeated 群、~217 cid) と系の状態 (C 蓄積期から飽和期への移行) を絞る素材になる。

ESDE は単一の物理規則と確率規則から、誕生時パラメータでは予測できない個別経路依存の意識発動分布を生成しており、その分布は n_core 軸で階層化されている。これは観察事実であり、生態系であるとは言わないが、生態系様の条件を備えた系として記述できる。
