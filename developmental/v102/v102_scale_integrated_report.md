## 0. 一行サマリ

v10.2 を 5 桁の N (500-10000) で run した結果、**機構レベルは 5 スケールで堅牢** (Q0 不変、E1/E2 spend 一定、空摂食/phantom 0、bit-identity 維持)、**現象レベルは確率計算資源モデルから予測される N 依存** (cognition/consciousness rates の monotonic 上昇)、そして **設計から直接予測できない構造的観察** (n≥6 coalition の N=10000 消失 = shadow_component_log で候補枯渇を直接確認、C_max の N=2500 ピーク非単調、k\* = 2L/N の N 逆相関、n_core=2 lifespan median の 5 スケール完全一致、n_core=2/5 の C_at_run_end ~100 倍差) の 3 区分が観察された。**5-node の階層貫通的特異性** が物理層 autonomy → 認知層 → 意識層 → 反復発動層の 4 段で再確認され、さらに **主役 272 cid の ghost ステータス 0** で「他者を吸収して生き続ける」存在様態としての特異性が確認された。v10.3 主役プールは N=5000 で 272 cid (n=5: 217 + n=4: 53 + n=7-8: 2)、うち bin 10-19 の 25 cid が「主役の中の主役」候補。

## 2. 観察事実の 3 区分

観察結果を以下の 3 区分で整理する。**規律 #100 (観察できないことを語らない)** に従い、N=5000 71×71 grid 24 seeds × tracking 50 という条件下での観察として記述する。

### 2.1 機構レベル: 5 スケールで堅牢 (= 設計通り動く)

#### 2.1.1 Q0 の N 不変性 (n_core 別 median)

| n_core | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| 2 | 12 | 12 | 12 | 12 | 11 |
| 3 | 20 | 20 | 19 | 18 | 18 |
| 4 | 28 | 28 | 27 | 26 | 25 |
| 5 | 37 | 36 | 34 | 33 | 32 |

5 スケールで n_core 別 Q0 median が 5-10% 範囲に収まる。`Pbirth = (1/C(N,n)) × ρ^(n-1) × r_core^(n-1) × S_avg^(n-1)` の N 依存項が他要因と相殺している。**設計時に明示的に意図されていなかった robustness**。

#### 2.1.2 E1/E2 spend 絶対量の N 完全独立

| 指標 | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---|---:|---:|---:|---:|---:|
| n_E1_E2_spend | 21,671 | 20,926 | 20,843 | 20,107 | 20,548 |

5 スケールで 20,107-21,671 の幅 (7% 以内) で揃う。**物理層由来の Q 消費は N に対し完全独立**。これは v6.x 以降の物理層 frozen 規律が 5 桁の N で機能している直接証拠。

#### 2.1.3 空摂食 / phantom contact 全 N で 0 件

5 スケール × 24 seeds × tracking 50 のすべての case で 0 件。即時摂食 (案 B) と動的決定連鎖の設計 robustness の確認。

#### 2.1.4 bit-identity の維持

二層 bit-identity 検証 (層 A: 同 seed 2 回 run / 層 B: v9.18 baseline 物理層 frozen) は v10.2 main で確認済。N-sweep 各スケールでも同条件で動作している (smoke 段階で確認、本番 run の物理層挙動は v10.1 と一致)。

### 2.3 設計から直接予測できない構造的観察

これらは確率計算資源モデルだけからは予測できない、構造効果に由来する観察。

#### 2.3.1 n_core ≥ 6 coalition の N=10000 完全消失

| N | n_core ≥ 6 cid 数 | 最大 n_core |
|---:|---:|---:|
| 500 | **71** | 11 |
| 1000 | 15 | 9 |
| 2500 | 10 | 8 |
| 5000 | 3 | 8 |
| **10000** | **0** | (n=5 まで) |

N が大きい = ノード集合が広い = persistence 条件 (age_r ≥ τ) を満たす component が成立しやすい、と素朴には予想されるが、観察は逆。N が大きいほど大型 coalition は形成されない。

follow-up §3 の空間解析 (label_member_persistence データ) によると、検出された大型 coalition は **格子の対角線距離の 87% を覆う広域分散構造** (dist_max_normalized 0.82-0.88)。link 形成が空間制約なし (= ランダムサンプル) なので member は格子上に散在。

仮説:
- N=500 (23×23 grid) では link/N 比率が高く、persistence 条件を満たす多数派 component が形成しやすい
- N=10000 (100×100 grid) では link 候補が広く分散するため、persistence 条件で連結する多数派 component が構造的に出現しない

これは v9.12 の n≥6 欠落原因 (50% overlap フィルタ + 非空間リンク形成) を **「N=5000 71×71 grid に固有の現象」** として再定位する材料になる。普遍的な制約ではなく N 依存の構造効果。

**追加観察 (extra B、shadow_component_log による直接確認)**:

`persistence/shadow_component_log_seed*.csv` (v9.13 persistence audit が threshold τ=50 を満たした連結成分のサイズ分布を window ごとに記録) で確認すると、**「N=10000 で大型 coalition が無い」のは「runtime label tracker の取りこぼし」ではなく「persistence audit のステージで既に候補が枯渇している」状態**。

| comp_size | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| 5 | 542 | 597 | 621 | 550 | 597 |
| **6** | **15** | **10** | **4** | **2** | **1** |
| **7** | **22** | **17** | **7** | **0** | **0** |
| **8** | **9** | **3** | **1** | **1** | **1** |
| **9** | **3** | 0 | 1 | 1 | 0 |
| **size ≥ 6 合計** | **50** | **32** | **13** | **4** | **2** |

- size ≤ 5 の候補数は N にほぼ独立 (size=5 で 542-621)
- size ≥ 6 の候補数は N に対し monotonic 消失 (50 → 2、25 倍減)
- k\* (= 2L/N) との強い正相関: N=10000 では k\* = 1.06 で閾値ギリギリ下、結果として大型候補がほぼ消える

**仮説 (構造的)**:
- 大型 coalition は **「k\* ≥ ~1.1」** という link 密度閾値の上で形成される
- persistence 条件 (age_r ≥ τ) は link の継続性を要求するが、k\* が低いと「複数 link が同時に persistence を満たし、かつ連結している」確率が下がる
- ESDE の **疎グラフ性が N で強化される** ことの直接的帰結。「N が大きい = 多様性増」という素朴期待と逆になる

**含意**: v10.3 で大型 coalition 主役を観察したいなら **N ≤ 1000** が必要。N=5000 / N=10000 では n_core=4-5 中型 coalition 中心の三項共鳴になる。

#### 2.3.2 C_max の N=2500 ピーク (非単調)

| 指標 | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| C_max overall | 66 | 81 | **90** | 85 | 78 |
| C ≥ 50 cid 数 | 19 | 29 | 118 | **194** | 192 |
| C ≥ 80 cid 数 | 0 | 1 | 2 | **4** | 0 |

cognition_rate / consciousness_rate は N=10000 で最大なのに、**個別 cid の C 蓄積上限は N=2500 がピーク**。集団指標と個別指標が異なる scaling。

C_max 達成者は 5 スケール全てで lifespan=25,000 (run 末まで生存)。**C 蓄積は累積型で、長寿が必要条件**。

N=500 の異例: C_max を達成したのは n_core=11 cid (最大 coalition)、意識発動 0 回、摂食 0 回。「大型 coalition は cognition 当選が多発するが、意識候補が成立しないため C が蓄積される一方」という構造の現れ。

仮説 (Code A): C 蓄積上限の非単調性は「個別 cid の累積 C 上限」と「集団全体の摂食機会」の異なる scaling に由来。

#### 2.3.3 n_core=2 lifespan median の 5 スケール完全一致

follow-up §2 lifespan 解析より:

| n_core | N=500 | N=1000 | N=2500 | N=5000 | N=10000 |
|---:|---:|---:|---:|---:|---:|
| **2** | **500** | **500** | **500** | **500** | **500** |
| 3 | 1,500 | 1,500 | 2,000 | 2,000 | 2,000 |
| 4 | 3,500 | 5,500 | 5,500 | 7,000 | 7,500 |
| 5 | 7,500 | 12,500 | 13,000 | 12,500 | 13,500 |

n_core=2 cid (= 全 cid の 70-76%) は **N が 20 倍変わっても median 寿命が 1 window (500 step) で完全一致**。n_core=5 は緩やかに上昇 (+80%)。

これは「**n_core で大枠が決まり、N が乗数効果を持つ**」という構造を示す。n_core=2 は N 不変な r 戦略の最小単位、n_core=5+ は N で活性化される K 戦略型。

観察:
- n_core=2 lifespan p25 = 500 step (= 全分布の下半分が 500 step で死ぬ)

- n_core=5 は N で **「単発発動」から「反復発動」への質的変化**

仮説: n_core=2 は ESDE における「**寿命 1 window の死単位**」として機能。物理層が cid を「1 window で消す」という最も基底的な動学。これは v10.2 main §6.1 「対称的二極化」観察を 5 桁の N 範囲で確認した形。

#### 2.3.4 k\* = 2L/N の N 逆相関

| N | links 平均 | k\* (= 2L/N) |
|---:|---:|---:|
| 500 | 351.5 | 1.406 |
| 1000 | 606.6 | 1.213 |
| 2500 | 1,405.6 | 1.124 |
| 5000 | 2,720.9 | 1.088 |
| 10000 | 5,296.7 | 1.059 |

平均次数が N に対し monotonic に減少 (1.41 → 1.06)。link 数自体は N にほぼ線形だが、ノード数も N 線形なので各ノードあたり link は減る。**疎グラフ性が N で強まる**。

これが認知層活性化の N 依存性 (cognition_rate 増、skip_C0 減) と関連する可能性。各 cid 周辺の link 密度 = E1/E2 event 発火頻度 → C 蓄積機会の構造。

注意: Genesis 期 (v0.x-v1.9) で確立された「k\*=4 が N 不変」は、本観察 (k\* = 2L/N 定義) と矛盾する。Genesis 期の k\* は別指標 (cycle peak、最頻次数等) または別パラメータ下の値の可能性が高い。検証は v9.x 系譜を読む別タスクとして残す。

## 3. 5-node の階層貫通的特異性

Autonomy 期 (v8.x、200win/500win 検証、48-seed) で確立された「5-node = density independence、転換点」が、N-sweep を経て新たな指標で再確認された。

### 3.1 階層貫通的観察

| 層 | 指標 | 5 スケールでの 5-node 観察 |
|---|---|---|
| 物理層 (Autonomy) | density independence | 5 スケールで n_core=5 比率が 10-15% 帯に維持 |
| 認知層 (capture) | n=5 capture_rate | (v10.2 main で 0.38 → N-sweep では未集計) |
| 意識層 (発動経験率) | n=5 意識発動経験率 | 14.0% → 79.0% で N 依存だが順序は不変 (n=2 < n=3 < n=4 < n=5) |
| 反復発動層 | bin_5plus 比率 (n=5) | 0% → 35.8% で N 依存、5 スケールすべてで n=2/3/4 を上回る |

**5-node が 4 つの層を貫いて頂点を保つ**観察。これは ESDE 階層構造の構造的継承 (v10.2 main で言語化) が N=5000 固有ではなく、5 スケールで保たれることを示す。

### 3.2 主役は ghost 経路を経ない (extra A、Aruism 的に重要)

extra A の主役プール 272 cid (N=5000、n_core ≥ 4 かつ n_consciousness ≥ 5) のステータス内訳:

| 状態 | cid 数 | 比率 |
|---|---:|---:|
| alive (run 末で生存) | 212 | 78% |
| reaped (摂食されて消滅) | 36 | 13% |
| **ghost (residual_Q を残す)** | **0** | **0%** |
| (その他: dead 等) | 24 | 9% |

主役 272 cid のうち **ghost ステータスは 0**。意識発動経験者は ghost 化しても摂食されて即 reaped、または alive のまま完走。

これは v10.2 主題 §3 の「ghost.residual_Q → CID Q への流入」設計と整合: **主役は他の cid の residual_Q を吸収する側であって、自身が residual_Q として消費される側にはなりにくい**。

Aruism 的観点: 5-node の階層貫通的特異性は単に「指標の頂点」というだけでなく、**「他者を吸収して生き続ける」という存在様態の特異性** でもある。短命の n_core=2 集団 (~70%) が ghost として食料源になり、長寿の n_core=4-5 主役 (~5%) がそれを吸収する、という二極構造。

### 3.3 v10.3 主役候補としての n_core=5

follow-up §3 repeated activation 解析より、bin_5plus かつ n_core ≥ 4 を「v10.3 主役候補」と定義:

## 9. 結論

v10.2 を 5 桁の N 範囲で run した本 N-sweep は、Taka の思いつきとして発動した補足実験だが、結果として以下が観察された:

**機構レベル**: Q0 が N にほぼ不変、E1/E2 spend が ~21k で N 完全独立、空摂食/phantom 0 件、bit-identity 維持。物理層 frozen 規律と層間介入規律が 5 スケールで機能している観察。

**現象レベル**: 確率計算資源モデル (P(認知)=Q/(Q+C)、P(意識)=C/(Q+C)) からの予測通り、認知/意識当選率が monotonic な N 依存。N=5000 は飽和ではなく N=10000 で更に活性化。

**構造的観察**: 設計から直接予測できない 5 つの観察が記録された:
- n≥6 coalition の N=10000 消失 (shadow_component_log で「候補そのものが枯渇」と直接確認)
- C_max の N=2500 ピーク非単調
- n_core=2 lifespan の N 完全不変 (5 スケールで median 500 step 一致)
- k\* = 2L/N の N 逆相関
- n_core=2 / 5 の二極構造 (C_at_run_end mean ~100 倍差) が 5 桁の N 範囲で不変

**5-node の階層貫通的特異性**: Autonomy 期に確立された 5-node の特異性が、物理層 (autonomy) → 認知層 (capture) → 意識層 (発動経験率) → 反復発動層 (bin_5plus) の 4 段で N=10000 まで保たれる。さらに、**主役 272 cid の ghost ステータスが 0** という観察により、5-node の特異性は単なる指標の頂点ではなく「他者を吸収して生き続ける」存在様態の特異性として 立ち現れる。

**v10.3 接続**:
- 主役プール (n_core ≥ 4 かつ n_consciousness ≥ 5): N=5000 で 272 cid (n=5: 217、n=4: 53、n=7-8: 2)
- 「主役の中の主役」(bin 10-19): 25 cid (n=5: 21、n=4: 3、n=7: 1)
- N=5000 で本番、N=10000 で追試、N=2500 で smoke が Code A 推奨。判断は Taka 預け
- 大型 coalition (n_core ≥ 6) を観察したいなら N ≤ 1000 が必要 (k\* ≥ ~1.1 が link 密度閾値)

本 N-sweep の収穫は v10.3 三項共鳴の baseline として参照される。定常検証フェイズには組み込まず、「たまに」のスタンスで継続。
