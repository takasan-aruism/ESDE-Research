# v1302 (A) 懐疑再点検 — 「transfer r=0.62」は何を何と比較した結果か

*作成*: 2026-06-24（Claude Code、Taka 依頼の一段懐疑点検）
*対象*: v1302 Phase Result の (A) scalar→plb transfer 成立（n2 0.62 / n4 0.73 / n5 0.72, p=0.001）
*方法*: engine 非実行。`cw_v1302_A_full_signatures.parquet`（既存 Code A 出力）だけを read-only 再解析。再現スクリプト＝`cw_v1302_A_skeptic_recheck.py`
*結論一言*: 報告書 #CW7「半ばトートロジー」は**控えめすぎ**。仕込んだ 1 スカラ(plb)を超えて伝わる親 identity は**残差ゼロ**。0.62 は「自分が回したノブが、そのノブが動かすものを動かしたか」を「継承」と言い換えて測った値。

---

## 0. 何を何と比較したか（曖昧さなく確定）

`transfer r` = **n_core 層ごとに作る CID×CID 距離行列 2 枚の Mantel 相関**。

| 行列 | 中身 |
|---|---|
| **Dp**（親） | 親 CID の `(s_avg, r_core, conc)` を層内 z 標準化した 3 次元のペア間ユークリッド距離 |
| **Dc**（子） | 子 late 署名 6 指標 `(n_labels, mean_size, std_size, share_gini, mean_age, lifecycle_events)` のペア距離。**各 CID で 5 seed を平均してから**距離化 |

- `p=0.001` は 999 回行置換で 0 個超過＝**下限値**（それ以上良くなりようがない、の意味でしかない）。
- 「成立」の正体 ＝ **A の Mantel(0.62) ≫ canon の Mantel(0.13/0.01/0.03)**。
- canon は plb 一定ゆえ CID 間で物理に効く違いは N(=b_gen×10) と seed のみ。A は `plb = BASE_PLB·(1+0.3·tanh(z_strength))`、`z_strength = mean(z_s, z_r, z_conc)` で **Dp を作る 3 軸そのものの z 平均**を plb に流し込む。

---

## 1. 検証1 — 「3 軸の継承」ではなく仕込んだ 1 スカラ(plb)に完全に潰れている

| 層 | Mantel(3軸) | Mantel(**plb 距離のみ**) | plb 除去後の 3 軸残差 ↔ 子残差 |
|---|---|---|---|
| n2 | 0.621 | **0.729** | **−0.010** |
| n4 | 0.731 | **0.830** | −0.005 |
| n5 | 0.717 | **0.842** | +0.182（低パワー17CID） |

- plb 距離 1 本だけで子署名は 3 軸より**よく**説明できる（3 軸の残り 2 次元は希釈ノイズ）。
- **plb 成分を回帰で抜くと、親 3 軸残差は子署名残差とほぼ無相関(−0.01)**。＝ノブを超えて伝わる親 identity はゼロ。3D の Dp を使ったことがトートロジーを覆い隠していた。

## 2. 検証2 — seed 平均化が r を底上げ（報告の「seed増で強化」の正体）

```
単一 seed r : [0.521, 0.319, 0.500, 0.334, 0.398]  中央値 0.398
1→2→3→5 seed 平均 : 0.521 → 0.466 → 0.563 → 0.621
```

単一の子は ~0.40。報告が robustness の証拠とした `0.35→0.621` は、**seed を増やすと各 CID の署名ノイズ球が縮み距離構造が締まる機械的効果**で、継承が強まったのではない。

## 3. 検証3 — 署名 6 指標自体が plb の機械的読み出し（n2 A, CID平均, Spearman）

```
plb ↔ lifecycle_events : rho +0.918    plb ↔ std_size : +0.791
plb ↔ share_gini       : +0.632        plb ↔ n_labels : +0.575
plb ↔ mean_age         : −0.726        plb ↔ mean_size: +0.121（唯一弱い）
```

plb = p_link_birth はリンク生成率そのもの→ label 数・サイズ・lifecycle を直接動かす。Dc は実質 plb 距離の再符号化。

---

## 4. 結論 — 閉ループを「継承」と言い換えていた

> 親(s,r,conc) →〔実験者の式 z平均→tanh〕→ **plb** →〔物理: plb が label 統計を機械的に決める〕→ 署名 → その署名を**元の(s,r,conc)に対して** Mantel

「自分で回したノブが、そのノブが動かすものを動かしたか」を「親 identity の継承」と言い換えて測っている。**0.62 は identity transfer の証拠ではない。** Taka の予言「物理パラメータが変われば全体平均が変わるのも違和感ない」がそのまま起きた事実＝構造継承でなく **plb による per-CID 平均シフト**を Mantel が拾っただけ。

**公平な留保**: 単一 seed でも 0.40 / p=0.001、canon は 0.13。「strength に比例した graded なノブを仕込めば canon と統計的に違う graded な系ができる」こと自体は本物。壊れているのは数値でなく**「親に似る／継承」フレーミング**のみ。

## 5. v1303 への含意

- 本点検は v1303 の方針転換（測る相手を「親に似るか #CW7」→「canon と統計的に違う系か」）を**弱めるどころか必須にする**。
- (A) の 0.62 は継承の証拠としては空だが、「違う系を自動で作る」第一歩としてなら graded ノブで成立済み、という切り分けになる。
- (B) の null（topology 上乗せ＝0）は本批判の影響を受けず、報告書で唯一堅い点という評価は不変。
- 横断教訓: ESDE で Mantel を回すときは **(i) Dp の次元と実際に物理へ入る次元が一致しているか（今回 3D 入力→1D 注入）、(ii) seed 平均前後で r がどう動くか、(iii) 署名指標がノブの機械的関数でないか** を必ず併走点検する。
