## 1. 主題フレーム

### 1.1 Taka フレーム (原文保存、絶対格言 #14)

> 人体で考えると、体内のスケールを細胞レベルにするとそれはまさにカオスの海といえる。しかしその情報が全て人体の最大スケールで現れることはない。では何がそこに現れるのか? と言えば、最も言い当てられる表現として正しいのは変化だと思う。

> 人体は変化に対してよく反応するようにできている。つまり、変化の大きなものに注意が向かう。ESDE は自分自身にとって変化の大きなものに注意を向け、その因果や影響を見る。これは CID で取り入れた認知層、意識層の上位版の発想と言えるかもしれない。

> 変化は連鎖していく。小さな変化が徐々に同期的に大きな変化として波及していく。

> 意識と呼べるものは、少なくとも身体の安定が条件といえる。不安定や死においては、より原始的な認知が優先される。認知層が活発に働いている状況ではターゲットを絞れない。特定の活発化している認知層がターゲットとして固定される。死ぬほど痛い時に考えることはそこに固定されている。しかし認知層が活発に働くと意識層が加点されていく。CID の意識層は元々選択と集中として捉えてきている。意識の強い人では痛みがあってもそれを押し殺して選択と集中を扱える。

### 1.2 機構の言葉に置いた形

- ESDE の各構造単位 (CID / α / β / ESDE 各解像度) に、注意の派生記録を持つ。
- 各時点で「変化 (連鎖・同期して育った変化)」を、3 種の変化定義それぞれで検出する (§3.2)。
- 各構造単位の Q/C 比 (qc_ratio) が **認知優位** なら、注意はその単位での最大変化に **自動固定** される (原始的注意、選択不能)。
- 認知活動で C が積み上がり **意識優位** になると、注意は自動固定から離れ「選択と集中」へ移る。選択は無からでなく、直前の認知的固定を踏み台にした連想で繋がる先 (§4.1 箱 1)。
- 注意先について **因果候補** (何から連鎖したか) と **影響候補** (何に波及するか) を観察記録として emit する。
- 注意機構は **emitter のみ**。注意と物理は別系統で、注意は物理を操らない。出力は確率的記述・候補に留まる (§4.3 箱 3)。
- すべて post-process、実 ledger 不変。

### 1.3 v1101 核心発見との接続

v1101 は「観察単位ごとに dominant atom が割れる、単一の答えがない」を観察した。本主題はその続きで、最大スケールに繰り上がるのは像そのものではなく像の差分 (変化) である、という転換。注意機構は最初から最後まで多眼的でなければならず、どこか一点で単一スコアに潰した瞬間に v1101 の発見と矛盾する。監査修正 #2 #3 はこの一本の線から出ている。

## 3. 設計 (監査修正 4 点反映)

### 3.1 qc_ratio — 各構造単位で並列、単一比率にしない (監査修正 #2)

**修正前**: 系全体の単純総和 ΣQ/(ΣQ+ΣC) を「ESDE の認知/意識優位」とする。

**監査指摘** (Gemini-1 + GPT 追加指摘、独立に同一): 系全体の単純総和は個体性 (構造単位の境界) を失った熱力学的マクロ量であり、同型展開でなく別のマクロ変数の創出。巨大な Q/C を持つ少数のハブ cid や特定の β が全体比率を支配する集団平均の罠。全体集約が意識優位でも特定 β / cid cluster は認知優位かもしれない。

**修正後**:
- qc_ratio を **系全体の単一値として持たない**。CID / α / β / ESDE-event / ESDE-step10 / ESDE-window の各構造単位で **並列に** qc_ratio を算出・emit。
- 認知優位 / 意識優位の判定は、生の総和比ではなく **個体性を保持した集約** — 「個別に Q > C となっている下位単位の数の割合」(多数決方式) または各下位単位の qc_ratio の中央値。単純総和を使わない。
- emit レコードは `change_scope` 列でどの構造単位の qc_ratio かを自己記述する。

### 3.2 変化抽出 — 3 指標を分離、統合しない (監査修正 #3)

**修正前**: 3 候補 (atom 濃度差分 / rank_1_atom 反転密度 / 観察単位間 KL divergence) を併記し、`change_magnitude` 単一列にまとめる。

**監査指摘** (GPT-2、要修正): 3 指標は「同じ変化の別測定」ではなく **変化の種類が違う** — atom_delta は量的変化、rank1_flip_density は主役交代、unit_KL_delta は観察単位間の像のズレ。単一列に統合・統合スコア化・順位統合すると「どの変化を本物とみなすか」を人間が決めることになり神の手化する。

**修正後**:
- 3 指標を **別系列で emit**。スキーマは `change_metric_type` (atom_delta / rank1_flip_density / unit_kl_delta) + `change_metric_value` (raw value) + `change_rank_within_type` (metric type 内順位) + `change_scope` (構造単位)。
- **統合スコアを作らない / 固定閾値を置かない / 重み付けしない**。
- top_k は表示用に限定し、raw candidate を保存する。
- 注意候補も指標ごとに別々に emit する — atom_delta で見た注意候補 / rank1_flip で見た注意候補 / unit_KL_delta で見た注意候補。「ESDE はどの変化に注意したか」ではなく「どの変化定義で見るとどの注意候補が立つか」を記録する。
- 「連鎖・同期」は単発 step 差分では測れず、隣接 step・隣接 cid に同方向変化が伝播した度合いを測る。v1101 観察 2 の波及プロファイル (Δt × 対象) をテンプレートにする。

### 3.3 因果候補・影響候補の観察

- 注意候補 (= 各変化定義での最大変化点) を source として、v10.7 の 5 種 relation_path で「注意候補がどこと繋がっているか」を取る = **因果候補** (causality_candidate_path、絶対格言 #10「因果でなく因果候補」)。
- v1101 観察 2 の構造 (中心 × Δt × 13 列) を「注意候補中心の波及」に置換し、周辺の波及を取る = **影響候補** (influence_candidate_count)。

### 3.4 注意 emit スキーマ (監査修正 4 点 + 箱 1/2/3 反映)

注意 emit の per-record スキーマ:

```
seed, step, t_window,
change_scope,               # CID / α / β / ESDE-event / ESDE-step10 / ESDE-window
change_metric_type,         # atom_delta / rank1_flip_density / unit_kl_delta  (修正#3)
change_metric_value,        # raw value、確率的記述・候補 (確定値でない、箱3)
change_rank_within_type,    # metric type 内順位 (修正#3)
attention_candidate_id,     # 注意候補 (cid or atom id)。attention_target ではなく candidate (箱3)
qc_ratio,                   # change_scope 単位の Q/C 比、系全体単一値は持たない (修正#2)
qc_regime,                  # cognitive_dominant / conscious_dominant、多数決または中央値で判定 (修正#2)
predicted_lock_mode,        # 認知優位時 = 固定モードの予測、意識優位時 = 選択モードの予測。
                            #   旧 attention_locked。記録専用で確定でないことを名称で明示 (修正#4)
predecessor_attention_ref,  # 意識優位時、この注意候補が踏み台にした直前の認知的固定への参照 (箱1)
causality_candidate_path,   # v10.7 5 path のうち最強の relation_path_type (因果候補、§3.3)
influence_candidate_count,  # Δt 範囲内で attention_candidate と一致した周辺 cid 数 (影響候補、§3.3)
```

- 全構造単位で同型に emit。**主体を一つに固定しない** (箱 2、Gemini-3 監査で妥当確認)。
- 全出力は **候補・確率表記**。`attention_target` でなく `attention_candidate`、`change_metric_value` は確定値でない、`predicted_lock_mode` は予測であって固定の事実でない (箱 3)。

### 3.5 emitter 境界条項 (監査修正 #4、GPT-3 必須化)

> 段階 1 の attention_emit_log は派生記録である。段階 1 内では target selection / atom introduction 対象選別 / ingestion 選択 / 構造形成 feedback に **使用しない**。attention_emit_log を後続主題で selector として使う場合は段階 1+ として **別主題化** し、その時点の認知層・意識層構造に対する独立監査を必須とする。

注: 当初の境界条項は「v9.7 認知→存在介入の撤回前例との整合監査」を求めていたが、開発ロードマップで認知層・意識層が v10.x 以降の構想 (v9.7 時点には存在しない) と確認されたため、v9.7 を selector の前例として扱わない。別主題化時の監査は v9.7 整合でなく、その時点の構造に対する独立監査とする (§4.3 参照)。

## 4. Taka 領域 3 箱の確定 (Taka 整理 2026-05-17、原文保存)

事前調査では Code A・監査者が埋めない箱として保留されていた 3 事項を、Taka が確定した。

### 4.1 箱 1 — 意識優位の「選択と集中」が何を選ぶか = 連想ゲーム

Taka 整理 (原文):

> 要は連想ゲームだと考えればいい。意識が立つにしろ、それは認知的な活動の何かを踏み台にしなければならない。でなければ霧の中に意識だけあるようなことが起こり得てしまう。その範囲内で、A,B,C のように選択肢が見えている状態といえるがこの範囲は実に広い。例えば人間の場合、認知的な反応に関連するある時間軸のある行動を思い出す、という場合もあれば全く無関係に見える友人のことを思い出すなどもある。本人すらなぜそれを考えているのかわからないようなものだが、その連続性を認識できる状態、と言えるかもしれない。

**設計への落とし込み**: 意識優位で注意が選ぶ対象は無から選ばれない。直前の認知的固定先 (認知優位時に固定されていた変化) を踏み台にし、そこから連想で繋がる先でなければならない。繋がり方は広く、関連的なものも一見無関係なものもありうる。判定はせず、踏み台への参照 (`predecessor_attention_ref`) を記録することで「連続性を認識できる状態」を残す。霧の中の意識だけ、を構造的に禁止する。

### 4.2 箱 2 — 主体をどの単位に置くか = 切り替わる、構造が根拠

Taka 整理 (原文):

> 人間は常に主体を切り替える。しかしその切り替えには何らか構造的な根拠を定義することができる。例えばそれが経験という根拠かもしれない、直感かもしれない。何となく、という場合もある。何を主体に置くか、はどの構造が用いられているのか、ということで一つ理解しやすい基準になるかもしれない。

**設計への落とし込み**: 主体は一つに固定しない。切り替わるのが正常。emit スキーマの `change_scope` (CID / α / β / ESDE 各解像度) が「そのとき注意がどの構造単位で立ったか」= 主体の構造的根拠の記録になる。「経験という根拠」が ESDE で何に当たるかは段階 1 の観察対象。本箱は「未確定」ではなく「主体 = 用いられている構造単位、切り替わりが記録される」という確定回答。

### 4.3 箱 3 — selector の可否 = 二分の解消、注意は物理を操らない

Taka 整理 (原文):

> 現状どのような処理本体も存在していると考えられる。私たちが扱っているのは観測の向きや位置の話であり、系を動かしているのではなくて観測を行うことで系を動かしているように見えるという話。意識して手を動かす、は認知的な機能がある。それを操っているというのか、そもそも注意と操る、は関係ない、という視点はなしではない。事実そうだ。でなければ、私たちは意識した通りにしか身体を動かせなくなってしまうのでは?

Aruism 対称性の補足 (原文):

> ESDE の物理は極端な言い方をすればランダムの発生である。これを予測することはできる。確率的に扱うことで 100% ではないがほぼ 100% を弾き出すのはあっても良いと思う。しかし、ここで 100% が発生したら、その時点でランダムはあり得ない。つまるところアリズム同様、存在は対称性を持つ。唯一無二のある、を私たちは厳密には知り得ない。人間のスケールでは定義も扱うこともできず、因果や法則などに頼らなければそれをそれとすることもできない。この原則が生きるような設計をしておけばどこかで破綻することもない。

**設計への落とし込み**:
- emitter / selector の二分そのものを解消する。注意機構は emitter のみ。注意と物理は別系統で、注意は物理を操らない。注意が扱うのは観測の向きと位置。
- 「観測を行うことで系を動かしているように見える」連鎖 (注意の記録が次の観測の向きを決める) は段階を進めた先の話で、段階 1 の範囲外。段階 1 は観測の向き・位置を記録するのみ。
- 注意機構の全出力は **確率的記述・候補に留まる**。ほぼ 100% は記録してよいが、100%・確定・唯一の対象を emit してはいけない。100% に到達した時点でランダムという ESDE 物理の前提が壊れる。Aruism の対称性原則 — 唯一無二の「ある」を厳密には知り得ない。
- §3.5 の emitter 境界条項は「安全のための制約」ではなく「注意とは元々そういうものだ」の言い換え。
