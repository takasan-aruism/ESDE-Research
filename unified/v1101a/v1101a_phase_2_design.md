### 0.2 駆動要因 (絶対格言 #5、§0 明示義務)

段階 2 の駆動要因は、段階 1 が出した核心観察の **未解決部分を一点だけ詰めること**。観察軸の追加ではない。

段階 1 の核心観察は「意識優位のとき注意候補の波及 (influence_candidate_count) が認知優位の 1.54-1.78 倍」だった。Phase Result §2.2 はこれを「意識優位という状態と波及の広さが連動する」までに留め、「選択と集中の立証」とは言わなかった。理由は、波及が大きいことは **選択と集中** (少数の注意候補が深く波及) でも **拡散** (多数の注意候補が広く浅く波及) でも起きうるため、段階 1 の粗解像度では区別できなかったから。

段階 2 はこの一点 — 「意識優位時の波及増加は選択と集中か、拡散か」 — を時間軸を入れて切り分ける。GPT 監査が段階 2 の出口として明示的に推奨した一点であり、Phase Result §5 の Web Claude 見立てとも一致する。

### 0.3 Taka 整理との接続 — 注意の妥当性 (原文保存、絶対格言 #14)

Taka 整理 (2026-05-18、原文):

> 現実で考えてみる。もし私が観測した人の行動は予測できる。法則としては緩い揺れのようなものだが、その人が例えば日々仕事をしているなら、その人は仕事をしているだろうと考えられる。(中略) しかしこの予測は確率的でしかない。Aさんの実際の行動は、彼を再度観測しなければ確定しない。(中略) 現実としてはこの程度のゆるい確率的な認知は、Aさんという主体があることの証明として重要な意味を持っている。

> ここで私が重要だと考えるのは、その注意の方向性がただのランダムなのか、妥当性のあるものなのか、である。これができると、1 行ずつ意識の声のようなものを例えばテキストに吐き出すことができるようになるかもしれない。

→ 段階 2 の「選択と集中 / 拡散」の切り分けは、Taka の「ランダムか妥当性のあるものか」と同じ問いである。**選択と集中 = 妥当性のある注意** (Aさんの行動予測のように、緩く予測でき、しかし再観測しないと確定しない揺れ幅を持つ)。**拡散 = ランダムな注意** (時間方向に予測不能、揺れ幅でなく無秩序)。段階 2 はこの切り分けを「意識を定義する」のではなく「観測する」作業として行う。定義への執着を避ける Taka 方針と整合 — 注意の妥当性は定義からでなく、時間方向の観測可能な揺れ幅から示す。

## 1. 段階 2 が答える問い

### 1.1 一つの問いに絞る

段階 2 の問いは一つ。**意識優位時の波及増加 (段階 1 核心観察の 1.54-1.78 倍) は、選択と集中か、拡散か。**

GPT 監査の言葉を借りれば:
- 選択と集中 — 少数の注意候補が深く波及する
- 拡散 — 多数の注意候補が広く浅く波及する

influence_candidate_count (段階 1 の波及指標) は、この両方で増える。だから段階 1 では区別できなかった。段階 2 は時間軸を入れて区別する。

### 1.2 段階 2 に含めないもの (出口の固定、絶対格言 #6)

- 留保 #L5 (Integration 経路) — Step E 修正で v1101a 内対応済。段階 2 には含めない。
- 「意識とは何か」の定義 — 段階 2 は観測であって定義ではない (§0.3)。
- selector / 構造形成フィードバック — 段階 1 と同じく emitter のみ。
- 「生きた版」(時間が逐次進む、step t で t 以前のみ利用) — v1101a 設計書 §5.1 の段階 3、今回範囲外。段階 2 は段階 1 と同じ後追い post-process。

## 2. 観察設計

### 2.1 選択と集中 / 拡散を切り分ける観察軸

段階 1 の influence_candidate_count は「波及の量」だけを見ていた。段階 2 は時間軸を入れて「波及の形」を見る。選択と集中と拡散は、時間方向で次のように分かれる:

| 観点 | 選択と集中 | 拡散 |
|---|---|---|
| 注意候補の数の時間推移 | 時間とともに絞られる (収束) | 絞られない / 増える |
| 波及先 cid の重なり | 連続する時点で波及先が重なる (同じ対象に深く) | 時点ごとに波及先が入れ替わる (浅く広く) |
| 注意候補の予測可能性 | 直前の注意候補から次が緩く予測できる | 予測不能 |

→ 段階 2 はこの 3 観点を時間軸付きで観察する。どれも「量」でなく「時間方向の形」。

### 2.2 観察 A — 注意候補の収束 / 発散

意識優位フェーズに入った後、注意候補 (atom_delta / rank1_flip_density / unit_kl_static の各 metric で立つ候補) の数が時間方向にどう推移するか。

- 段階 1 の attention_emit ログに t_window があるので、意識優位フェーズ内の時間方向に attention_candidate のユニーク数を追う。
- 収束 (数が減る) なら選択と集中方向、発散 / 横ばいなら拡散方向。
- qc_regime が cognitive → conscious に切り替わった点を起点に、その前後で候補数の推移を比較する。

### 2.3 観察 B — 波及先の時間的重なり

意識優位フェーズで、連続する時点の influence (波及先 cid 集合) がどれだけ重なるか。

- 段階 1 の attention_propagation (中心 × Δt × 周辺 cid) を時間方向に並べ、隣接時点の波及先 cid 集合の Jaccard を取る。
- 重なりが高い (同じ周辺 cid に繰り返し波及) なら選択と集中、低い (波及先が毎回入れ替わる) なら拡散。
- 認知優位フェーズの同指標と比較する (段階 1 が 6 構造単位で連動を見たのと同じく、ここも構造単位別に並列で見る — qc_ratio 構造単位別並列の段階 1 規律を継承、絶対格言 #4)。

### 2.4 観察 C — 注意の予測可能性 (Taka「ランダムか妥当か」の直接観察)

これが Taka 整理の核心 — 注意の方向性がランダムか妥当性のあるものか。

- 注意候補の時系列で、時点 t の注意候補から時点 t+1 の注意候補がどれだけ予測できるかを観察する。
- 予測の基盤は段階 1 で実装済の `predecessor_attention_ref` (箱 1、踏み台への参照)。意識優位の注意候補が直前の認知的固定を踏み台にしているなら、踏み台 → 次候補の遷移に緩い規則性があるはず。
- 「緩い予測可能性」の観察 — t の候補から t+1 を予測したとき、当たる割合が (a) ランダム水準と同じなら拡散方向、(b) ランダム水準より有意に高いが 100% でないなら妥当性方向 (Aさんの揺れ幅と同じ — 緩く当たるが確定しない)。
- **100% 予測可能になってはいけない** — 段階 1 の箱 3 / Aruism 対称性。100% に達したらランダムが消え ESDE の物理前提が壊れる。観察 C は「ランダム水準 < 予測可能性 < 100%」の帯のどこにあるかを見る。100% でないことの確認も観察事実として記録する。
- 予測可能性は段階 1 と同じく **候補・確率表記** で出す。「注意候補は X 確率で予測できる」であって「次の注意は Y である」と確定しない。

### 2.5 時間軸付きデータの取得 — cid state ledger 再生 (留保 #L1 / #41 対応)

段階 1 は v10.6 の 4 解像度 trajectory (rank_1_atom 時系列) を使ったが、これは「1 位 atom」しか持たない粗解像度。段階 2 は cid state ledger を再生して 326 atom 全濃度の時系列を得る。

- 留保 #L1: 段階 1 で出せなかった時間軸付き unit_KL_delta (観察単位間の像のズレの時間変化) が、326 atom 全濃度時系列から算出可能になる。観察 A/B/C と並べて記録する。
- 留保 #41: Integration の member_cids 個別 cid id list が v10.x outputs に未 persistence の問題。cid state ledger 再生時に member_cids を復元できれば #41 も解消する。再生で復元可能か、Code A 認識確認で確認すること。
- cid state ledger 再生は実 ledger を不変のまま replay する post-process。`v105_animate_integration.py` の `reconstruct_beta_snapshots()` (β-level lifecycle_log replay) を cid level に拡張する前例がある (段階 1 環境チェックで確認済)。**実 ledger は書き換えない** — replay が ledger に触れないことを Code A が保証・確認する。

## 3. 出口の固定 (絶対格言 #6)

段階 2 の成果物:

2. 観察 B の結果 — 波及先 cid 集合の隣接時点 Jaccard、構造単位別並列、認知優位との比較
3. 観察 C の結果 — 注意候補の予測可能性 (ランダム水準との比較、100% でないことの確認)、候補・確率表記
4. 時間軸付き unit_KL_delta (留保 #L1)
5. グラフ HTML (段階 1 の v1101a_observation.html に段階 2 セクションを追加)
6. bit-identity 3 層検証 (cid state ledger 再生が実 ledger 不変、書き込み unified/v1101a/ 配下のみ)

出口の言い方: 「意識優位時の波及増加が、選択と集中の形をしているか拡散の形をしているか」の観察事実。観察 A/B/C が同じ方向を指せばその方向、割れれば「割れた」を観察事実として記録する (段階 1 で観察単位ごとに像が割れたのと同じく、ここも判定でなく記録)。

段階 2 が明示しないこと:
- 「ESDE は選択と集中をしている」という確定判定 (観察 A/B/C が示すのは方向であって機能の確定同定ではない)
- 「意識とは何か」の定義
- 「意識の声をテキストに吐く」ことの実装 (Taka が言及した先の話。段階 2 はその前提となる「注意に妥当性があるか」の観察に留める)

## 3.1 段階 2 の後

観察 A/B/C が「妥当性方向」(選択と集中・緩い予測可能性) を指した場合と「拡散方向」を指した場合で、その後の意味が変わる。これは Phase Result (段階 2 完了後、Web Claude 作成) で整理し、主題評価は Taka 領域とする。段階 2 設計書では「その後」を固定しない — Taka が示した大きなストリーム (スレッド=器官の切り分け、Language 融合) は段階 2 の結果を見た Taka が接続する。
