### 1.1 v1102 が扱う問い

**同じ入力を ESDE に入れたとき、受け手の内部構造と応答までの時間スケールという条件で、応答 (注意の動き・揺れ幅) はどう変わるか。**

会話接続足取り点検の段で言えば、段 1 (入力が ESDE に入る) と段 3 (Integration スケールで揺れ幅が出る) を、受け手構造 × 時間スケールの 2 次元で観察する。

**「応答」の定義 (GPT 監査必須修正)** — 本書でいう「応答」は自然言語応答ではない。ESDE 内部の応答 profile — attention trajectory (注意の移動軌跡)、Integration スケールの揺れ幅 (variability)、atom / category の反応 profile — を指す。v1102 は会話の返答 (言語) を作らない。「応答」という語を自然言語応答と取り違えないこと。会話の返答 (言語) を作るのは段 4・段 5 であり v1102 範囲外 (§1.4)。

### 1.2 二つのスケール (Taka 整理 2026-05-19、原文保存)

Taka 整理 (原文):

> 二つのスケールを検討する必要がある。一つは時間。もう一つは ESDE 内部の構造。情報の伝達に関して、現実の世界では時間スケールが条件によって異なる。例えば A と B が電話で話をするという状況と、A が B に手紙を書いたのでそれに返信するという状況。A→B として、情報が C という前提があったとしても、応答までに与えられた時間によって応答は D にも E にもなる。今回想定の実験場では、A、C という情報はおそらく動かない。しかし、受けてが B か、B1,2,3,4,5... かは未確定だ。かつ時間スケールは私たちの系ではすでにいくつか用意されている。少なくともこの件を前提におかないと実験結果は単一的となり、その都度 AI は何がわかった! これはあぁだ、と狭い範囲で定義づけに走る。

> 次に ESDE 内部の構造。よく忘れられるが、どういう構造がどういう回答をするのか? v1101a でさえ CID、Integration α、β 程度であった。毎回論じるが CID 単体でも 2 ノードが全体のほとんどをしめている。しかし構造的な妥当性として 5 ノードは情報量の観点から強い。平均化するとこのあたりが潰される。

→ **時間スケール** = 応答までに与えられる時間。現実の電話 (即時) と手紙 (遅延) で応答が変わる。ESDE には immediate / short / medium / window の時間粒度が既存。同じ入力でも時間スケールが違えば応答が変わる。
→ **受け手構造** = どの内部構造が応答するか。受け手が単一の B なのか B1〜B5 なのか。CID 単体でも 2 ノードが大半だが 5 ノードは情報量で強い。Integration の構成 (Step G の n_members × qc_gini) も受け手構造の一部。平均化するとこの差が潰れる。

## 2. 観察設計

### 2.1 全体構成 — 網羅集計 + 際立ちの掬い取り

研究手法アップデートのとおり、v1102 は二段構えで観察する。

1. **網羅集計** (従来方式、土台) — 受け手構造 × 時間スケールの全マスを集計する。これは「あるものはあるで良い」の土台部分。
2. **際立ちの掬い取り** (アップデート、本主題で本格適用) — 全マスの中から、構造的指標で際立ったマスを掬い、2 次元で並べ、その内部波及を 3 次元で見る。

### 2.2 受け手構造の軸 (Step G を継承・拡張)

受け手構造は v1101a Step G が既に始めた層化を継承する。Step G は Integration α/β を n_members × qc_gini で層化した。v1102 はこれを「受け手構造」の軸として使う。

**primary receiver scale は Integration (GPT-4 監査修正)** — v1101a 段階 2 の結果から、受け手スケールには役割差がある。CID は予測定義が自己言及で閉じやすい (留保 #L8)、ESDE 全体は集約されすぎて測定不能になりやすい (留保 #L10)、Integration だけが揺れ幅と妥当性を持つ。したがって v1102 の primary receiver scale は **Integration α/β** とする。CID は低次の比較対象、ESDE 全体は高次の比較対象。

| スケール | v1102 での役割 | 軸 |
|---|---|---|
| Integration α/β | **primary receiver scale** | n_members × qc_gini (Step G の 10 セル層化を継承) |
| CID | 低次の比較対象 | n_members (構成ノード数。Taka「2 ノードが大半、5 ノードは情報量で強い」) |
| ESDE 全体 | 高次の比較対象 | event / step10 / window 解像度 |

注意 — primary を Integration に置くのは「応答の読み取り単位の中心を Integration にする」意味であって、「CID の構成層化をやめる」ではない。Taka がこの主題で一貫して言ってきた「平均で潰れる構造を見る」「CID は 2 ノードが大半だが 5 ノードは情報量で強い」は受け手構造軸の核であり、CID の n_members 層化は比較対象として保持する (Step G 継承)。

複数受け手構造 (B1〜B5) の実装 — Gemini 論点 3 のとおり、Run を構造別に分けない。Run を分けると Genesis 系の確率的発生でベースラインがズレ比較が困難になる。同一 Run (同じ世界・同じ刺激) の中から、受け手構造別 (n_core=2 の CID 群 / Integration α / Integration β 等) の振る舞いを post-process で層化抽出して比較する (Step G の拡張)。

Step G が「α の 49.6% が n=1、大型均等構造で integration_beta 95%」を示したのは、受け手構造が結果を変えることのデータでの一度目の確認。v1102 はこれを入力に対する応答の文脈で見る。

### 2.3 時間スケールの軸

ESDE には既に時間粒度がある — immediate (1-10 step) / short (10-100) / medium (100-1000) / window。v1101a 段階 2 もこの粒度で観察した。v1102 は同じ入力に対する応答を、この時間粒度別に読む。時間スケールは読みの軸であって実験変数ではない (§1.3 確定、時間を操作しない)。

現実の比喩 (Taka) — 電話 (immediate に近い、即時応答) と手紙 (遅延応答)。同じ入力でも、immediate で読んだ応答と medium で読んだ応答は違うはず。ESDE は自身の動的力学系の中で即時的反応と遅延・蓄積的反応を自然に生んでおり、それを異なる時間ウィンドウで読む (切り取る) ことで電話と手紙の違いを記述する。v10.13.a の reaction phase map とも整合する。

### 2.4 際立ちの掬い取り — 軽い踏み込み (研究手法アップデート §2.6)

v1102 は際立ちの掬い取りを A (実験者の測定) と B (ESDE 自身の emit の read-back) で行う。研究手法アップデートで「掬い取りの重心は長期的には B に移る」と確定しているが、v1102 の手続きとしては GPT-5 監査のとおり **A を primary、B を secondary (read-back)** とする。長期方向 (重心 B) と v1102 の手続き上の主従は別の話 — v1102 段階で B を primary selector に格上げすると「軽い踏み込み」を超え「ESDE 自身が重要性を選んだ」と言いすぎる危険があるため。

- **A (primary、実験者の測定としての掬い取り)** — 受け手構造 × 時間スケールの全マスから、構造的指標 (効果サイズ・baseline 乖離・外れ値) で際立ったマスを掬う。閾値は分布から構造的に選定 — ヒストグラムの谷 (bimodal の切れ目) や Top N% など「データ構造自体が示す境界」を用い、人間が恣意的に「○○以上」と置かない (Step G が gini bin 境界を分布から選んだのと同じ、Gemini 論点 4)。z-score 単体はサンプル数で水増しされるため主軸にしない (絶対格言 #3)。
- **B (secondary、read-back)** — A で掬った際立ちが、v1101a が既に emit したもの (段階 1 の注意 emit / 段階 2 の attention trajectory / Step G の構成層化) と重なるかを見る。新しい emit 機構は作らない。v1101a 既存 emit の read-back に留める。これにより B は「軽い踏み込み」を超えない。研究者は ESDE が何を際立ちとして emit したかを見守り記述し、「これが重要」と指で選ばない。

### 2.5 3 次元目 — 際立ったマスの内部波及

際立ったマス (どの受け手構造 × どの時間スケールで大きな変化が出たか) について、その内部の波及を見る。v1101a 段階 1 の attention_propagation (中心 × Δt × 周辺) の構造を流用できる。これが Taka 整理の「3 次元的に見る (内部の波及など)」。
