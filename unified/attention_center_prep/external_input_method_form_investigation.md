## 0. 問い（3 分割）
1. **方法**: 外部から情報を入れるのは、どういう方法で可能か。
2. **形式**: どういう形式（フォーマット）で入れられるのか。
3. **可能性**: そもそも不可能なのか。
前提（Taka）: 24 シード ESDE は「同じ構造を異なる系で測ったもの」。ESDE の CID は ESDE 内部の物理的因果で成立している。

## 1. 結論（先に）
- **不可能ではない**。物理的な「注入」は実コードで実証済み（`physics.inject`、stage3）。
- 核心は方法より**形式**。**外部情報は座標・node ID のコピーとしては入れられない**（系を跨ぐと無意味＝番号コピー欠陥、4 連続失敗の結論）。入れられるのは**構造（位相帯）で番地付けした物理摂動**のみ。
- 論理: **「意味」を注入するのではなく、構造化した摂動を注入し、ESDE 内部の物理因果が意味を作る**。これは Taka 前提「CID は内部因果で成立」を壊さず、むしろ守るための唯一の形。
- ただし「真に外部（テキスト／現実）由来の構造を、その形式へ符号化する」段は**まだ穴**であり、現フロンティア v1114 は意図的に注意（読み）側を先に固めている（§6）。

## 3. 形式（どういう形で入れるか）── 本丸
### 3.1 入れられない形式（証明済みの「無理」）
**座標・node ID のコピー** ＝ 番号コピー欠陥（v1111c/d）。別 seed = 別宇宙なので、同じ node ID が別物を指し無意味。v1110–v1113 の 4 連続失敗はすべて「**異なる系の対応関係を測る／移す**」発想。**Taka 観察「24 シードは同じ構造を異なる系で測ったもの」は、リテラルなコピーが破綻する根拠そのもの**。

### 3.2 入れられる形式（ESDE が出した答え）
**構造で番地付けした物理摂動**。具体機構は v1114 Step2/3 提案の **位相帯対応（phase 帯対応）**:
- 番地を **θ 値（連続位相）**で指定し、node ID は使わない。「擦り込む対象＝似た phase を持つ node 集合」という構造的アドレス（系の番号付けに依存しない）。
- 新発明ではなく、既存の環境要因 **v43 `apply_semantic_pressure`**（全 node に θ 摂動 + 近傍 latent_boost）と同系統＝「外部影響を構造的に擦り込む」確立パターンの踏襲。
- 系を跨いで**持ち運べる情報は統計・構造特徴**（記号＝event 種別 / n_core / lifespan / C / Q_remaining / familiarity）。座標・ID・不透明 float ベクトルは持ち運べない（v1114「残すもの／残さないもの」規律）。

### 3.3 核心の論理（内部再生成）
```
外部情報 → 位相帯/エネルギーパターンとして physics.inject（or v43 型 θ 擦り込み）
  → 物理層変化 → cid 再構築 → β 動学 → Atom プロファイル変化（=「別系を学習した」状態）
```
外部は内部因果を迂回せず、物理摂動になって入り、内部因果がそれを再解釈する。だから公式チャネルが `physics.inject`（＝まず物理になる）であって、認知層に「意味」を直書きしても系内で意味を持たない。

### 3.4 環境要因の現在地（外部取り込みの先行機構・土台、2026-06-19 調査追記）
物理層期の「環境要因を取り込む」構想は 3 機構として実体化し、現在の生死は分かれる（実コード確認）:

| 環境要因 | 層 | 実体 | 現在 |
|---|---|---|---|
| **semantic_pressure** | node | `apply_semantic_pressure`（`esde_v43_engine.py:374`, prob0.005/latent_boost0.05, 近傍 latent 摂動・島内部 shield） | **常時稼働**。`esde_v82_engine.py:226` で stress ブロックの外＝**無条件**、24seed main run 含め毎 step 走る |
| **stress_decay** | link | `apply_stress_decay`（`esde_v82_engine.py:58`, stress_intensity=current_links/link_ema の好不況） | 機構は生・既定 True、**main run は OFF**（`v918_memory_readout.py:1535` stress_enabled=False）。実験で再点火（stage4 B3 / 注意センター build_center）。廃止でない |
| **External Wave** | 外部 energy 波 | `autonomy/esde_v83_calibrate.py`（wave_amplitude/period, 「±50%吸収=選択圧」） | **レガシー**。calibration のみ、現行 run 未接続（amplitude=0 既定） |

含意（本調査の主題との接続）:
- **semantic_pressure ＝ §3.2 で薦めた「位相帯=構造摂動」チャネルが、設計案でなく今動いている実機構**。外部入力は新チャネルを発明せず、この常時稼働の node/latent 摂動に「外部由来パターン」を流す形に帰着する（§2–3 の組合せ・新規発明不要を補強）。
- **External Wave ＝「外部を取り込む」系譜の祖先**だが休眠。系譜は注意センターの外部入力（physics.inject + 位相帯擦り込み, §2/§3）へ引き継がれている。
- **CID 層直接の環境要因は今もゼロ**（link/node 経由で間接）。§3.3「外部は物理に入り CID が内部因果で再解釈」と整合 ―― 環境要因はもともと物理層概念で、CID はそこから emergent する側。

## 4. 「現実世界の構造を入れる」の着地点
「別系」候補は 3 つ（Q10）:
- (i) 別 `V82Engine` instance（別 seed/N/params）＝最小代用（推奨・stage3 inject ループ流用可）。
- (ii) `language/sensor`（Phase 8、text→Molecule）＝意味 sensor。
- (iii) **外部 file/socket 経由の現実 sensor**（stage2 `sandbox/state.json` パターンの拡張、例: 温度センサ）＝「現実の構造を入れる」経路。hardware は本リポジトリ外。

**設計の急所**: 現実世界の構造を `target_nodes`／位相帯へ**どう符号化するか**。番号コピーの罠を避ける ―― 「現実エンティティ ID → ESDE node ID」は禁（無意味）、「現実の**構造特徴** → 位相帯/エネルギーパターン」が正。この符号化規則そのものは未確立（§6）。

## 5. そもそも不可能か → 否。ただし制約の意味を読み違えない
- **機械的には可能**（inject は動く、読み書き経路は確認済み）。
- **本質的制約**は「内部因果 + 異系間非対応」ゆえ、**外部の意味を移植できない／構造摂動として入れて内部に再生成させるしかない**こと。これは欠陥でなく、ESDE の自己性（CID が内部因果で成立する性質）を保つ仕様。
- Taka 自己理論（stage3）: 自然界でも自己決定の機構は外部（進化・環境）が作った。外部が形作ることは「自己でない」ことを意味しない。「示せていない（否定）」を「まだ顕在化していない（発達段階）」と読む。

## 6. 現在地と未解決（推測しない・正直に）
**現在地**: 注意センター v1114 は Step1（内部注意）確立、Step2a（生きた Center）/ **Step2-B（Atom 経由の注意）実装済**。ただし Step2-B は **意図的に「注意を向ける」配管確認まで**で、**`physics.inject` を呼ばず `engine.state` も触らない**（Taka 釘: crown 禁止・応答=cid dynamics は Step3 以降・**入力テキスト→Atom の知覚は"穴"として残す**）。書き戻し（inject）側は stage3 で可能性確認済だが、生きた Center からの常時書き戻しはまだ。

**未解決（推測しない）**:

2. 予測不能トリガー `dynamic_threshold` の関数形（神の手回避上、複数が等価で未確定）。

4. 「現実物理系」の具体（真の sensor hardware はリポジトリ外、Taka 判断）。
5. **最深の飛躍**: 真に外部由来の位相帯摂動が、意味ある内部再解釈を生むのか、ノイズに終わるのか。会話経路の段4-c/4-d/5 の「未定義の飛躍」と同型で、未証明。v1103 は「48次元密度で応答 Atom を絞る機構が原理的には働く（"principally"）」まで。`cid_atom_sim_matrix` 自体も両端で人工（LLM 判定 + 手定義投影）であり「再生成で本物になった」と読まない（Step2-B 釘(1)）。
