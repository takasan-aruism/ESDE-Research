## 観察対象注釈ブロック（v1114 規律）

## 0. 一行
親 ESDE の n_core=5 の各 CID の形態を、物理法則 params（`v19g_canon`）の*変異*に写し、**同一 Frozen 条件・異なる物理演算法則**のミニESDEを CID ごとに 500 step 回し、**どれが残りどれが消えるか／残ったものがどう動くか**を観察する。CID 多様性を「人間が決めない法則空間サンプル」として使い、生じた多様性を**どう束ねるか**を設計する試み。

## 1. 着想の発生（やり取りの記録）
1. Taka 案: CID の値を使って CID 内部にミニESDEを持たせ、param を CID 値依存に。Step1 につき 500 step、n_core=5 で試験。実験者がケースを想定せず自動で多様なミニESDEを回せる。
2. Code A 初期評価: 意味なくない。むしろ「CID 値を入力に使う」のクリーンな形 ―― 結果(CID)を置く(#20 死)でなく **param(構造拘束)を渡し子世界に発生を埋めさせる(発芽)** ＝3死線(#20/番号コピー/神の手)を全部回避。下向き/再帰の同型反復で既存の言い換えでない。だが 5 リスク（crown / 人工性 / 異系の再帰 / habitable band 外で即死 / §10 what-for）。
3. Taka reframe（リスクを枝葉に降格）: ESDE は random×構造の演算の反復。重要なのは**多様性が生じること**、そして**その多様性をどう束ねるかが系そのもの**。実験の難点は「人間が param を決めるのが大変」。それを ESDE が決めるのは方向としてあり。本丸は**生じた多様性のカオスをどう形にするか**。
4. Code A 応答: reframe に同意（crown/人工性リスクが溶ける）。「束ねる」は ESDE 既存の演算子（persistence/B_Gen/α/β/Salience/注意）の**一段内側への再適用**。「束ね方が系」＝#33。実験者の仕事が「param 決定」→「**束ね方の選択**」へ移る。make-or-break は「多様性が**束ねに乗る(安定な署名でクラスタ)**かノイズか」。
5. Taka 結晶化（本ドキュメント §2-3）。

## 2. 設計（Taka 結晶化）
- **何を回すか**: CID の内側に発生するミニESDE。各ミニESDEは **ESDE 本体の物理層 params を、その CID の形態に合わせて変化させた**もの ＝「同一 Frozen 条件・異なる物理演算法則」。
- **何を観るか**: (a) **どのミニESDEが残り、どれが消えるか**（＝その法則変異が「計算の継続」を満たすか）。(b) **残ったミニESDEがどのような動態をするか**。これを**それぞれ**観察。
- **範囲**: n_core=5 の 21 CID（seed0）で試験（全 CID は計算過大）。1 CID = 500 step。

## 3. なぜこの観察か（Taka の論拠 ―― 物理法則空間の探索）
- 我々は **「計算の継続」という物理層の至上命題**の上に CID の世界を建てた。物理層はその意味で**完成**している（habitable band 内で構造が自立持続する、Genesis の確認事項）。
- 本案は、その完成した物理を起点に、**Frozen 条件は同一のまま物理演算"法則"を変異させたら何が変わるか**を見る ―― ＝**法則空間（canon params の近傍）の系統的探索**。変異の駆動を**人間の param sweep でなく、親 ESDE 自身の CID 多様性**にやらせる。survival（計算継続するか）＝物理の至上命題そのものを readout に使う、という自己整合がある。

## 4. reframe の核（討議の中心仮説）
- ESDE 内＝random×構造の演算反復。価値は**多様性の生成**。
- **「多様性をどう束ねるか」が系そのもの**＝#33（集計単位で像が変わる、欠陥でなく構造的性質）。∴ カオスに**単一の正しい形は無い**。形は「どの束ね方を選ぶか」で*構成*される。
- ∴ **実験者の役割が移動**: 「param を決める」(ESDE に委譲) → 「**束ね方を選ぶ**」(還元不能の設計行為)。束ね方自体も注意センターで ESDE 駆動にしうる。

## 5. 束ね演算子（ESDE 既存・再発明不要）
ミニESDE群は新しい "node 層" を一段下に作る。束ねる＝既存演算子の一段内側への再適用（同型反復）:

| 演算子 | 親での働き | 本案での再適用 |
|---|---|---|
| 署名 (B_Gen 的) | 構造→ほぼ一意の指紋 | 各ミニESDEを低次元署名に圧縮（生死/寿命/最終 alive_n/閉路率/V_unified 等） |
| α-Integration | cid→観察軸 | 似た CID が似た子世界を作るかのクラスタ（観察軸） |
| β-Integration | cid→個体(会計) | 子世界群を一個体に束ねる会計単位 |
| Salience | 多様性→注目 | mass 的に重い子世界を拾う |
| 注意(z>2σ) | 全事象→287点 | 稀な/異常な子世界に注意を落とす |

## 6. make-or-break（効く/効かないの分かれ目）
- 多様性は安い（random param でも子世界はバラつく）。問いは「**そのバラつきが束ねに乗る構造かノイズか**」。
- **似た CID → 似た子世界**が*再現性をもって*出る → 署名が安定にクラスタ → **束ねられる＝形になる＝意味あり**。
- 全子世界が無構造に違うだけ → 多様性はあるが**束ねられない＝形にならない**（「カオスをどう形に」が「できない、ノイズ」になる）。
- ∴ 最小実験の眼目は「多様な世界が回ったか」でなく「**生成多様性が安定な署名でクラスタするか**」を実測すること。

## 7. 入力問題への別角度（§10、正直に soft）
- Taka 正直: 「それが何になるか」は少し困る部分がある。だが**「ESDE にインプットする」難しさへの別角度**になりうる。
- Code A 補足: 「内部の多様性を束ねて形にする」＝**応答とは何か**（内部状態を一つの方向出力に束ねる＝会話経路 段4 の飛躍）と同型。本案はその**束ね問題のリハーサル**。また、CID 形態→法則変異→子世界の survival/動態 が安定な署名を持つなら、それは**CID の新しい構造特徴**として親の 48 次元 profile や注意センターの判定材料に戻せる（書き戻しは別途・保留中の frontier）。＝ 入力を「外から鮮明に注ぐ」でなく「**CID 形態が生む法則変異の振る舞いを内部で読む**」角度。

## 8. 未解決・3-AI への問い（討議の論点）
1. **写像（CID 形態 → 法則 param）**: どの CID 値（M_c=n_core/S_avg/r_core/phase_sig、Q/C、48 次元軌跡…）を、どの canon param（p_link_birth/K_sync/bias/decay/inject…）に写すか。**構造同型な写像**（n_core→N、r_core→K_sync、phase_sig→初期θ分布、S_avg→p_link_birth 等）が恣意性最小か。
2. **静的 or 動的**: param は CID ごとに1回固定か、CID 形態の時間変化で run 中も変える「動的」か。Taka 原文は「動的に変化させる」。最小は静的、richは動的。
3. **署名の選択**: 子世界を何に圧縮するか（生死/寿命/最終 alive_n/閉路率/V_unified/C′ 的タグ）。豊かすぎ→束ねられない、貧しすぎ→多様性消える（前ターン「符号化規則の穴」と同型）。
4. **束ね方の選択**: §5 のどれ（クラスタ/β/注意）で束ねるか。「束ね方が系」なので複数試す価値。
5. **seed 規律**: 子世界1個に seed 1 個だと符号反転しうる（smoke seed0 を絶対視しない）。固定 seed で param 効果のみ読むか、数 seed 回すか。
6. **habitable band**: CID 値を生存域内に収めて変調するか（外だと大半即死→多様性ゼロ）。あるいは「即死する法則変異」自体を survival 観察の対象として歓迎するか。
7. **§10 what-for の固定**: 子世界の readout を最終的に何に効かせるか（CID profile への構造特徴 / 注意センター判定 / 入力問題の別角度）。ここを決めないと「観察のための観察」に落ちる。
