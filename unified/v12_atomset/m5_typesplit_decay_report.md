# v12 Atomset M5 (post-process 2) — 経験を種類で分けて別軸を育てる + 衰退

日付: 2026-06-11 / **新 run ゼロ**（既存 24 seeds ログ、`m5_typesplit_decay.py`、72 秒）
設計転換（Taka、相談役 忖度なし合意）: 前回の「累積をどう抑えるか」は見当違い＝経験を**種類で混ぜたバグ**。分ければ消える。
- (1) 種類分け: 出会い系→**他者・関係軸(OTHER)**、自己系→**自己の動き軸(SELF)**。混ぜない。
- (2) 衰退: 使わない方向は徐々に低下（個性化の必要条件）。
- (3) 平衡を先に目指さない・過度に振らせて波及観察。発散抑制を目的化しない。**技術的一線=θ が inf で記録が死ぬ域だけ回避**。
- 式は robust_z 確定のまま、種類分けで「どの経験がどの軸を動かすか」を分ける。

**θ は post-process では観測不能**（エンジンを走らせない）。「記録が死ぬ」代理 = **match_rate 自体が inf 化する (α,λ) 域**（rate inf → torque inf → θ NaN の上流）。**live はこの rate 有限域内で振らせ、θ を実観測する**。

軸割り当て（10/48 軸の意味から自然対応、実コードで確認）:
- **SELF**: lifespan(temporal) / n_core(scale) / Q(ontological) / C(resonance)
- **OTHER**: R_familiarity(epistemological) / n_alphas(interconnection) / n_observed(experience)

---

## 0. 結論（先に・正直に）

- **種類分けは #7 の支配問題を解消した（Taka の読み通り、データで確認）。** self/other の swing 比は **1.4〜5.8 倍**（前回 product 累積の **~3000 倍**から激減）、衰退なし(λ=1)で **sep≈0**（自己軸と他者軸は独立に動く）。→ **「自己系500回が出会い系を埋もれさせる」問題は消えた。累積 bound は支配解消の目的では不要。**
- **記録が死ぬ(inf)域は gain α が支配**: **α≤0.5 で死亡 0%**、α=1 で 1.1%、α=2 で 2.3%、α=8 で 5.6%。**衰退 λ は死亡率にほぼ無関係**（α が決める）。→ ③ の答え: **no-inf 域は α≤0.5**。
- **ただし α≤0.5 でも「有限だが過大」な裾が残る**（swing_p99 = **10^214**）。これは inf（記録死）未満だが、**live で torque に載せれば θ をほぼ確実に NaN にする**規模。裾は **MAD がほぼゼロの低分散 CID が z-clip(±4) を飽和**させて生む（数百 event の積で爆発）。→ **記録は死なないが θ は死ぬ域**が α≤0.5 にも広く存在（post-process の inf 代理では捉えきれない、live で θ 実観測が要る）。
- **個性化(②)は存在するが、衰退が「増やす」とは静的 replay では言えない**: dom_entropy ≈ 2.4/2.8（CID は支配軸が散る＝個性あり）だが**衰退は個性指標を僅かに圧縮**し、かつ **self/other の magnitude を結合させる（sep 0→0.6）**。「衰退→個性化」は**live の feedback（伸びた軸が次の挙動を変える）でしか検証できない可能性**（静的 replay の限界）。

### 読み
- **① 種類分けで別軸に効くか**: λ=1 で sep ≈ 0（α=1 で 0.00、α=2 で −0.15）＝**自己軸と他者軸は独立**。self/oth swing 比 3.8〜5.8（self が数倍大きい＝event 数差の自然な反映、支配ではない）。**→ 別軸化は成立、埋もれ問題は消えた。**
- **③ 記録死(inf)域**: dead% ≈ 0.7·α %（α=0.5→0、α=1→1.1、α=8→5.6）。**λ は効かない**。**no-inf 境界 = α≤0.5**。
- **裾の警告**: swing_p99 が α=0.5 でも **10^214**。median(p50) は 10^0.5≈3 と健全だが、**上位 1% の高 event CID が桁外れ**。inf 未満なので「記録は死なない」が、θ には致命的規模。
- **② 個性化**: dom_entropy 2.3〜2.5（max 2.8 に近い）＝**CID は伸びる軸が違う＝個性あり**。dom=SELF 62〜72%（self は event 多く支配軸になりやすい）。**衰退は diversity を 4.3→2.2 に圧縮**（magnitude を均す）し dom_entropy も微減＝**静的 replay では衰退が個性を増やさない**。

## 2. 種類分けで「累積 bound 不要」は半分正しい（正直な切り分け）

- **✅ 支配（#7）は解消**: 別軸なので自己系が出会い系を埋もれさせない（self/oth 3000倍→数倍、sep≈0）。**この意味で Taka の「分ければ bound 不要」は確認された。**
- **⚠️ だが per-axis の裾は残る**: SELF 軸は各 pulse で毎回更新される（~500 回/CID）。robust_z でも、**低 MAD CID は毎 event が z-clip 飽和** → (1+α·4) の積が 10^200+ に発散（inf 未満の有限値）。**種類分けはこの裾を消さない**（event 数は軸ごとに減らない）。
- **裾を抑える非抑圧的レバー（発散抑制の目的化ではなく、θ を生かすため）**:
  1. **MAD floor を上げる**（現 `SCALE_FLOOR=1e-6` が小さすぎ、低分散 CID が clip 飽和。floor を上げれば飽和が減る＝裾の主因対策、§2 で予告した σ floor）。
  2. **衰退 λ を強める**（λ≤0.9 でも 24 seeds では裾 10^186、まだ大。より強い λ が要るが個性を圧縮）。
  3. **加法累積**（積でなく和）に変える＝積の爆発を構造的に回避（ただし「経験で育つ」感覚は変わる）。
- これらは **Taka の「inf だけ避ける」線を守りつつ θ を生かす**ための調整。**どれを採るかは live で θ を見ながら**（post-process は inf までしか見えない）。

## 3. live への含意（α,λ は Web Claude/Taka 判断、post-process が示した境界）

- **no-inf（記録が死なない）域 = α≤0.5**（24 seeds、λ 不問）。3 seeds では α≤2 に見えたが 24 seeds で α=1 が既に 1.1% 死＝[[smoke-seed0-not-absolute]] どおり少数 seed で判定しない。
- **だが α≤0.5 でも有限の裾 10^214 が残る**＝**live で θ は α=0.5 でも死ぬ可能性大**。**実用 α は θ 耐性で決まり、0.5 より小さい公算**。これは post-process では決まらない（θ 観測が要る）。
- **推奨の探索起点**（Taka「振らせて観察」前提、確定でなく出発点）: **MAD floor を上げて clip 飽和裾を潰す → α を小さめ（≤0.5）から開始 → 衰退は個性化意図で λ=0.95〜0.99 → live で θ を監視し、θ が死なない最大 α まで上げて波及を観察**。
- **衰退の個性化効果は live で要検証**（静的 replay では増えない＝feedback 依存の仮説）。

## 4. 確定・未確定・次

- **確定（データ）**: ①種類分けで自己軸・他者軸は独立に動く（埋もれ解消、支配の意味で bound 不要）。③記録死(inf)は α≤0.5 で 0%。式 = robust_z のまま種類分けで適用、機構は動く。
- **新たに判明（要注意）**: 種類分けは per-axis の**有限な過大裾**（低 MAD CID の clip 飽和、~500 回更新）を消さない。**MAD floor / 衰退強度 / 加法累積** のいずれかで θ を生かす調整が要る（抑圧目的でなく inf 回避の技術線）。衰退は静的 replay では個性を増やさず magnitude を結合させる（sep 0→0.6）。
- **次（Web Claude/Taka 判断）**: (a) MAD floor を上げた再 sweep を post-process で見るか / (b) この境界（α≤0.5, MAD floor 調整）で **live M5 hook に進み θ を実観測**するか。**Taka の「振らせて波及を見る」が主目的、記録が死ぬ域だけ把握**は post-process で達成（no-inf=α≤0.5、裾の主因=MAD floor）。
- 計装前提（pre-event 凍結、種類分け）は満たし済み。**live はまだ入っていない。**

## 5. MAD floor 当たり付け（live 前の技術線、`--floorsweep`）

裾の主因 = 低スケール SELF 軸が clip 飽和。値の全体 MAD（実測）:
- SELF: lifespan **0.458** / n_core **0.000** / Q **0.009** / C **0.006**  ← Q/C/n_core はほぼ定数
- OTHER: R_familiarity 0.673 / n_alphas 1.056 / n_observed 1.003  ← 健全

**絶対 floor は低スケール軸（Q/C）を黙らせる**ので不可。**per-axis 相対 floor**（`floor_a = floor_rel × その軸の全体 MAD`）が正解。α=0.5 での sweep（24 seeds）:

| floor_rel | sw_p99 (max log10 rate) | stress%(>1e6) | dom_entropy(個性) | diversity | dead% |
|---|---|---|---|---|---|
| none (1e-6) | 214 | 22.5% | 2.50 | 3.34 | 0% |
| 1× | 174 | 18.3% | 2.54 | 2.87 | 0% |
| 2× | 130 | 15.6% | 2.56 | 2.32 | 0% |
| 5× | 70 | 11.2% | 2.57 | 1.64 | 0% |
| **10×** | **40** | **8.0%** | **2.58** | 1.26 | 0% |
| 20× | 23 | 5.2% | 2.57 | 0.96 | 0% |
| 50× | 12 | 3.0% | 2.57 | 0.67 | 0% |

### 読み・推奨
- **per-axis 相対 floor は個性を殺さず裾を潰す**: dom_entropy は 5×〜50× で **2.57〜2.58（max 2.81 に近い）で平坦**＝floor を上げても「どの軸が伸びるか」の個性は保たれる（floor が消すのは clip 飽和ノイズ＝magnitude の偽裾だけ）。絶対 floor が低スケール軸を黙らせたのと対照的。
- **裾は大きく改善**: sw_p99 が 214（10^214）→ 40（10×）→ 23（20×）と数十〜百桁減。stress% も 22%→8%（10×）。
- **だが floor 単独では θ 安全域に届かない**: 50× でも sw_p99=12（10^12）。残る裾は構造由来（lifespan 単調増加 + 各 SELF 軸 ~500 回更新）で floor では消えない。**過度に floor を上げると Taka の「振らせて観察」用の揺れも消す**ので、floor は「clip 飽和の人工裾を消す最小限」に留める。
- **当たり（推奨 1 値）: `floor_rel = 10×`**（per-axis MAD 下限 = その軸の全体 MAD の 10 倍）。dom_entropy ピーク 2.58、人工裾を 214→40 に圧縮、stress 22→8%、揺れは残す。**live で θ がすぐ死ぬなら 20×まで上げる余地（個性コストほぼゼロ）。**

### live M5 設計（確定パラメータ）
- 式 = **robust_z**（median/MAD・符号付き・clip Z=4）/ 種類分け（自己→SELF 軸・出会い→OTHER 軸）/ 衰退 λ=0.95〜0.99
- **MAD floor = per-axis 相対 10×**（θ がすぐ死ぬなら 20×）
- gain **α は θ 耐性で決める**: 0.5 以下から開始 → θ が死なない最大まで上げて波及観察（Taka「振らせて波及」）
- θ を毎 window 監視（NaN/inf 即検知）。smoke first → pause（[[smoke-then-pause]]）
